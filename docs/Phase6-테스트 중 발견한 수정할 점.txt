파티 빌더 페이지
1.포켓몬 샘플 저장 UI의 위치를 왼쪽으로 5px 이동(현재 X 버튼-파티에서 포켓몬 삭제-과 너무 붙어있음)
2.타입 상성 요약 컴포넌트에서 각 타입을 선택하면 페이지가 자동적으로 가장 아래로 이동되어야하는데 
  기존에 골라둔 타입이 보여준 파티원 반응 보다 더 많은 파티원이 있는 타입을 선택하면 스크롤을 해서 아래로 내려야 함
  언제나 페이지의 가장 밑으로 자동으로 이동되게 조절
3.타입 상성 요약 컴포넌트 UI문구 수정
  기존 : 공격 타입별로 파티가 얼마나 약한지/버티는지 한눈에 봅니다. 칸을 누르면 어떤 포켓몬이 해당되는지 보여줍니다.
  수정 : 현재 파티의 약점 타입을 한눈에 볼 수 있습니다. 타입을 선택하면 어떤 포켓몬이 해당되는지 보여줍니다.
4.타입 상성 요약 컴포넌트 - 타입을 선택했을 때 하단에 추가되는 컴포넌트 UI 문구 수정
  기존 : [선택한 타입] 공격에 대한 파티원 반응
  수정 : [선택한 타입] 기술에 대한 포켓몬 상성

결정력 & 내구력 페이지
1.UI문구 수정
  기존 : 내 포켓몬과 상대 포켓몬을 고르고, 기술까지 선택하면 몇 타에 끝나는지 판정해드려요.
  수정 : 내 포켓몬과 상대 포켓몬을 고르고, 기술을 선택하면 타수 판정을 확인할 수 있습니다.
2.현재 포켓몬 카드에 실능치(포인트 분배가 끝난 6종의 능력치)가 표시되어 있는데
  랭크 변경시에 변경된 능력치도 표시되도록 반영
  능력치가 변화하는 도구 선택시에도 능력치가 반영되도록 수정
  특성에 의한 능력치 변화도 반영되어야 함
3.내 포켓몬의 물리, 특수 내구력도 표시되게 UI 추가
4.날씨를 선택하면 선택한 날씨가 배경으로 표시되게 변경
  대전 로그 페이지의 날씨 배경을 그대로 차용
5.날씨 뿐만 아니라 필드도 선택할 수 있도록 UI 추가
  대전 로그 페이지의 필드 배경을 그대로 차용
6.기술 성묘(고스트타입)의 배율 추가
  다단 히트 기술은 아니지만, 포켓몬이 기절할때마다 기술의 위력이 50씩 오르기 때문에, 일반적인 63배틀로 가정하고
  x0 x1 x2를 구현(0은 기절한 포켓몬이 한마리도 없을때- 위력은 그대로 50
  1은 기절한 포켓몬이 한마리일때- 위력이 50증가해 100
  2는 기절한 포켓몬이 두마리일때- 위력이 100(기절한 포켓몬 한마리당 50 두마리 기절했으니 상승폭은 100)증가해
  150 이렇게 계산하도록 변경
7.특성 부자유친이 결정력에 반영되어 있지 않음
  캥카의 메가진화 특성인 부자유친은 공격1타 이후에 0.25배의 위력으로 한번 더 공격을 가하는 메커니즘
  결정력에 해당 반영 사항이 없음
  메가진화 전 캥카의 지진과 메가진화 후 캥카의 지진이 동일한 결정력을 가지고 있음(메가진화 전 캥카의 공격 실능치를
  메가진화 후 캥카의 실능치와 동일하게 조정한 뒤, 결정력 비교)
8.스케일샷, 록블라스트 등 2~5회 공격하는 기술들의 결정력 세부 표시
  최소 2회는 보장해주니까 UI추가해서 각 횟수마다의 결정력을 확인할 수 있도록 UI추가
  x2 x3 x4 x5와 같이 추가

대전 로그 페이지
1.UI문구 추가&수정사항
  랭크업 기술을 사용하면 어떤 능력치가 얼만큼 올라갔는지 대전 로그에 표기
  ex)대쓰여너가 고속이동을 사용한 경우
     턴1 먼저 행동:대쓰여너
     대쓰여너의 고속이동
     대쓰여너의 스피드가 크게 올라갔다!
     상대 포켓몬의 기술 - ...
     
1-1.특성 발동(깨어진 갑옷) 문구 추가
    특성 발동 문구가 아예 존재하지 않음
    ex)카디나르마와 한카리아스가 대면한 경우
       턴1 먼저 행동:한카리아스
       한카리아스의 지진 -데미지
       카디나르마는 기합의띠로 버텼다!(HP1)
       카디나르마의 꺠어진 갑옷!
       카디나르마의 방어가 떨어졌다!
       카디나르마의 스피드가 크게 올라갔다!
       카디나르마의 와이드포스 - 데미지

1-2.길동무 기술 구현
    현재 길동무 기술이 구현되어 있지 않음을 확인
    길동무 기술을 사용한 포켓몬이 해당 턴에 기절하면 상대 포켓몬도 같이 기절한다
    승리 판정은 길동무를 쓴 포켓몬이 패배하는거로(먼저 HP가 0이 되기 때문에)
    또한 길동무 기술은 사용한 포켓몬을 길동무 상태로 만든다(상태이상 개념)
    해당 상태의 포켓몬은 길동무 이외의 기술을 쓸때까지 길동무 상태가 유지된다
    길동무 상태가 사라지기 전, HP를 0이 되었다면 0으로만든 상대 포켓몬의 HP도 0으로 만든다
    길동무 기술은 연속으로 사용하면 실패한다
    길동무-길동무-길동무는 첫번쨰 길동무 성공, 두번쨰 길동무 실패, 세번째 길동무 성공이다

1-3.공중날기 등 차징 기술(1턴 뒤에 발동되는 기술들의 문구 수정)
    공중날기- [사용한 포켓몬]은 하늘 높이 날아올랐다!

1-4.판별, 방어등 문구 수정
    판별을 사용한 포켓몬에게 공중날기등 1턴 뒤에 발동되는 기술을 사용하면 문구가 이상함
    판별로 몸을 지켰다! 라는 문구가 출력됨
    공격을 방어하지 않았으니 해당 기술은 실패했다는 문구를 출력 되게 해야함
    또한 판별의 우선도가 다른 기술들 보다 높아 먼저 사용되는건 맞는데 문구가 무적 상태라 빗나감이 아니라
    방어, 판별, 버티기 등의 기술들은 연속으로 사용할시 기술 성공 확률이 점차 줄어드는 매커니즘이 있음
    (저번에 알려줬음) 해당 매커니즘에 따라 기술이 실패했다는 문구로 뜨도록 변경해야함
    지금은 확률이 너무 높음

1-5.기술 오류
    일렉트로빔은 사용한 턴에는 차지하면서 자신의 특수공격을 올리고, 2턴째에 자동으로 나가는 기술인데 구현안되있음
    현재 1턴째 바로 나가도록 로직이 구현되어 있는 듯
