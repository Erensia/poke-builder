# 데이터 변경 이력

`src/data/*.json`(포켓몬·기술·특성·도구 수치/학습셋)에 대한 **밸런스 패치·데이터 정정** 기록.
신규 종/기술/도구 "편입"(레귤레이션 업데이트처럼 한 번에 여러 개 들여오는 작업)은 각 버전
백로그 문서(`1.x-backlog.md`)에 남기고 여기엔 안 적는다 — 이 문서는 **기존 항목의 수치·학습셋이
바뀐 것**만 대상으로 한다.

형식은 초안이다 — ver.1.4 착수 시 사용자와 협의해 확정할 것(하단 "형식 메모" 참고).

### 하향

**기술**
- 힘흡수: PP 12 → 8 *(10 → 8로 실제 반영. 기존 값이 10이었던 경위는 불명 — 아래 "확인 필요" 참고)*
- 희망사항: PP 12 → 8 *(실제 반영)*

**기술폭**
- 브리두라스: 메탈버스트·미러코트 습득 불가 *(learnset에서 제거, 실제 반영)*
- 드닐레이브: 아이스해머·절대영도 습득 불가 *(이미 없었음 — 확인만)*
- 왕구리: 막치기 습득 불가 *(learnset에서 제거, 실제 반영)*

### 확인 필요

- **힘흡수 PP**: 패치 내역은 "12 → 8"인데 이번 작업 전 실제 값은 **10**이었다(12도 8도 아님).
  10이 어디서 왔는지 이력을 못 찾음 — 과거에 부분 반영됐던 것인지, 애초에 다른 값으로
  들어온 것인지 확인 필요. 이번엔 최종값 8만 확정 반영.

## 형식 메모 (ver.1.4 착수 시 확정할 것)

- **범위**: 신규 편입(백로그 문서) vs 기존 항목 수치 변경(이 문서) 경계가 지금은 "느낌"으로
  가른 것 — 명문화 필요.
- **출처 표기**: 이번엔 "사용자 제공(대화)"로만 적었다. 공식 M-C 패치노트 링크/버전 번호가
  따로 있다면 그걸 인용하는 게 나을 수 있음.
- **"이미 반영돼 있었음" 표시가 이대로 유용한지**: 이번 패치 내역 중 상당수가 이미 최신 값으로
  들어있었다(아마 M-C 스테이징을 처음 병합할 때 이미 패치 후 수치로 받아온 것으로 추정) —
  "확인만 하고 넘어간 항목"과 "실제로 수치를 바꾼 항목"을 이렇게 계속 구분해서 적을지,
  아니면 그냥 "패치 내역 vs 실제 반영 결과"를 표로 나란히 둘지.
- **granularity**: 패치 1건 = 문서 1섹션(지금 방식) vs 개별 항목마다 별도 커밋/섹션.
