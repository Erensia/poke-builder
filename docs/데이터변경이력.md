# 데이터 변경 이력

`src/data/*.json`(포켓몬·기술·특성·도구) 관련 데이터 변경을 전부 기록한다 — 신규 종/기술/
도구 편입이든 기존 항목 수치·학습셋 밸런스 패치든 **앞으로는 전부 이 문서에 남긴다**
(2026-09-14 확정). 과거(ver.1.0~1.3)의 편입 이력은 각 `1.x-backlog.md`에 이미 남아있으므로
소급해서 옮기지 않는다 — 이 문서는 2026-09-14 이후 변경분부터.

기록 단위는 **패치/편입 배치 1건 = 섹션 1개**. 패치 내역에 있었지만 실제로는 이미 최신 값이
반영돼 있어서 고칠 게 없었던 항목은 적지 않는다 — **실제로 데이터를 바꾼 것만** 기록한다.
