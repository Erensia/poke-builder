## ⚠️ 재현 시 주의 — 타입체크 명령어

`tsc --noEmit -p .`(루트 tsconfig)는 `"files": []` + `references`만 있는 솔루션 파일이라 **아무것도 검사하지 않고 조용히 통과**한다. 반드시 아래처럼 실제 앱 프로젝트를 지정할 것:

```bash
node_modules/.bin/tsc --noEmit -p tsconfig.app.json
```

(1-3 작업 중 이걸 몰라서 `getMove` import 누락 버그를 한동안 못 잡았음 — phase3-plan.md §1-3 마지막 항목 참고)

## ✅ 이어서 완료한 것 (다른 PC, 이번 세션)

집(다른 PC)에서 여기까지 해두고 커밋·푸시한 뒤, 이어서 회사 PC에서 진행:

| 항목 | 내용 |
|---|---|
| 필드 재설치 버그 | 필드가 이미 깔려있는 동안 필드 기술(그래스필드 등)을 다시 쓰면 지속 턴수가 갱신되던 버그 — 이미 필드가 있으면 실패하도록 수정. `ActionLogEntry.fieldSetFailed` + UI "이미 필드가 있어 실패!" 추가 |
| 1-4 | 상태이상 치료(`Move.curesStatus`) — 물거품아리아(화상 한정) |
| 1-5 | 지연형 상태이상(`VolatileCondition.drowsy`) — 하품. 2턴 카운터, 재사용 가드, 트리거 시점 면역 재확인까지 구현. 부수로 잠듦/마비/얼음의 "상태이상 데미지 0" 무의미 로그도 정리 |
| 1-4-1 | 불꽃타입 기술이 얼음 상태 상대를 즉시 해동(지속시간 무관) — 사용자 제보로 확인·구현 |
| §7 | 주 상태이상 6종 전수 재검증 — 타입 면역 확장(독/강철=독, 불꽃=화상, 얼음=얼음), 쾌청=얼음 안 걸림, 불꽃 해동은 데미지 기술만(변화기 제외)으로 정정, 얼음 상태에서 쓰면 해동되는 기술 3종(`thawsUserOnUse`), UI 3단계 문구(걸림/발동/나음) 전면 교체. 잠듦·얼음 해제 확률은 재검증 결과 이미 정확했음(몬테카를로로 확인). 부수로 플레어드라이브 반동(recoil) 데이터 누락도 같이 수정 |
| 하품 UI | 졸음 유도 시 전용 문구("상대 ○○의 졸음을 유도했다!")로 교체 |
| 1-10 | 배짱(Scrappy) 면역 무시 버그 — `Ability.bypassesImmunityForTypes` 추가, `moveContext.ts`에 배선(대전 로그·매치업 화면 공유 함수라 양쪽 다 고쳐짐) |

## 🔜 남은 것 (다음에 이어서 할 항목)

우선순위 순서대로:

1. **4-2 — 지닌 도구 데미지 배율** — **사용자가 도구별 배율 데이터를 정리해서 전달하기로 함, 아직 미도착.** 데이터 도착 즉시 착수 가능(배선 지점은 4-1과 동일 — `resolveAction`의 `computeDamage` 호출부).
2. **1-6 — 설치형 필드 효과(엔트리 해저드)**: 1v1 설계 범위 밖이라 보류. 파티 단위 확장을 논의하기 전까진 미착수.

### ~~얼어있는 포켓몬이 스스로 불꽃 기술을 쓰는 경우~~ — ✅ §7에서 해결

"본가는 얼음 상태에서 스스로 불꽃타입 기술을 쓰면 즉시 자기 해동된다"고 여기 적어뒀던 건 부정확한 일반화였음 — 사용자가 준 정확한 규칙은 "모든 불꽃 기술이 아니라 지정된 특정 기술 10종만" 해동시킨다는 것. `Move.thawsUserOnUse`로 구현 완료(현재 데이터에 있는 3종: 불사르기·열사의대지·플레어드라이브). 나머지 7종(성스러운불꽃·스팀버스트·열탕·크로스플레임·화염바퀴·화염볼·휘적휘적포)은 `moves.json`에 데이터 자체가 없어서 태깅 불가 — 데이터 보강 시 추가.

### 잠자기(Rest) 관련 후속 작업 (1-4 작업 중 발견)

HP 회복 기술(광합성·뿌리박기·잠자기 등)이 프로젝트에 아예 구현 안 돼 있음 — `curesStatus`만으론 잠자기를 표현 못 함. 회복 메커니즘 자체를 새로 설계해야 하는 별도 작업.

### 그 외 문서에만 기록된 후속 작업 (아직 스케줄 안 됨)

- 트릭룸 등 공간 변화 기술 — `turnOrder.ts`에 미배선
- 날씨 변화 기술(비바라기 등) — 특성처럼 자동 적용 안 됨
- 일렉트릭필드를 배우는 포켓몬 확인 안 됨(기술 데이터만 추가됨)
- 필드 개별 기술 상호작용(그래스슬라이더 우선도 등 다수)
- 그라운드코트(필드 지속시간 연장 도구) — 4-2와 같은 이유로 보류
- 고스트다이브의 "상대 방어 무시" 부분 — 방어 무시 자체는 별도 메커니즘이라 미구현
- 잠꼬대의 "무작위 기술 대신 사용" — usageCondition 태깅 보류
