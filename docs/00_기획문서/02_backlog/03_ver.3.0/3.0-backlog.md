## 항목 메모

### L1-a~c. 역산의 관측별 메가 폼 (2.5 L1 후속)

- 구현: `InferenceObservation.megaForm`(`defenseInference.ts`). 메가 전·후 관측이 같은 포인트 배분 후보 하나로 합쳐 검사된다(HP 종족값·포인트·성격 동일).
- L1-a는 화면에서 순서를 강제하거나(메가 후 줄 뒤에는 "메가 전" 선택 불가) 경고를 띄우는 안이 있다. 지금은 새 줄이 직전 줄의 폼을 이어받는 것으로 완화만 했다.
- L1-c는 도구를 관측별로 받아야 해서 입력 모델이 커진다 — 효용이 작으면 안 하는 쪽이 낫다.

### L4-a~f. 배틀 프런티어 (2.5 L4 후속)

- 저장 키: `champions-party-sim.battle-frontier.v1` — 현재·최대 연승, 샘플별 누적 승패, 진행 중 표시(`pendingId`). 파티·프리셋 키는 건드리지 않는다.
- 이탈 = 패배는 "판 시작 때 `pendingId` 저장 → 결과가 나오면 지움 → 앱을 열 때 남아 있으면 패배 정산"(`settleAbandoned`, 멱등).
- L4-c를 하면 "이탈 = 패배"의 우회 경로가 된다 — 기록 초기화는 확인 대화상자를 두는 편이 안전하다(단, 네이티브 `confirm`은 브라우저 자동화가 멈추니 CLAUDE.md의 검증 주의사항을 따른다).
- 코드: `useBattleSeries.ts`·`battleSeries.ts`·`BattleSeriesPanel.tsx/css`·`BattleLogPage.tsx`·`storage.ts`.
