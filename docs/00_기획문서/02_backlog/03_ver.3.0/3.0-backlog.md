### N1. 도감 타입 상성표 (새 기능, 2026-10-07 확정)

- 위치: 포켓몬 도감 우측 상세 패널에서 포켓몬을 선택하지 않았을 때 "포켓몬을 선택하세요." 문구 아래. 포켓몬을 선택하면 상성표 대신 상세가 나오고, 다른 탭에 갔다가 돌아오면(도감 컴포넌트가 새로 마운트되며 선택이 초기화) 다시 표시된다 — 별도 상태 저장 없음.
- 모양: 가로 = 공격 타입, 세로 = 방어 타입. 칸은 ×2·×½·×0만 표시하고 ×1은 비운다. 범례 한 줄. 칸 호버 시 행·열 강조 + "불꽃 → 풀: ×2" 툴팁.
- 데이터: `typeChart.json`(18×18)을 그대로 읽는다(배틀·분석과 같은 값). 아이콘은 기존 `TypeBadge`.
- **모바일은 축소 표시(B안, 사용자 확정)**: 가로 스크롤을 만들지 않고 폭에 맞춰 칸을 줄인다(약 17px). 칸이 작아 아이콘 대신 색 칸 + 기호(×2/½/0)로 줄여 쓴다. **가독성은 사용자 화면 확인으로 판단**하고, 안 읽히면 C안(공격 타입을 고르면 효과 있음/별로/없음 목록을 보여 주는 모바일 전용 UI)을 후보로 올린다. 가로 스크롤은 기술표에서 고전한 전례가 있어 쓰지 않는다.

### L4-a~f. 배틀 프런티어 (2.5 L4 후속)

- 저장 키: `champions-party-sim.battle-frontier.v1` — 현재·최대 연승, 샘플별 누적 승패, 진행 중 표시(`pendingId`). 파티·프리셋 키는 건드리지 않는다.
