# ver.4.0 백로그

3.7 마무리에서 넘어온 항목. 이전 버전: `../03_ver.3.0/3.7-backlog.md`(3.7 종료 — HP 눈금 강조 확대·패널 고정 영역, 방어 역산 턴 종료 효과, 내구 조정 탭).

- **기능 테스트**(사용자 화면 확인, 체크리스트는 착수 때 만든다): 계산 기능 4개 탭(결정력 계산 · 노력치 역산 · 스피드 조정 · 내구 조정) · 도감 · 배틀 시뮬레이터/프런티어/배틀타워/배틀비디오 · 파티 편집/샘플. 모바일 폭 포함.

### ③ 3.x에서 이월된 미수정 한계 (착수 때 포함 여부를 정한다)

- **화면 확인이 아직 안 된 것**: 모바일 폭(≤760px)에서 HP 눈금 설명 패널(3.7 H1-b) · 내구 조정 탭(3.7 A3) · 방어 역산 "턴 종료 효과" 선택(3.7 A4). 4.0 기능 테스트에 포함하는 것을 추천.
- **방어 역산 턴 종료 효과(A4) 한계**: 자뭉열매처럼 HP 절반 이하에서 조건부로 발동하는 효과는 분기가 필요해 제외 · 공격 역산 쪽 없음 · 상대 도구를 먹다남은음식으로 가정했을 때 기본값 자동 채움 없음.
- **내구 조정(A3) 한계**: 공격 1개 기준(여러 공격 동시 버티기 제외) · 분화 등 HP 비례 위력·조건부 위력 가정·도구 강탈은 이 탭에서 지정하지 않는다 · 내 나머지 포인트·성격·도구·특성은 고정하고 HP·방어(특방)만 바꾼다.
- **노력치 역산 미지원 기술**(I1-e에서 사유와 함께 보류): 고정 데미지 · 자이로볼/일렉트릭볼 · 속임수 · 셸암즈 · 쓰러진 다단히트 · 멀티스케일·섀도실드 + 다단히트(V4-b, 3.7에서 효용 낮아 패스).
- **스피드 역산**: 동속 가능도 ½ · 관측 폭 한계(역산 탭에 안내 있음).
- **보류**: P1-b(AI 속도 추가 최적화 — `partyEval`의 `afterDuel`·`duel`·GC가 상위 병목, 결과 불변 조건을 지키며 줄이려면 대면표 메모 구조를 손봐야 함) · H1-c(원본의 HP 외 능력치 기준 — 없음) · E1-c(AI 교체 왕복 14회 — AI로 대전 이력을 쌓으며 체감 확인 후 필요하면 다시 올린다).
- **확인 필요(후보)**: 결정력 계산 탭은 메가스톤을 들면 타입·종족값만 메가폼으로 바뀌고 특성은 직접 골라야 한다 — 3.7 A2에서 샘플 저장을 위해 개별 선택 설계를 유지하기로 했으므로 변경하지 않는다(사용자가 다시 정하면 재논의).
