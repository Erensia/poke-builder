## ③ 이월된 미수정 한계
- **개발 환경**: `npm run test:rules`는 Java 21 이상이 필요하고 이전 에뮬레이터가 8080을 잡고 있으면 실패한다. 이 PC(E: 드라이브가 exFAT)는 소유권을 기록하지 않아 `git worktree`가 `dubious ownership`으로 막히므로 다른 버전과 대조할 때는 `SIM_ROOT=<저장소 안 폴더>`로 `main`의 `src`를 받아 쓰고 `git -C`를 쓰지 않는다.
- **측정은 집 PC**: 이 PC는 메모리가 작아 대량 측정을 돌리면 백그라운드 명령이 종료될 수 있다. 엔진 전체 검증(`verify.sh`)·사다리·등급 측정은 집 PC에서 한다.
- 6.0·6.1 "마무리"의 한계 그대로(위 후보 표에 올린 것 외 새 항목 없음).
