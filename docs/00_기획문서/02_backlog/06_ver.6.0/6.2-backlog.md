## ①-3 6.3으로 이관 (AI 작업 — `CLAUDE.md` "버전 구성")
- **G1 앱의 3선출 난이도 구분**: 랭크 AI 단계(몬스터~챔피언)는 실수율·탐색 끄기 / 학습 사용률 λ / 상대 파티 등급으로만 갈리고 선출은 모든 단계가 최선이며 샘플 상대는 `fixedPicks`까지 항상 쓴다. `chooseAiSelection` 파라미터·랭크 AI 단계 정의를 건드려 `verify.sh` 기준이 바뀌므로 AI 작업이다. 영향 크기 근거: AI 선출 대 무작위 3마리 600판 62.3%(2.2 B5), 즉 선출 하나가 승률 약 12%p — 이미 약한 P0~P1보다 사다리 격차가 합격선을 넘는 구간(P1/P0·P2/P1·P3/P2)의 간격 조정에 쓸 만하다. `selectvs` 약화 조건은 5.1~5.4에서 계속 미측정이라 G3 숫자가 선행한다.

- **랭크 AI 학습 기억(`ai-memory-rank`) 동기화** — AI가 쌓는 데이터라 크기·형식을 먼저 재고 AI 작업으로 6.3에서 다룬다(사용자 결정 2026-10-30).

## ①-4 6.2 범위 밖 후보 (사용자 결정 2026-10-30 — 6.2에 넣지 않고 후보로만 남긴다)

### P1 PWA(서비스 워커) — 오프라인에서도 앱이 열리게
- **배경**: 지금은 정적 SPA에 서비스 워커가 없어 오프라인에서 새로고침하면 브라우저의 연결 오류 화면이 나온다(C2 확인 중 발견, 앱 버그 아님). PWA를 넣으면 앱이 오프라인에서도 열리고, 오프라인에서 플레이·저장한 기록이 C2(온라인 복귀 자동 재시도)로 올라간다. **동기화는 깨지지 않는다** — 동기화는 Firebase SDK가 Firestore·인증 서버로 직접 보내는 요청이라 서비스 워커가 가로채지 않으면 영향이 없다.
- **성격**: 엔진·AI 출력에 영향이 없는 일반 기능이라 `x.1`·`x.2` 버전에 들어간다(`CLAUDE.md` "버전 구성").
- **고려할 사항**
  1. **캐시 범위**: 우리 정적 파일(HTML·JS·CSS·데이터 JSON·이미지)만 캐시한다. Firebase·Google 도메인 요청은 가로채지도 캐시하지도 않는다. 로그인 팝업/리다이렉트와 인증 헬퍼(`firebaseapp.com`)는 다른 도메인이라 대상이 아니다.
  2. **새 버전 반영(가장 흔한 사고)**: 서비스 워커가 옛 앱을 계속 보여 주면 Vercel 배포 직후 사용자가 옛 버전에 머문다. 새 버전을 감지하면 안내하고 새로고침하게 하는 갱신 정책, 해시가 붙은 옛 번들 캐시 정리, 개발 서버(HMR)에서는 서비스 워커를 끄는 것을 정해야 한다.
  3. **지연 로딩 청크**: Firebase SDK는 동적 import라 별도 청크다. 오프라인 시작에서도 로그인 상태 복원과 동기화가 되려면 이 청크도 미리 캐시해야 한다(C2의 `started=false` 경로).
  4. **용량**: 포켓몬 데이터 JSON과 스프라이트 이미지를 얼마나 미리 캐시할지(개수·총 용량 실측). Cache Storage는 `localStorage`와 별개이고 브라우저가 용량 부족 때 비울 수 있다(5.5 G1의 `navigator.storage.persist()` 요청과 연결).
  5. **설치 가능성**: `manifest`(이름·아이콘 세트·`theme_color`·`display`)와 아이콘 이미지가 필요하다. iOS는 지원 범위가 제한적이다.
  6. **구현 방법**: 직접 작성 vs `vite-plugin-pwa`(새 의존성). 필요한 것이 "정적 파일 캐시 + 갱신 안내" 정도라면 직접 작성이 더 작을 수 있어 `ponytail`로 비교한다.
  7. **데이터 갱신**: 데이터 JSON이 바뀐 배포(밸런스 패치·샘플 추가)가 캐시 때문에 늦게 반영되지 않는지.
  8. **Preview 도메인**: Vercel Preview URL에서도 서비스 워커가 등록된다. 로그인은 `localhost`와 Production에서만 확인한다는 기존 결정을 따른다.
  9. **검증**: 브라우저가 필요하므로 사용자에게 위임한다(체크리스트 — DevTools Application 탭의 서비스 워커·Cache Storage, Offline 새로고침, 새 배포 후 갱신 안내, 로그인·동기화 회귀).
