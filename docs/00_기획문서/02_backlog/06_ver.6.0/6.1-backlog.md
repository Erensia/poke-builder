## 분기 — 집 PC 확인 결과
확인 절차는 `6.0-backlog.md` "집 PC 첫 로그인 절차"와 집 PC용 순서서(`firebase-환경설정-순서서.md.local`, git 밖). 항목: 집 PC 첫 로그인(백업 파일 → 주 계정 → 올라감) · 회사 PC에서 받기 · Production 주소 로그인 · 로그아웃 후 목록 유지 · 모바일 폭.

- **A. 문제가 나오면 → 6.1은 수정 버전**: 증상·원인·수정을 L0에 적고 고친다(로그인 실패, 동기화 오류, 데이터가 달라 보임 등). 범위는 그 문제로 한정하고, 리팩토링(B)은 같이 하지 않는다.
- **B. 문제가 없으면 → 6.1은 리팩토링 버전**: 아래 L1~L5를 사용자가 고른 만큼 한다.
