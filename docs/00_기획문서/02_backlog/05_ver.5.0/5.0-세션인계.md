## R3 랭크배틀용 AI — 시작 지점

### 요구(확정)
랭크배틀 전용 AI. 랭크별 성향·상대 샘플 차등을 포함한다. **경험치제 구간(몬스터볼~하이퍼볼)에는 연패 가중이 없는 대신, 연패가 반복되면 AI 수준을 낮추거나 상대 파티 조합을 일부러 쉽게 고르는 난이도 보정**을 둔다.
랭크 상태는 이미 `useRankBattle().save.state`(`gauge`·`rating`·`streak`·`lossStreak`·`champion`)와 `rankOf(state)`(볼·단계)로 읽을 수 있다.

### (설계 확정 전 메모 — 아래 두 절은 backlog가 우선) 사용자와 먼저 정할 것
1. 목표: 랭크가 오를수록 강해지는 곡선인지, 같은 강도에 연패 보정만 둘지.
2. 강해지는 수단: 성향(`riskAversion`) 분포 / 탐색 깊이·켜고 끄기 / 상대 모델·학습 / 강한 샘플 파티 선택.
3. 상대 파티: 샘플 파티에 강도 등급을 매겨 랭크·연패에 맞게 고를지.
4. 연패 보정: 몇 연패부터·몇 단계·연패가 끊기면 즉시 복구할지.
5. 검증 합격선: 기준 AI 대비 승률 몇 %로 "더 강해졌다 / 단계가 나뉜다"를 판단할지.

### 단순 시작안 (제안 — 미확정, 사용자가 안 정리해줘 하면 이걸로)
- **프리셋 3단**: 약 = 탐색 끔·상대 모델 끔·일부 `*Aware` 끔 / 중 = 탐색 끔(평가식만, 수십 ms) / 강 = 지금 앱 기본(`APP_DECISION_PARAMS` = 탐색 오라클 + 상대 모델). 몬스터볼=약, 슈퍼볼=약~중, 하이퍼볼=중, 마스터볼=강, 챔피언=강+상위 등급 파티.
- **샘플 35개 강도 등급**: `sim:ai`로 샘플끼리·기준 AI와 대결시켜 승률 순으로 상/중/하 등급(스크립트 신설) → 랭크별 상대 풀 가중.
- **연패 보정**: 연패 3 → 프리셋·파티 등급 한 단계 하향, 5 → 두 단계, 이기면 즉시 복구(경험치제 구간만).
- **검증**: `h2h` 모드로 프리셋 간 강약 순서와 격차 확인. 합격선은 사용자와 합의.
