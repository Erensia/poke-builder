## 착수 때 논의 정리 (2026-10-19)

**확정된 것** (2026-10-19 사용자 결정 — 규칙은 R1·R3 본문에 반영함)

- **순서**: R1 → R3. 기존 R2(랭크별 AI 성향 차등)는 **R3에 통합**했다. R1은 PR 3개(ⓐ 순수 함수+검증 스크립트 ⓑ `RankSave`·판 결과 연동 ⓒ 화면).
- 연승은 구간·단계가 바뀌어도 이어지고, 마스터볼 아래 구간의 연승이 마스터볼 첫 판 배율에 반영된다.
- 경험치제 구간에는 연패 가중이 없다(패배는 -1/4 고정). 대신 연패가 반복되면 AI 수준을 낮추거나 상대 파티를 쉬운 조합으로 고르는 **난이도 보정**이 있다(R3).
- 초기 레이팅의 승수 기준은 몬스터볼~하이퍼볼 전 구간 **누적 승수**. 레이팅은 **소수점 둘째 자리까지** 표기·저장한다.
- 경험치제 강등은 볼 경계를 넘는다(하이퍼볼 4에서 패배 → 슈퍼볼 1, 슈퍼볼 4에서 패배 → 몬스터볼 1). 몬스터볼 4의 게이지 0만 하한.
- 마스터볼의 이탈·무승부는 패배(-20, 연패 배율 적용). 엔진은 TOD 룰·턴 상한 무승부를 두지 않으므로 무승부는 실제로 발생하지 않는다.
- 랭크배틀 화면은 **기존 배틀타워 화면, 파티·선출 UI를 그대로 재사용**한다.

**남은 논의**

1. (확정됨 — 아래 R1 "마스터볼 진입" 참고) 1.1배는 (a) 합산 점수 전체에 곱하고, 연승 중이거나 승-패 ≥ 10일 때 적용한다.
2. 사이드 메뉴 "랭크배틀"은 **별도 사이드바 메뉴를 신설**하는 방향(사용자 구상, 2026-10-19) — 기존 배틀타워 화면·파티·선출 UI는 그대로 재사용. 파티·선출 데이터를 배틀타워와 공유할지, 재사용 컴포넌트에 랭크 모드를 어떻게 넘길지는 ⓒ 착수 때.
3. (확정) 이력은 최근 50판, 수동 초기화는 시즌 기록 저장 방식 — 세부(시즌 기록 필드의 예외 경우)는 R1 "저장·시즌" 참고.
4. 원형 게이지 방식 — 화면 기초(ⓒ)가 잡힌 뒤 정한다(사용자 결정). 랭크 아이콘은 `public/sprites/Rank/` PNG 5종 사용으로 확정.
5. 챔피언 달성 연출의 세부(방식·재달성 시) — 규칙(2500 이상, 미만이면 마스터볼 복귀, 달성 이력 유지)은 확정.
5. R3: 목표(더 강한 AI / 단계 난이도), 연패 보정 세부, 검증 합격선 — R3 "착수 때 논의할 것".

## ① 기능 작업

### R1 배틀타워 랭크배틀 시스템 (2026-10-19 사용자 요청, 4.1에서 5.0으로 이동)

기존 배틀 프런티어(연승·전적)와 **기능을 분리**한 별도 시스템이다. 랭크 전용 연승·연패 카운터와 저장(`RankSave`)을 따로 둔다.

#### 규칙 — 확정

**랭크 구성**: 몬스터볼 → 슈퍼볼 → 하이퍼볼 → 마스터볼 → **챔피언**(마스터볼 레이팅 2500 이상). 몬스터볼·슈퍼볼·하이퍼볼은 각각 **4~1의 4단계**(4가 가장 낮고 1이 가장 높다, 총 12단계 + 마스터볼 + 챔피언).

**몬스터볼~하이퍼볼 (경험치제)**

- 단계마다 게이지를 1로 보고, 1승에 **+1/4**(4승 승급), 1패에 **-1/4**.
- 연승 보너스: **2연승째부터** 한 판마다 기본 1/4 **대신** 1/2 상승(합산 3/4 아님).
- **승급은 초과분을 이월한다**: 예) 몬스터볼 1의 게이지 3/4에서 2연승째로 +1/2 → 합계 5/4 → 슈퍼볼 4에 게이지 1/4로 올라간다. 게이지를 하나의 연속 눈금으로 본다.
- **단계 강등 존재**: 게이지 0에서 패배하면 바로 아래 단계의 3/4로 내려간다(연속 눈금 기준). **볼 경계도 넘는다**(하이퍼볼 4 → 슈퍼볼 1, 슈퍼볼 4 → 몬스터볼 1). 몬스터볼 4의 게이지 0에서는 더 내려가지 않는다.
- **연패 가중 없음**: 패배는 연패 수와 무관하게 -1/4 고정. 연패가 반복될 때의 난이도 보정은 AI 쪽에서(R3).
- **연승은 이어진다**: 승급·강등 때 끊기지 않고, 마스터볼 진입 뒤 첫 판 연승 배율에도 반영된다(진입 승리까지 센 연승 수 + 1 번째 승리로 계산).

**마스터볼 진입**

- 하이퍼볼 1의 게이지가 전부 차면 마스터볼로 올라가며 **초기 레이팅이 산정**된다.
- 초기 레이팅 = (기본 1300 + 몬스터볼~하이퍼볼 전 구간 **누적 승수 × 2점**) × **연승 보너스 1.1배(조건부)**. 소수점 둘째 자리까지.
- **1.1배는 합산 점수 전체에 곱한다 — (a)안 확정(2026-10-19)**. 적용 조건은 둘 중 하나라도 맞을 때:
  1. 마스터볼 승급 시점에 **연승 중**(승급 승리를 포함해 **2연승 이상**; 승급은 항상 승리로 이뤄지므로 1연승만으로는 조건이 되지 않는다고 해석 — 연승 배율이 2연승부터인 것과 같은 기준).
  2. 연승 중이 아니더라도 몬스터볼~하이퍼볼 전 구간 누적 **승수 − 패수 ≥ 10**(이탈 패배도 패수에 포함).
  둘 다 아니면 1.1배 없이 (1300 + 2×승수)이다.

  | 방식 | 식 | W=25 | W=40 | W=60 | W=100 |
  |---|---|---|---|---|---|
  | (a) 합산 점수 전체 | (1300+2W)×1.1 | 1485.00 | 1518.00 | 1562.00 | 1650.00 |
  | (b) 추가 점수에만 | 1300+2W×1.1 | 1355.00 | 1388.00 | 1432.00 | 1520.00 |
  | 보너스 없음(참고) | 1300+2W | 1350.00 | 1380.00 | 1420.00 | 1500.00 |

  (a)−(b)는 승수와 무관하게 항상 **130.00**(= 1300×0.1). (b)의 보너스는 W=40에서 +8점에 불과해 사실상 무의미하고, (a)는 +130점의 고정 보상이다. W=25는 연승만으로 올라간 최소 승수(1/4 + 24×1/2 ≥ 12).

  **가계산 (2026-10-19, 누적 30승 · 7연승으로 진입, (a)안 확정)**: 보너스 없음 1360.00 / (a) (1300+60)×1.1 = **1496.00** / (b, 폐기) 1300+60×1.1 = 1366.00. 위 비교표는 (a)/(b) 선택 근거로만 남긴다.

**마스터볼 (레이팅제)**

- 승리 시 기본 **+20**, 패배 시 기본 **-20**. **강등은 없고(하이퍼볼로 내려가지 않는다) 레이팅 하한은 0**. 레이팅은 **소수점 둘째 자리까지** 저장·표기한다.
- 승리일 때의 **턴 수 보정**(선형, **승리에만 적용** — 패배는 턴 수와 무관하게 기본 -20):
  - 30턴 이하는 1턴 빠를 때마다 **+1**(20턴 이하에서 **최대 +10**).
  - 40턴 초과는 1턴 늦을 때마다 **-1**(50턴 이상에서 **최대 -10**).
  - 31~40턴은 보정 없음.
  - 턴 수는 **판이 끝난 시점의 턴 번호**(교체·강제 교체 턴 포함)를 쓴다.
- **연승·연패 배율**: 2연승부터 승리 점수 ×1.1, 3연승 ×1.2, 4연승 ×1.3, 5연승 ×1.4 … 계속 상승(상한 없음). 2연패부터 차감 레이팅 ×1.1, 3연패 ×1.2, 4연패 ×1.3 … 계속 상승(상한 없음).
- **계산 순서**: (기본 20 ± 턴 보정) × 연승·연패 배율, 마지막에 **소수점 둘째 자리로 반올림**(부동소수 오차를 막으려고 매 판 `Math.round(x*100)/100`).

**챔피언 (마스터볼 상위, 2026-10-19 사용자 추가)**

- 마스터볼에서 레이팅이 **2500점 이상**이면(2500.00 포함) 신규 랭크 **챔피언**이다. 마스터볼의 최상위 등급이다(2026-10-19 "초과"에서 "이상"으로 확정).
- **챔피언은 마스터볼과 같은 레이팅제**를 그대로 쓴다. 레이팅이 2500 미만으로 내려가면 **마스터볼로 돌아가고**, **챔피언 달성 이력은 남긴다**(`RankSave`에 달성 여부·최초 달성 시점·최고 레이팅을 따로 기록).
- **달성 연출**을 넣는다(2026-10-19 사용자 선호). 최초 달성과 재달성 때 같은 연출을 쓸지, 방식(모달/배너)은 화면(ⓒ)에서 정한다.
- 아이콘은 사용자가 넣은 `public/sprites/Rank/` PNG 5종(`Champs_{Poké,Great,Ultra,Master}_Ball_Tier_Icon.png`, `Champs_Champion_Tier_Icon.png`)을 **그대로 사용**한다(확정, 인라인 SVG 안은 폐기).

**연승·연패 정의**

- 랭크 전용으로 따로 센다(프런티어의 `streak`와 별개).
- 이탈(새로고침·창 닫기)은 **패배로 처리**하며 **연패에도 포함**된다(경험치제 구간 -1/4, 마스터볼 -20×연패 배율). 무승부는 엔진에 TOD 룰·턴 상한이 없어 발생하지 않는다(발생하면 패배와 같게 처리). AI전이라 턴 상한 무승부는 형평성이 낮다고 보고 두지 않는다(2026-10-19 결정).

**저장·시즌**: 별도 `RankSave` 타입을 신설한다(프런티어 `FrontierSave`와 분리).
- 저장 키는 `localStorage['champions-party-sim.battle-rank.v1']` — `lib/storage.ts`의 다른 키(`...battle-frontier.v1` 등)와 같은 형식의 별도 키.
- **이력 = 랭크 판마다 한 줄**(날짜 · 상대 샘플 · 승/패/이탈 · 턴 수 · 게이지·레이팅 변화와 계산 내역), **최근 50판만 보관**(확정, 2026-10-19). 랭크 프로필 화면에서 볼 수 있다.
- **수동 초기화 = 시즌 기록 저장 후 초기화**(확정, 2026-10-19). 랭크 화면의 "랭크 초기화" 버튼 + 확인(앱 안 모달 — 네이티브 `confirm`은 자동화에서 탭이 멈추므로 쓰지 않는다). 초기화 직전 상태를 **N시즌**(1시즌, 2시즌 …)으로 저장하고 랭크는 몬스터볼 4·게이지 0, 연승·연패 0, 이력 비움으로 되돌린다. 시즌 기록에 담는 것:
  - **초기화 직전 레이팅**(마스터볼 이상일 때) — 마스터볼 미도달이면 레이팅이 없으므로 **도달한 볼·단계**를 저장(기본안).
  - **시즌 중 최대 레이팅**.
  - **챔피언 달성 여부**: 달성했다면 달성 사실을 남기고, 달성하지 못했다면 최대 레이팅만 표시한다.
  - **초기화 직전 사용한 파티**(랭크 판에서 마지막으로 쓴 파티의 스냅숏).
  - **승리한 수**(그 시즌 랭크 판 전체 승수, 경험치제 구간 포함).
  - 랭크 프로필 화면에서 **시즌별 기록 목록**을 볼 수 있다. 이전에 정한 "챔피언 달성 이력은 초기화에서 지우는가" 문제는 시즌 기록이 이력을 보존하므로 해소된다.
- 기간별 자동 초기화는 두지 않는다(서버 없이 기기 시계에 의존). 시즌은 사용자가 초기화를 누를 때만 넘어간다.

**표시**: 랭크 아이콘(`public/sprites/Rank/` PNG 5종 그대로) · 게이지 막대(**원형**) · 승패 직후 계산 내역 반영 · **이력 저장**. 원형 게이지는 화면 기초(ⓒ)가 잡힌 뒤 정한다. 기본안: SVG `stroke-dasharray`(CSS `conic-gradient`도 가능).

**UI(개발안 추가)**: **사이드 메뉴에 "랭크배틀" 추가**. 랭크 프로필 · 랭크 배틀 시작 · 파티 편성 등의 화면 구성은 **기존 배틀타워 화면과 파티·선출 UI를 그대로 재사용**한다(2026-10-19 결정). 사이드 메뉴 항목과 배틀타워 화면의 연결 방식은 착수 때 논의.

#### 기존 코드 현황(2026-10-19 확인)

- 화면 이름은 "배틀타워"(`BattleLogPage.tsx`), 코드 이름은 "배틀 프런티어". 이미 있는 것: 연승(`streak`)·최대 연승(`best`)·샘플별 전적·상대 대기열·이탈=패배 정산(`lib/battleSeries.ts`, `hooks/useBattleSeries.ts`), 저장은 `localStorage['champions-party-sim.battle-frontier.v1']`(`lib/storage.ts`의 `createLocalStorageStore` 팩토리). 랭크배틀은 이것과 기능을 분리하되 **저장 팩토리·이탈 정산 방식은 재사용**할 수 있다.
- 상대는 샘플 파티 무작위 순서의 AI이고 AI 성향(`riskAversion`)은 판마다 `sampleRiskAversion()`으로 새로 뽑는다. 무승부는 지금 패배로 처리한다.

### R3 랭크배틀용 AI 개발 (R1 뒤, 구 R2 랭크별 AI 성향 차등 통합 — 2026-10-19 사용자 결정)

랭크배틀에서 맞붙는 상대 AI를 **랭크배틀 전용으로 개발**하는 작업이다. 기존 R2(랭크에 따라 `riskAversion` 분포·상대 샘플 선택을 차등)는 이 항목에 **통합**했다. 지금 배틀타워의 상대는 샘플 파티 + 판마다 `sampleRiskAversion()`(U(0,1))으로 뽑은 성향의 범용 AI(`chooseAiAction`)다.

R1은 랭크 상태(볼·단계·레이팅·연승·연패)를 AI 설정 쪽에서 읽을 수 있는 형태로 노출해 둔다. AI 판단을 바꾸므로 `sim:ai regress`·`test:ai` 해시가 바뀐다 — 의도한 변화인지 확인하고 기준값을 다시 기록한다.

#### 확정된 요구

- **연패 난이도 보정**: 경험치제 구간(몬스터볼~하이퍼볼)에는 연패 가중이 없는 대신, 연패가 반복되면 AI 수준을 낮추거나 상대 파티 조합을 일부러 쉽게 고르는 추가 난이도 조정을 둔다(2026-10-19).

#### 착수 때 논의할 것

1. "랭크배틀용 AI"의 목표 — 더 강한 AI인지, 랭크 구간별로 단계 난이도가 있는 AI인지(통합했으므로 둘 다일 가능성이 큼).
2. 개발 범위 — 기존 `lib/battle/ai/`(평가식 `evaluator`·결정 `decision`·탐색 `search`·상대 모델·`teamSelect` 선출)에서 **무엇을 켜고 무엇을 새로 만들지**. 랭크 전용 `DecisionParams` 프리셋만으로 되는지, 새 로직이 필요한지.
3. 상대 파티 구성 — 랭크·레이팅에 맞는 파티를 고르는 기준(샘플 파티에 강도 등급을 매길지). 연패 시 쉬운 조합을 고르는 기준도 여기서 정한다(파티 풀 신설은 `SP` 샘플 추가와 별개).
4. 연패 보정 세부 — 몇 연패부터, 단계적으로 얼마나(`riskAversion` 분포 이동 / 탐색 끄기 / 쉬운 파티), 연패가 끊기면 즉시 복구할지.
5. 성능 — 탐색 AI는 `aiWorker`를 쓴다. 랭크 판에서 대기 시간 상한(모바일 포함).
6. 검증 — `test:ai`·`sim:ai regress` 해시가 바뀐다. 기준 AI 대비 승률(`sim:ai` 모드)로 "더 강해졌다/단계가 나뉜다"를 수치로 확인하는 방법과 합격선. 기준값 재기록은 의도한 변화로 확인한 뒤.
7. 배틀 사이의 학습 — 상대 패턴 학습(`opponentMemory`)을 랭크 판에서 쓸지(판 간 누적 허용 여부).

#### 구현 방향(안)

R1 ⓑ(랭크 상태 노출)가 들어간 뒤 시작한다. 상세 설계는 목표(논의 1번)가 정해진 뒤 이 절에 채운다.
