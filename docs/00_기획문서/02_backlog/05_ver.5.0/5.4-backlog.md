### E3 `fixedPicks` 앱 연동 (UI) — **완료**(2026-10-27, PR #343, `dev`)
- **결과**: 샘플을 불러온 진영의 `fixedPicks`를 `useBattleSetup`이 기억하고, 선출 화면에 들어갈 때(`handleProceed`) 현재 빌드 슬롯과 종 id로 대조해 초기 선택을 채운다. 빠지거나 기술이 없어진 마리는 건너뛰고 사용자는 평소처럼 해제·변경할 수 있다. 고정선출 마리 카드에는 "고정선출" 칩을 붙인다(상대 AI 편은 선출 비공개라 칩 숨김). 다른 파티 프리셋·슬롯 조합을 불러오면 기억을 비운다. `tsc -b`·`build`·`validate:data`·`test:sample` 통과, 엔진 변경 없음.
- **UI 결정 과정(사용자 화면 확인)**: ① 처음엔 컬럼 제목 아래 안내 줄("샘플의 고정 선출을 미리 골랐어요")을 뒀으나 PC에서 컬럼 폭이 커져 가로 배치가 세로로 접히고, 줄을 옮기면 두 컬럼 카드 높이가 어긋났다 → 안내 줄을 없애고 카드별 칩으로 교체. ② 칩 문구는 "고정"만으로는 뜻이 안 통해 데이터·문서 용어인 **"고정선출"**로. ③ 카드 폭을 264px 고정으로 넓혀도 긴 이름이 두 줄이 됐다(가장 긴 이름이 "켄타로스(팔데아/블레이즈종)" 15글자) → **PC에서는 컬럼 폭을 `max-content`로 내용에 맞추고 이름은 줄바꿈 금지, 모바일만 줄바꿈 허용**.
- **한계**: 컬럼 폭이 내용에 따라 달라져 한쪽에만 긴 이름이 있으면 좌우 컬럼 폭이 조금 다르다(양쪽을 같은 폭으로 맞추려면 grid 구조 변경 필요). 앱 AI(상대 편)가 샘플의 `fixedPicks`를 선출에 쓰는 것은 이번 범위가 아니다(시뮬레이터·벤치는 이미 쓴다).
- (아래는 확정 당시 계획)
- **문제**: 샘플을 불러올 때 선출 화면에 `fixedPicks`를 미리 채우는 기능이 없다. `real-m4-rank3`·`real-mb-late-dragonite` 등은 `fixedPicks` 미지정이고, 별도 UI가 필요해 5.2·5.3에서 보류했다.

- **결정(2026-10-27 사용자)**: ① 미리 채우되 사용자가 해제·변경할 수 있다 ② 기초샘플 8개에는 `fixedPicks`를 지정하지 않는다(데이터 변경 없음 — 기존 심화 샘플의 `fixedPicks`만 연동).
