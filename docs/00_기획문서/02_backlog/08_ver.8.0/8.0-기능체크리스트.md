# ver.8.0 일괄 기능 체크리스트 (F1)

**수행: 사용자.** 8.0은 동작 불변 리팩토링이라, 이 문서는 "리팩토링 뒤에도 전 화면이 예전과 같은가"를 한 번에 도는 점검이다. 4.0·4.1부터 미뤄 온 **모바일 실기기·761~890px 폭·스크린리더** 점검을 함께 푼다. 항목이 어긋나면 어떤 화면에서 무엇이 달랐는지만 알려 주면 된다.

- 준비: `main`(배포본)과 비교할 수 있게 [poke-builder-two.vercel.app](https://poke-builder-two.vercel.app/)(7.7)과 로컬 `npm run dev`(8.0) 두 창을 나란히 둔다. 비교 대상이 없는 항목은 "정상 동작"만 본다.
- **지우지 말 것**: `localStorage`의 `champions-party-sim.party.v1`(편집 중인 파티)과 `...party-presets.v1`.
- 이번에 코드가 바뀐 곳은 ★로 표시했다(배틀 화면 연출·AI·CSS, 추론 모듈, 상성표).

## 4. ★ 배틀타워 (자유 대전)

- [x] AI 상대 켬: 턴을 누르면 계산 중 표시가 뜨고 AI가 기술·교체·메가진화를 고른다.

- [x] 연출: 타격 흔들림·%팝업, 교체 모션, 메가진화(고리·폼 변경), 기절(먼지)·마지막 기절의 판 흔들림과 결과 배너, 날씨·필드 물결과 배경 입자, 설치물 조각, 상태이상 입자, 보호막, 달빛·희망사항, 회복·랭크 변화 팝업.

- [x] 계산 중 "초기화"를 눌러도 늦게 온 AI 답이 반영되지 않는다. 대전 종료 후 AI 학습 표시("N판 학습")와 AI 기억 창.

## 결과 기록
점검 후 어긋난 항목이 있으면 아래에 화면·상황·기대와 실제를 적는다(없으면 "이상 없음").

**수행: 2026-11-10 (사용자).** 8개 절 중 3개 항목을 빼고 모두 통과했다. 리팩토링(동작 불변)이 만든 어긋남은 보고되지 않았다. 아래 3건은 8.0 변경이 아니라 기존 동작·설계에 대한 의견이며 8.1 후보(U6~U8)로 올렸다(`8.0-backlog.md` "8.1 후보").

- **§1 능력 포인트 슬라이더 반응이 느린 듯함 → U6.** 코드 확인: 채움 막대 `transition: width 0.08s linear`(`PointsEditorModal.css:129`)는 지연이 작다. 더 유력한 후보는 드래그 중 `pointermove`마다 파티 상태가 바뀌고 `useParty`가 매번 `saveParty`로 `localStorage`에 동기 저장하는 구조(`useParty.ts:21`)다. 확정 전 — 7.7(배포본)과 로컬 8.0에서 같이 느린지로 8.0 변경 여부를 먼저 가른다.
- **§1 파티 프리셋 불러오기 때 달라진 슬롯만 모션 → U7.** 코드 확인: 의도된 동작이다. `usePop`(`src/hooks/usePop.ts`, 6.5 M1 D)이 슬롯의 포켓몬 ID를 이전 값과 비교해 바뀐 카드에만 `card-pop`을 붙인다. 6칸 전부 모션으로 바꿀지는 사용자 결정.
- **§7 모바일 실기기(≤760px) 미체크 → U8.** "세로 배치를 더 고민해야 함" 의견. 하단 탭·터치 영역·연출 잘림은 이 점검에서 판정하지 않았다(U1·U3이 이어 받는다).
- 나머지 §1~§8 항목(상성표·계산 4탭·도감·배틀타워 연출·AI·랭크·백업·761~890px·스크린리더·동작 줄이기·테마·PWA)은 이상 없음.
