# ver.8.0 일괄 기능 체크리스트 (F1)

**수행: 사용자.** 8.0은 동작 불변 리팩토링이라, 이 문서는 "리팩토링 뒤에도 전 화면이 예전과 같은가"를 한 번에 도는 점검이다. 4.0·4.1부터 미뤄 온 **모바일 실기기·761~890px 폭·스크린리더** 점검을 함께 푼다. 항목이 어긋나면 어떤 화면에서 무엇이 달랐는지만 알려 주면 된다.

- 준비: `main`(배포본)과 비교할 수 있게 [poke-builder-two.vercel.app](https://poke-builder-two.vercel.app/)(7.7)과 로컬 `npm run dev`(8.0) 두 창을 나란히 둔다. 비교 대상이 없는 항목은 "정상 동작"만 본다.
- **지우지 말 것**: `localStorage`의 `champions-party-sim.party.v1`(편집 중인 파티)과 `...party-presets.v1`.
- 이번에 코드가 바뀐 곳은 ★로 표시했다(배틀 화면 연출·AI·CSS, 추론 모듈, 상성표).

## 1. 파티 편성
- [ ] 포켓몬 6슬롯 선택·해제, 기술 4개·특성·도구 배치, 성격·능력 포인트 슬라이더.
- [ ] 드래그앤드롭 순서 변경, 파티 프리셋 저장·불러오기, 슬롯 프리셋 저장·불러오기.
- [ ] 샘플 파티 불러오기(64개 목록이 뜨는지), 랜덤 파티.
- [ ] ★ 타입 상성표(방어/공격): 두 표가 접힌 상태로 시작하고 눌러 펼쳐진다. 폼 라벨이 있는 포켓몬(메가 등)은 "메가"로 줄어 표시된다. 두 표의 표기가 서로 같은 규칙이다.

## 2. 계산 기능 4탭 (탭끼리 포켓몬·날씨·필드 공유, 새로고침 뒤 복원)
- [ ] 결정력 계산: 랭크·날씨·필드·스크린·특성·다단히트 반영, 확정 1타~3타 판정, 16단계 난수 펼치기. 자리 바꾸기(드래그).
- [ ] ★ 노력치 역산(상대 방어·특방): 관측 1~3개 입력 → 능력 포인트·성격 범위가 좁혀진다. 관측이 서로 모순이면 "어느 관측을 빼면 풀리는지" 표시. 단독 관측별 가능 여부 표시.
- [ ] ★ 노력치 역산(상대 공격·특공): 같은 흐름. 스피드 역산(선후공 관측)도 같은 흐름.
- [ ] 스피드 조정 표, 내구 조정 표(HP 눈금 16n+15 등).

## 3. 도감
- [ ] 포켓몬 도감(전국도감 순, 폼 탭 전환), 기술표(카드형), 도구 도감. 검색·정렬.

## 4. ★ 배틀타워 (자유 대전)
- [ ] 셋업 → 선출(3마리, 순서) → 대전 진행이 한 흐름으로 이어진다. 양쪽 편이 서로를 향해 들어오는 전환 모션.
- [ ] AI 상대 켬: 턴을 누르면 계산 중 표시가 뜨고 AI가 기술·교체·메가진화를 고른다.
- [ ] AI 포켓몬이 기절하면 알아서 교체한다. 유턴·볼트체인지를 AI가 쓰면 교대를 자동으로 고른다. 양쪽 동시 기절 시 순서가 맞다.
- [ ] 연출: 타격 흔들림·%팝업, 교체 모션, 메가진화(고리·폼 변경), 기절(먼지)·마지막 기절의 판 흔들림과 결과 배너, 날씨·필드 물결과 배경 입자, 설치물 조각, 상태이상 입자, 보호막, 달빛·희망사항, 회복·랭크 변화 팝업.
- [ ] 연출 중 다음 턴을 눌러도 순서대로 재생된다. OS의 "동작 줄이기"를 켜면 연출 없이 즉시 표시된다.
- [ ] 계산 중 "초기화"를 눌러도 늦게 온 AI 답이 반영되지 않는다. 대전 종료 후 AI 학습 표시("N판 학습")와 AI 기억 창.
- [ ] 배틀비디오 저장·목록·다시보기(다시보기는 연출 없음이 정상). 구애스카프·도발 등 잠금 경고.
- [ ] 프런티어(연속 대전): 시작·연승·판마다 AI 편 지정.

## 5. ★ 랭크배틀
- [ ] 상대가 AI·샘플 파티로 자동 고정, 단계(몬스터볼~하이퍼볼~마스터볼) 표시, 판 끝난 뒤 게이지·레이팅 반영.
- [ ] 대전 중 하단 탭·새로고침·이탈 시 확인이 뜬다(코드 리뷰만 했던 항목 — 새로고침 막기를 직접 확인).

## 6. 백업·클라우드
- [ ] JSON 내보내기·가져오기. (로그인을 쓴다면) Google 로그인 → 파티·빌드 동기화, 두 기기 병합.

## 7. 반응형·접근성 (4.0·4.1부터 미룬 점검)
- [ ] **761~890px 폭**(브라우저 폭 조절): 결정력 계산·배틀 셋업 보드가 넘쳐 잘리지 않는다(7.5 수정 확인). 920px 이상에서는 가로 배치, 미만은 쌓인다.
- [ ] **모바일 실기기**(≤760px): 하단 탭 네비 5개, 파티·계산·배틀·랭크·도감 시트, 터치 영역(알약·pip이 누르기 어렵지 않은지), 세로 배치와 연출이 잘리지 않는지.
- [ ] **스크린리더**(NVDA 또는 VoiceOver): 파티 편성·상성표 접기/펼치기 버튼, 배틀 로그 읽기, 모달 포커스 이동.
- [ ] `--reduced-transition` 0.08s 느낌(동작 줄이기에서 화면 전환이 어색하지 않은가).
- [ ] 다크/라이트 테마 전환.
