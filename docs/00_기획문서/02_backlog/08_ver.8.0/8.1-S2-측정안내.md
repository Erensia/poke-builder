# ver.8.1 S2 — 사다리·선출 약화 측정 안내 (집 PC)

**작성 2026-11-10 — 측정은 사용자가 집 PC에서 한다. 이 문서는 명령과 기록 양식이다.** 8.3의 챔피언 AI·사다리 작업은 여기서 얻은 **숫자에서 출발**한다. 이 측정은 **숫자만 기록**하면 되고 코드를 바꾸지 않으므로 AI 작업이 아니다(`CLAUDE.md` "버전 구성", x.1·x.2에서도 가능).

## 전제
- **집 PC에서만** 돌린다. 회사 PC(RAM 8GB)에서는 병렬 측정이 메모리 부족으로 종료된다.
- 프로세스 하나가 약 **500MB**다. `--jobs`는 `코어 수`와 `남는 RAM ÷ 500MB` 중 작은 값으로 잡는다.
- **측정 중에는 `src/`를 바꾸지 않는다**(프로세스가 모듈을 읽는다). `git pull`도 하지 않는다.
- Windows 하이브리드 CPU에서 사용률이 25% 안팎에 머물면 효율 코어에 갇힌 것이다 — 측정 중에 `scripts/win-unthrottle.ps1`을 **다른 창에서** 실행한다.
- PowerShell에서 JSON 인자는 따옴표를 이스케이프한다: `'{\"kind\":\"random\"}'`. Git Bash에서는 그대로 `'{"kind":"random"}'`.

## 먼저 스모크로 시간을 잰다 (각 측정 전)
이전 기록에 집 PC의 사다리 소요 시간이 없다. 아래 한 줄이 **약 10분 안**에 끝나는지 보고, 본 측정 시간을 가늠한다.
```
node scripts/rank-ladder.mjs 2 --rungs 0,1,2 --chunk 2 --jobs 1
```

## M1. 사다리 P3~P7 인접 간격 (선출 포함)
```
SELECT=1 node scripts/rank-ladder.mjs 300 --rungs 3,4,5,6,7 --chunk 25 --jobs 4
```
- `SELECT=1`: 3선출 포함(6.3 A2와 같은 조건). 환경변수 형식은 셸에 맞춘다(PowerShell: `$env:SELECT=1; node …`).
- 인접 쌍 **P4/P3 · P5/P4 · P6/P5 · P7/P6**의 승률(무승부 제외)이 나온다. 이 러너는 **학습 없이** 잰다 — 학습 단계(3~5)의 λ 차이는 상대 모델과 대전 간 누적이 있어야 드러나므로 M2가 따로 필요하다.
- 끝점 연속성을 보고 싶으면 기존 구간도 한 번: `SELECT=1 node scripts/rank-ladder.mjs 300 --rungs 0,1,2,3,6 --chunk 25 --jobs 4`

## M2. 학습 단계(P4·P5) 강도 — 대전 간 학습 켜기
학습은 **한 프로세스 안에서 이어져야** 하므로 조각(`--chunk`)으로 나누지 않고 단일 프로세스로 돌린다.
```
LEARN=1 npm run sim:ai -- h2h 300 rank:4 rank:3
LEARN=1 npm run sim:ai -- h2h 300 rank:5 rank:4
LEARN=1 npm run sim:ai -- h2h 300 rank:6 rank:5
```
- 출력 JSON의 승패와 `learned`(누적 대전 수·교체/변화기 보정 배율)를 기록한다. 한 번에 약 500MB 프로세스 하나라 세 줄을 **동시에** 띄워도 된다(RAM 여유 시).
- **`riskAversion` 고정 조건**: 하네스(`battle-ai-sim.mjs`)에 이 값을 고정하는 옵션이 **지금은 없다**(판마다 시드에서 나온다). 고정 조건 측정은 8.3 착수 때 **하네스 옵션 추가**와 함께 설계한다 — 이번에는 위 M2 숫자만 기록한다.

## M3. 3선출 약화 조건(`selectvs`)
같은 파티 두 개를 두고 A·B가 각각 양쪽 선출을 맡아 좌우·파티를 바꿔 **시드당 4판**을 돈다(대전은 양쪽 같은 AI). **인자는 두 개** — 판 수 뒤에 A 선출 옵션, B 선출 옵션 순서다(`{}` = 기본 AI 선출, `{"kind":"random"}` 무작위, `{"kind":"first"}` 앞 3마리, `{"kind":"fixed"}` 샘플의 고정 선출; 하네스 코드로 확인). 스모크로 한 번 확인해도 좋다(`… selectvs 2 …`).
```
# AI 선출 대 무작위 선출
POOL=samples npm run sim:ai -- selectvs 100 '{}' '{"kind":"random"}'
# AI 선출 대 앞 3마리 고정(가장 약한 선출)
POOL=samples npm run sim:ai -- selectvs 100 '{}' '{"kind":"first"}'
# 고정 선출(fixedPicks)이 있는 샘플 파티만: 고정 선출 대 AI 선출
POOL=picks npm run sim:ai -- selectvs 100 '{"kind":"fixed"}' '{}'
```
- 기록할 것: A 승률, 무승부 제외 승/패, 판 수. "선출을 약하게 하면 승률이 얼마나 떨어지나"가 8.3의 **샘플 상대 선출 약화 조건**의 출발점이다.
