# ver.8.0 백로그

**초안(2026-11-09) — 8.x 메이저의 시작. 범위는 사용자가 항목마다 확정한다.** 8.0은 **코드 전체 리팩토링 버전**이다(`CLAUDE.md` "버전 구성": 메이저 = `ponytail` 스킬로 코드 전체 리팩토링 → 엔진 로직 테스트·기능 테스트). **사용자 결정(2026-11-09)**: ① 8.3(AI·엔진 전용) 전에 미리 해 둘 수 있는 작업은 8.0~8.2로 쪼개서 한다 ② 7.x뿐 아니라 그동안 **제외 확정하지 않은 한계 전부**를 총망라해, 작업이 필요한 것은 일단 8.0~8.2에서 해 본다. 이전 메이저 마무리: `../07_ver.7.0/7.7-backlog.md`.
