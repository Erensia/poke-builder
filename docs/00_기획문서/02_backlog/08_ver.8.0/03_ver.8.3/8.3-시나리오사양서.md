# ver.8.3 시나리오 사양서 (8.2 T3)

**작성 2026-11-10 — 문서만이다. 코드는 8.3에서 쓴다**(지금 `scripts/battle-ai-scenarios/`에 넣으면 현재 동작과 충돌해 실패한다). 근거는 `8.3-규칙조사.md`의 "확정" 칸(2026-11-10 사용자 답). 시나리오는 `scripts/battle-ai-scenarios/NN-*.mjs` 섹션 형식(`mon`·`est` 헬퍼, 결과 표에 `true/false`)으로 추가한다. 항목마다 **입력 상태 → 기대 결과**를 적고, "지금 동작"은 8.3 착수 전 실패를 확인하는 용도다.

## R1 돌림노래
| # | 입력 | 기대 | 지금 동작 |
|---|---|---|---|
| R1-a | 한 턴에 A가 돌림노래 → B가 돌림노래 | B의 위력 **120**(2배), A는 60 | B도 60 |
| R1-b | 연속 두 턴에 A만 돌림노래(상대는 안 씀) | 두 턴 모두 **60**(연속 사용 보너스 없음) | 2턴째 120 |
| R1-c | A·B 둘 다 돌림노래, B가 먼저 행동(스피드) | 뒤에 쓴 A가 120 | — |
| R1-d | 행동 순서 | 우선도 0 그대로, 순서는 변하지 않음 | 확인용 |

## R2 사이코노이즈 회복봉인
| # | 입력 | 기대 |
|---|---|---|
| R2-a | 봉인 중 나무열매(오랭 등) 발동 조건 충족 | 열매가 **소비되지 않고** 회복 없음 |
| R2-b | 봉인 중 조개껍질방울·먹다남은음식·기가드레인 등 흡수 기술 | 회복 0(흡수 기술은 데미지만) |
| R2-c | 봉인 중 사이코노이즈 재사용 | **데미지는 들어가고** 남은 봉인 턴수는 갱신되지 않음 |
| R2-d | AI: 상대가 회복 기술 보유 | 사이코노이즈 점수 상승(회복 의존 상대) |

| # | 입력 | 기대 |
|---|---|---|
| R3-a | 쓴 뒤 칼춤·교체로 능력치 변화, 2턴 뒤 적중 | **맞는 시점의 스탯**으로 계산 |

## R6 턴 종료 순서
| # | 입력 | 기대 |
|---|---|---|
| R6-a | 희망사항을 쓴 다음 턴, 먹다남은음식 보유 | 희망사항 회복이 먼저 → 먹다남은음식 |
| R6-b | 희망사항 시점에 HP가 가득 | 회복 0이어도 로그 "희망사항이 이루어졌지만 회복할 HP가 없었다" 한 줄 |
| R6-c | 날씨 종료와 날씨 대미지 | 종료 확인 → 날씨 대미지·특성 → 희망사항/미래예지 → 개별 효과 → 상태이상 틱 |
| R6-d | 희망사항·미래예지가 같은 턴 대기 | 설치된 순서대로 |

## R7 방어류·길동무
| # | 입력 | 기대 |
|---|---|---|
| R7-a | 길동무 성공 다음 턴 길동무 | 100% 실패, `protectStreak` 불변 |
| R7-b | 방어 성공 후 길동무 | 길동무 확률은 영향받지 않음(방어 카운터와 분리) |
| R7-c | 패스트가드·와이드가드 연속 사용 | 자신은 항상 성공, 다음 방어·판별 확률은 1/3로 감소 |
| R7-d | 버티기를 그 턴 마지막에 사용 | 기술 **성공**, 다음 턴 연속 사용 실패 확률만 증가(방어·판별·킹실드의 "마지막이면 실패"와 다름) |
| R7-e | AI `protectSuccessChance` | 위 규칙과 일치 |

## 순서와 기준값
1. R6(턴 종료 순서)만 한 PR에서 먼저 → `update-baseline.sh`로 `verify-kit` 기준값 갱신(해시 변화의 원인을 순서 하나로 분리).
2. R1·R2·R3·R7·R8을 항목별 PR로. 각 PR에서 해당 시나리오가 **먼저 실패 → 수정 후 통과**하는 것을 확인하고 기준값을 다시 갱신한다.
3. 마지막에 집 PC에서 `verify.sh` 전체 통과.
