## 2. 영향 범위 (구현 전에 알아 둘 것)

접촉 여부는 아래를 바꾼다. 데이터만 바꿔도 해시가 변할 수 있는 이유다.

**읽는 기준(검수 §2-0, 엔진 확인 완료)**: 지구던지기는 고정 데미지라 `hitResolution.ts` `resolveMainHit`의 `fixedDamage` 분기(713행)에서 특성·도구·방어·랭크 보정 없이 수치가 그대로 들어간다(Showdown `getDamage`가 `damage === 'level'`에서 곧바로 반환하는 것과 같다). 그래서 **위력·데미지 보정형**(단단한발톱·복슬복슬·파동의방호, 방어 관통 ×0.25 — `hitResolution.ts:298` 주석이 "일격기·고정 데미지는 이 클로저를 거치지 않는다"고 적고 있다)은 지구던지기에 적용되지 않고, **명중 후 반응형**(까칠한피부·울퉁불퉁멧·방어류 접촉 반응 등)은 데미지 계산과 무관하게 실행되므로 적용된다. 엔진이 이미 이렇게 되어 있어 **엔진 코드 변경은 없다**(검수가 우려한 "지구던지기가 절반이 되는 새 오차" 없음 — 시험으로 고정한다).

| 영역 | 바뀌는 동작 |
|---|---|
| 접촉 반응 특성(까칠한피부·정전기·불꽃몸·독가시·미라·미끈미끈 등 설명문에 "접촉"이 든 특성 18종) | 불새·트림·대격분·바늘미사일은 **반응이 없어지고**, 지구던지기는 **반응이 생긴다** |
| 울퉁불퉁멧(도구) | 같음 |
| 원격(`movesIgnoreContact`) | 지구던지기가 접촉이 되면 원격 보유자에게는 접촉 반응이 없는 쪽으로 처리됨 |
| **관통드릴·보이지않는주먹** | 접촉기만 방어류를 뚫는다 → **불새·대격분·바늘미사일·트림은 이제 방어에 막히고**, **지구던지기는 뚫는다**. 뚫은 지구던지기의 데미지는 **50 그대로(×0.25 없음)** — B9 확정 규칙(일격기·고정 데미지는 ×0.25 제외)이고 Showdown도 같다. 뚫었을 때 방어류 접촉 반응은 B9 확정대로 발동(Showdown은 미발동, 의도적 차이). **실전 조합 없음**(관통드릴은 메가몰드류, 보이지않는주먹은 메가골루그뿐이고 이 5개 기술을 배우지 않는다) → §5의 관통·원격 시험은 특성을 강제로 붙인 시험 전용 경로 |
| 복슬복슬(방어 2배)·파동의방호(방어 2배) | **지구던지기는 변화 없음**(고정 데미지, 위 기준). 바뀌는 쪽은 **불새·트림·바늘미사일이 더 이상 절반이 되지 않아 데미지 2배**, **대격분 vs 복슬복슬은 접촉 ×0.5와 불꽃 ×2가 겹치던 ×1에서 ×2로** 바뀐다 |
| 단단한발톱(×1.3, 접촉기 위력 보정) | **메가프테라 불새·메가갑주무사 바늘미사일이 ×1.3을 잃는다**(실전 메가 2종의 화력 변화 → 해시 변동 가능성 높음). 지구던지기는 고정 데미지라 영향 없음 |
| 방어류(킹실드·니들가드·토치카) 막힘 반응 | 불새(공격 턴)·트림·대격분·바늘미사일은 막혔을 때의 반응(킹실드 공격 −1·니들가드 1/8·토치카 독)이 **없어지고**, 지구던지기는 **새로 생긴다**(바늘미사일이 막히면 반응은 1회) |
| AI(`moveDamage.ts:231`) | 접촉 반응 예상 손실이 같은 방향으로 바뀜 |
