## 3. 부록 A(champions 실효 값이 다른 75개) 교차

- **엔진이 이미 champions 값과 일치: 67개.** 7.x까지 반영된 것이다.
- 엔진이 어긋난 **8개**: 페이탈클로(위 §2-4 — 확률은 별도 필드로 구현돼 **문제없음**) · 성장(타입 변경 포함 값은 일치, 위 중복 항목만 확인) · 빙산바람(**D3-E0-03**) · 니들가드·마지막일침·뱀눈초리(PP, §2-2) · 시럽봄(§2-4 문제없음) · 기충전(PP는 일치, §2-4 표기 차이).
- 부록 A에 **없는데** 불일치로 잡힌 기술: 57줄. 대부분 §2-3·§2-4의 구조 차이이고, 진짜 데이터 오류는 §2-1의 `막말내뱉기`·`썬더다이브`·`액셀록`·`트라이어택`·`트릭`·접촉 표기·PP 기본값 누락이다 — **champions 재정의와 무관한 기존 엔진 데이터 오류가 위주**다.
