## 0. 요약
- **현황(S2, 선출 포함 사다리, 시드 300 = 600판, 학습 끔)**: P4/P3 **50.0%(300:300)** · P5/P4 **59.5%** · P6/P5 **50.0%(300:300)** · P7/P6 **53.3%**. 학습을 켠 h2h(M2): P4 vs P3 49.7%(285:288) · P5 vs P4 57.2% · P6 vs P5 50.3%.
- **원인(코드·측정)**: P3·P4는 같은 AI(`MODEL_ONLY`)이고 λ(0.25/0.5)만 다르다. P5·P6은 같은 AI(`APP_DECISION_PARAMS`)이고 λ(0.75/1.0)만 다르다. **사다리 측정은 학습을 끈 채로 재므로 이 두 쌍은 완전히 같은 AI끼리의 거울상 대국이라 정확히 50.0%**가 나온 것이다. 학습을 켠 M2에서도 동률이라 **λ는 강도 수단이 아니다**(C2-a: 결정 민감도 3~19%, C2-b2 M0b: 순이득 0 근처). 격차는 P5(탐색 켬) 한 곳에만 있다.
- **제안(Q3 확정: 완화 최소 약화)**: 상위(P6·P7)와 하위(P0~P2)는 건드리지 않고 **P3 약 −25 Elo, P4 불변, P5 약 −44 Elo**로 약화해 인접 승률을 **≥ 53%**(목표 배치 53.3~61.2%)로 만든다. 약화 수단은 P3 = 실수 모델(`mistake`, margin 0.5 우선), P5 = 탐색 약화.
- 폐기도 정당한 결과다: 라운드 상한 안에서 목표를 못 맞추면 현행 유지로 닫고 근거를 적는다.

|---|---|---|---|---|

## 3. 약화 수단과 후보 격자
| 단계 | 수단 | 첫 후보 | 근거·주의 |
|---|---|---|---|
| P3 | `mistake: { rate, margin }`(탐색 없음에서 최선 − margin 이내 차선책을 확률 rate로 균등 선택) | `margin 0.5`(그럴듯한 실수), **`rate ∈ {0.06, 0.10}`** | `applyMistake`는 `params.mistake && !params.search`일 때만 적용 → 탐색 없는 P3에 쓴다. P0~P2는 `margin 1e9`(어떤 차선책이든)였다(6.3 A2). P1→P2 외삽: −64 Elo ≈ r 0.17 → **−25 Elo ≈ r 0.07 안팎**. margin 1e9도 보조 후보 |
| P4 | **불변**(`MODEL_ONLY` + λ 0.5) | — | 목표가 P4 불변이다 |
| P5 | **탐색 약화** — `search`를 안쪽까지 복사해 `topK`·`maxOpponentMoves`·`budget`을 줄인다 | **후보 A** `topK 2` · **후보 B** `topK 2 + maxOpponentMoves 2` · (보조) `topK 2 + budget 12` | 탐색이 있으면 `mistake`는 적용되지 않는다. `topK 1`은 사실상 탐색 없음이라 약 P4 수준(≈ 296 Elo) — 목표 319는 `topK 3`(363)과 `topK 1` 사이이므로 `topK 2` 계열이 유력. 작은 조정으로 부족하면 강한 조합으로 간다 |
| λ | **유지**(P3 0.25 · P4 0.5 · P5 0.75 · P6 1.0) | — | λ는 강도 수단이 아니다. UI 표시("AI 학습")와 일치를 위해 그대로 |

- 약화량 ↔ Elo의 관계는 모른다 → 측정으로 교정(§4). 위 격자는 첫 시도다.
- **공유 상수 주의**: `APP_DECISION_PARAMS.search`(= `PRODUCT_SEARCH_PARAMS`)를 그대로 참조해 P5 정의에서 얕게 복사하면 앱 AI·P6까지 같이 바뀐다 → `{ ...APP_DECISION_PARAMS, search: { ...APP_DECISION_PARAMS.search, topK: 2 } }`처럼 안쪽 객체를 복사하고 §6 시험으로 확인한다.

## 7. 알면서 두는 한계(예정)
- **튜닝은 학습을 끈 기본 강도로 한다.** 앱의 랭크 모드에서는 학습(λ)이 켜져 있어 같은 단계라도 학습 이득(C2: 0~3%p)만큼 강하다. 사다리 측정(`rank-ladder.mjs`)은 학습 없이 재므로 λ가 작동하지 않고, λ만 다른 단계는 거울상 대국이 되어 정확히 50.0%가 나온다(수치 해석에서 "정확히 50.0%"는 동일 AI 신호이지 우연이 아니다).
- 600판 측정의 표준오차는 ±2%p(≈ ±14 Elo). 확정 측정은 1,200판(±1.4%p ≈ ±10 Elo)이라도 53% 하한 근처의 판정은 불확실하다 — 신뢰구간 하한 > 50% 조건이 이를 보완한다.
- 인접 단계끼리만 직접 쟀다. 먼 단계(예: P3 대 P6) 승률은 Elo 합과 어긋날 수 있다(비전이성) — 확정 측정에서 P3 대 P6도 한 번 잰다.
- 약화로 만든 강도 격차는 "실수하는 AI"의 격차다. margin 0.5로 그럴듯한 실수만 하게 하지만 사용자가 느끼는 난이도가 달라질 수 있다 — 체감 확인.
- P7(챔피언) 간격(P7/P6 53.3%)은 C1 소관이다.
