## 1. 무엇이 틀렸나

| 항목 | Showdown(champions) | 엔진 현재 |
|---|---|---|
| 불새(skyattack) | `flags.charge: 1` + `onTryMove`(1턴째 준비, 2턴째 발동). 위력 140·명중 90·급소 +1·30% 풀죽음 | `chargeTurn` **없음** — 태그 "충전-제자리"와 효과 문구("2턴째에 상대를 공격한다")만 2턴이고, 실제로는 **매 턴 140 위력으로 바로 공격하는 1턴 기술** |

- 발견 경위: D3-fix-2 시나리오 33을 쓰다가 불새를 2턴 돌렸더니 두 번 다 데미지가 들어갔다(`dealt` 90 = 한 턴치, 2턴에 180). 지금 불새는 140짜리 막강한 1턴기라 사용 포켓몬(엔진 습득기 12종)에게 과하게 유리하다.
- **다른 충전 기술은 이상 없음**: Showdown `flags.charge`는 10개(bounce·dig·dive·electroshot·fly·meteorbeam·phantomforce·skyattack·solarbeam·solarblade)이고 엔진 `chargeTurn`은 9개(불새만 없음). 반동(`flags.recharge`) 7개는 엔진과 일치(champions 사용 가능 6개 + `meteorassault`는 champions에서 `Past`인데 엔진에 남아 있다 — 이번 범위 밖 참고).
- 이 건은 E0 데이터 층 대조(`8.3-D3-E0-검수.md`)가 **필드 값만 비교하고 필드 누락은 보지 못해** 놓쳤다. D3 동작 층(E1~E10)의 충전 영역 점검에서 이미 짚을 대상이라 이 PR로 먼저 처리한다.

## 2. 고칠 것

`src/data/moves.json`의 불새에 `"chargeTurn": true`를 더한다(`makesContact`·`tags`·`highCritRatio`·`inflictsVolatile`은 그대로). 다른 필드는 필요 없다:
- `chargeSkipWeather`: **넣지 않는다.** 불새는 날씨로 준비 턴이 생략되지 않는다(일렉트로빔은 비, 솔라빔은 쾌청).
- `chargeHideType`: **넣지 않는다.** 불새는 준비 턴에 숨지 않는다(공중날기·구멍파기 등과 다르다).
- `chargeStatChanges`: **넣지 않는다.** 능력치 상승 없음(일렉트로빔·메테오빔과 다르다).
- 파워풀허브(준비 생략 도구): champions에서 **`Past`(사용 불가)** 로 지정돼 있다(덤프가 `Past` 도구를 걸러 "없다"로 보였다. 엔진에도 없다) — 생략 경로가 없다. `onChargeMove`는 기본 데이터에서 파워풀허브 하나뿐이다.

## 4. 영향 범위

- **사용 포켓몬**: 불새 습득 12종(E0 집계). 샘플 파티(`samplePartyPresets.json`)에는 **0건** — 샘플 등급·`sample` 기준값은 영향이 없을 것으로 본다(D2 재측정에서 확인).
- **해시**: `regress`(무작위 빌드로 대국 — 불새를 든 빌드가 섞임)와 `matchup`(차분 해시, 불새 데이터를 평가)이 바뀔 가능성이 높다. 단독 PR이라 원인 분리는 쉽다(불새만 바뀐다). `greedy120`·`status60`·`h2h40`·`ai60`은 샘플 대국이라 변동 없을 것으로 예상하되 측정으로 확인한다.
- **AI**: 별도 코드 없이 `moveDamage.ts:183` `withTurnCost`가 `chargeTurn`을 읽어 불새를 **2턴 비용**(데미지 ÷2, 한 방 처치도 상대가 한 번 더 움직임)으로 평가한다. 상대 예측은 `opponentMoveModel.ts:54`가 준비 중 잠금을 이미 본다. 즉 AI의 불새 평가가 내려가는 것이 의도된 변화다.
- **화면**: 준비 중 안내("불새 준비 중...", `BattleFighterInput.tsx:227`)와 준비 턴 로그는 기존 충전 기술과 같은 경로라 자동으로 적용된다. 효과 문구("2턴째에 상대를 공격한다")는 이미 정확하다.

## 7. 위험·한계

- 불새의 위력이 사실상 "2턴 비용"으로 내려가므로 불새를 쓰는 AI 빌드의 승률이 내려간다 — 의도한 변화이며 랭크 사다리(D1·D2 재측정)에서 일괄 확인한다.
- **흉내쟁이 충전 기술 제외는 Showdown과 다르다(검수 §3-3, E-영역 후보 확정)**: Showdown 흉내쟁이는 `failcopycat`만 검사하고 `flags.charge`는 막지 않아 불새를 부를 수 있다(1턴째 준비 시작). 엔진은 `chargeTurn` 기술을 제외한다(`preHitEffects.ts:1351`). 흉내쟁이는 champions에서 26종이 습득한다. 이번 PR 범위 밖이라 현재 동작을 시험으로 고정하지 않는다. 같은 이유로 준비 턴에도 `lastMove`가 불새로 기록되는 점(Showdown `moveUsed`)은 fix5(앙코르) 시험에서 확인한다.
- 이 PR은 **D3-fix-2(#502)가 머지된 뒤** 올린다(둘 다 `regress` 기준값을 바꾸므로 원인 분리와 기준값 충돌 방지).
