- 기준: smogon/pokemon-showdown `data/mods/champions/rulesets.ts` `Flat Rules`(`claude/showdown-code-map.md` §4 정리 내용), `scripts.ts` `actions.canMegaEvo`. 싱글(`gen9championsbssregmc`)

- 범위: C4는 엔진 규칙이 아니라 **생성 휴리스틱**이므로 Showdown 대조는 "메가 수가 규칙상 제한이 아니다"는 전제 확인에 한정한다. 나머지는 측정·판정 논리를 검토했다.

## 1. 판정 요약

| 항목 | 판정 |
|---|---|
| 전제: 파티 규칙상 메가 수 제한 없음, 배틀 중 메가는 한 번 | ✅ `Flat Rules`의 팀 제약은 Species Clause·Item Clause·금지급 제외·6마리뿐이다. 메가스톤 개수 제한이 없다. 배틀 중 1회 제한은 `canMegaEvo`(사이드 단위)에서 처리한다. "규칙 위반이 아닌 생성 휴리스틱" 주석이 정확하다 |
| §2 측정 조건(중복 포켓몬·도구 금지) | ✅ Species Clause·Item Clause와 같다. 서로 다른 메가스톤은 다른 도구이므로 메가 여러 마리 자체는 Item Clause에 걸리지 않는다 |
| §2 표 수치 내부 정합성 | ✅ 9+21+36+2=68, 메가 슬롯 0·21·72·6=99, 슬롯 68×6=408. 상한 2 분포 = 상한 없음의 0·1(10.3·32.9) + 2 이상 합(36.2+20.6=56.8 ≈ 57). 같은 셔플이라는 설명과 맞다 |
| §2 "상한이 결과를 바꾼 비율 20.5%" vs "3+ 20.6%" | ⚠️ 같은 셔플이면 두 값은 **정확히 같아야** 한다(3마리 이상이던 구축만 바뀌고, 바뀐 구축은 반드시 3마리 이상이었다). 0.1%p 차이는 반올림 또는 별도 실행 차이로 보인다. 결론에는 영향 없음. 문구에 "반올림 차"를 적거나 한 값으로 통일한다 |
| §3 "상한 3이면 3마리 구축 약 17%(샘플의 5배)" | ❌ **수치 오류.** 16.7%는 상한 없음에서 *정확히 3마리*인 비율이다. 상한 3이면 4·5마리 구축(3.6+0.3%)도 3마리로 잘리므로 3마리 구축은 **약 20.6%**, 샘플(2/68 = 2.9%)의 **약 7배**다. 결론(상한 3 기각)은 오히려 강해진다 |
| §4 Q2 생략 근거 | ⚠️ 결론(생략)은 맞지만 근거를 바꾼다. 5.1 A3 난이도 측정(하 56.3·중 50.0·상 52.9%)은 **이미 상한 2 상태에서** 잰 값이고 이번에 코드가 바뀌지 않으므로, 승률을 다시 잴 대상 자체가 없다. "분포가 샘플과 같아서"보다 이 근거가 직접적이다 |
| §3 한계(등급별 풀 미측정) | ⚠️ 수용 가능. 다만 "결론은 같다고 본다"는 추정이다. 판정 근거가 "상한이 걸리는 비율이 무시할 수준이 아니다"이므로, 어느 등급 풀에서 3+ 비율이 낮더라도 상한 2는 손해가 없다(걸리지 않으면 무해). 이 논리를 한 줄 적으면 추정이 필요 없어진다 |

**결론: Q1·Q2·Q3 모두 기본안대로 확정 가능.** 설계서에는 아래 문구 수정만 반영한다.
1. §3: "상한 3 → 3마리 구축 약 17%(5배)" → "**약 20.6%(4마리 이상이 3으로 잘림), 샘플 2.9%의 약 7배**".
2. §2 표: 20.5%와 20.6%를 한 값으로 맞추거나 "반올림 차"를 적는다.
3. §4 Q2 근거: "5.1 A3 난이도는 이미 상한 2 상태에서 측정했고, 코드 변경이 없으므로 재측정 대상이 없다".
4. §3 한계: "등급별 풀에서 상한이 덜 걸리더라도 상한 2는 분포를 샘플 쪽으로만 옮기므로 손해가 없다".

## 2. 상세

### 2-1. 상한 3의 3마리 비율
- 같은 셔플에서 상한 k는 "메가 k마리 이상이던 구축을 k마리로 자른다". 따라서 상한 3의 3마리 비율 = 상한 없음의 P(≥3) = 16.7 + 3.6 + 0.3 = **20.6%**.
- 샘플 3마리 비율 = 2/68 = **2.9%** → 약 **7.0배**. 설계서의 "5배"는 P(=3)만 본 계산이다.

### 2-2. "바뀐 비율"과 "3+ 비율"이 같아야 하는 이유
- 상한 2는 세 번째 메가를 뽑는 순간에만 개입한다. 상한 없음에서 메가가 2마리 이하인 구축은 같은 셔플이면 결과가 같다. 3마리 이상인 구축은 반드시 달라진다.
- 따라서 두 비율은 정의상 같다. 차이가 실제로 존재한다면 비교가 "같은 셔플"이 아니었다는 뜻이므로 문구를 확인한다(결론 영향 없음).

### 2-3. Q2를 생략해도 되는 직접 근거
- 승률 측정이 필요한 경우는 "상한을 바꿀 때"뿐이다. 유지 결정이면 현재 난이도(5.1 A3)가 곧 상한 2의 난이도이다.
- 따라서 `partyvs` 측정은 Q1이 "변경"으로 바뀔 때만 의미가 있다. Q1 = 유지이면 Q2 = 생략은 자동으로 따라온다.
