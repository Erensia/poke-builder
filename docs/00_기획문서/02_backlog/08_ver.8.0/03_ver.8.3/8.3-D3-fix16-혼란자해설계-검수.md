## 1. 소스 대조

```ts
// data/conditions.ts confusion.onBeforeMove (priority 3) — champions 재정의 없음
pokemon.volatiles['confusion'].time--;  if (!time) { removeVolatile; return; }   // 굴림 없이 해제
if (!this.randomChance(33, 100)) return;                                         // 난수 1
this.activeTarget = pokemon;
const damage = this.actions.getConfusionDamage(pokemon, 40);                    // 난수 2
this.damage(damage, pokemon, pokemon, { id: 'confused', effectType: 'Move', type: '???' });
return false;

// sim/battle-actions.ts getConfusionDamage
const attack  = pokemon.calculateStat('atk', pokemon.boosts['atk']);   // 실능 × 랭크 배율, ModifyAtk 없음
const defense = pokemon.calculateStat('def', pokemon.boosts['def']);
baseDamage = tr(tr(tr(tr(2*L/5+2) * 40 * attack) / defense) / 50) + 2;
damage = randomizer(tr(baseDamage, 16));   // tr(tr(d * (100 - random(16))) / 100)
return Math.max(1, damage);
```

## 2. 보완

### 2-1. [필수] 천진·천하장사·도구는 자해 피해에 영향 없음 — 시험 5 확장
- 이번 PR이 `computeDamage`에 **처음으로 랭크를 넘긴다.** 엔진 `computeDamage`가 `attackerAbility`/`defenderAbility`로 천진(Unaware)을 처리하는 구조라면, 공격·방어가 같은 포켓몬인 자해에서 **자기 천진이 자기 랭크를 지우는** 경로가 새로 열린다.
- Showdown `unaware.onAnyModifyBoost`: 보유자 본인이면 `return`, 상대 보유자일 때는 `activePokemon === activeTarget === 자해 포켓몬`이라 두 조건 모두 불성립 → **자기·상대 어느 쪽 천진도 무영향.**
- 시험 5에 추가: ① 천진 픽시(챔피언스 합법, 숨겨진 특성) 공격 +2 자해 = 천진 아닌 같은 조건(+2 반영), ② 상대가 천진이어도 같음, ③ 천하장사 마릴리(·순수한힘 메가요가램)·구애머리띠 보유 자해 = 중립 포켓몬과 같음.
- 엔진이 이 옵션들을 자해 호출에 넘기지 않는 구조라면 시험만 통과하면 된다(코드 변경 없음).

### 2-2. [권고] 16단계 굴림은 본 피해 경로와 같은 식을 재사용
Showdown은 `100 − random(16)`(작은 난수 → 100%), 설계서는 `85 + floor(r × 16)`(작은 난수 → 85%)로 방향이 반대다. 엔진 난수열이 Showdown과 다르므로 분포만 같으면 결과 관측은 동등하나, 본 피해 경로와 자해가 **다른 식을 쓰면 시험 1의 "단계 지정"이 두 경로에서 엇갈린다.** 본 피해 경로의 굴림 함수(또는 상수식)를 그대로 호출하고, 시험 1은 그 매핑 기준으로 단계를 지정한다. (부동소수점: 피해 1~400 × 85~100%에서 `floor(b × p/100)`과 `floor(floor(b × p)/100)`이 어긋나는 경우는 없음을 확인했다.)

### 2-3. [권고] §6 "알면서 둔 것"에 매직가드·탈 추가
자해는 `effectType: 'Move'`로 들어가므로:
- **매직가드(픽시 — 흔함)는 자해 피해를 막지 않는다**(`magicguard.onDamage`는 `effectType !== 'Move'`만 차단).
- **탈(따라큐)은 자해를 막고 벗겨진다**(`disguise.onDamage`가 `effectType === 'Move'`로 판정). 얼음인형(Ice Face)은 `category === 'Physical'` 조건이라 막지 않는다.
- 옹골참·기합의띠도 발동(설계서 기재대로).
엔진 자해가 "간접 피해"로 처리되어 매직가드에 막힌다면 Showdown과 다르다. 구현 첫 단계에서 자해 피해 적용 함수가 매직가드를 보는지 grep으로 확인하고, 다르면 E8 백로그에 근거(위 두 줄)와 함께 올린다.

### 2-4. [참고·백로그] 원더룸
`calculateStat`은 원더룸 중 `def` 자리에 **실능 특방**을 쓰고 랭크는 **방어 랭크**를 쓴다. 원더룸은 챔피언스 합법 기술이다. 엔진이 원더룸을 구현하지 않았다면 무관, 구현했다면 자해 호출에도 같은 교환이 들어가는지 확인 항목으로 둔다.
