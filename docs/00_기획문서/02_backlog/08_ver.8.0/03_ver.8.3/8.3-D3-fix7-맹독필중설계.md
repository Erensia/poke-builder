## 1. 무엇이 틀렸나
| 항목 | Showdown(champions) | 엔진 현재 |
|---|---|---|
| 독 타입이 쓰는 맹독 | 필중(명중 판정·회피 랭크·반짝가루 등 전부 무시) | 명중 90에 랭크·보정이 그대로 걸려 최대 10% 빗나감 |
- 근거 확인: `hitChance.ts`·`preHitEffects.ts`에 독 타입·맹독 연계 분기 없음(grep). 사용자 사례가 필요한 값 규칙은 아니고 소스 명시 규칙(본가 6세대 이후 동일).

## 2. 고칠 것
- `src/lib/battle/hitChance.ts` `computeBattleHitChance`의 필중 분기 묶음(`alwaysHits`·`lockOn`…) 옆에 한 줄: `move.id === "맹독" && attacker.types.includes("독")`이면 `null`. 사용자 타입은 **현재 타입**(`attacker.types`, 변경·추가 반영)을 쓴다 — Showdown `hasType`과 같다.
- 평가기·AI(`moveDamage.ts:287`·`evaluator.ts:641`·`finishTurn.ts:270`)는 같은 함수를 호출하므로 자동 반영.
- **무적 상태 통과도 이번에 넣는다(A안, 검수 권고)**: Showdown은 같은 조건을 무적 판정 단계(`hitStepInvulnerabilityEvent`, `battle-actions.ts:689`)와 명중 단계(`:793`) 두 곳에 둔다. 엔진은 무적을 `preHitEffects.ts:1110` `evadedByCharge`(차지 기술 준비 턴)에서 따로 보므로, 독 타입 맹독이면 `evadedByCharge`도 `false`로 둔다. 판별식은 공유 함수 `toxicNeverMisses(attacker, move)` 한 곳에 두고 `hitChance.ts`·`preHitEffects.ts`가 같이 쓴다. 근거: 본가 규칙이 "필중 + 무적 통과" 한 묶음이고, champions에서 구멍파기 158종·다이빙 44종·공중날기 37종이 배워 "드물다"는 전제가 약하다.
- 노가드·록온도 같은 묶음 규칙(필중 + 무적 통과)을 갖지만 엔진은 지금 무적을 통과시키지 않는다. **이번 범위 밖** — E2 2차 항목 E2-12로 백로그.

## 3. 규칙
- 필중이면 `null`(기존 규약: "반드시 맞으면 null"). 일격필살·방어 판정 등 다른 단계는 영향 없음.
- 독 타입이 아니면 현행 그대로(명중 90, 랭크·보정 적용). 메가진화로 독 타입이 생기거나 사라져도 `attacker.types`가 현재 값이라 따라간다.

## 4. 영향 범위
- 기준 출력: 독 타입 맹독 사용 판의 명중 판정 → `regress`·`greedy`·`h2h`·`ai` 해시 변동 예상(맹독 + 독 타입 샘플 수는 구현 전에 `samplePartyPresets.json`에서 센다 — 0이면 h2h·ai는 불변일 수 있음).
- 화면: 배틀 로그에서 맹독이 빗나가는 일이 독 타입에게는 사라진다.

## 5. 시험(먼저 쓰고 실패 확인) — 시나리오 `38-ver83-d3fix7.mjs`(번호는 구현 때 확정)
1. 독 타입 사용자의 맹독 `computeBattleHitChance` = `null` (구현 전 0.9로 실패).
2. 비독 타입(예: 노말) 사용자 = 0.9 (회귀 방지).
3. 독 타입 + 상대 회피 +6 + 반짝가루 → 여전히 `null`. 모래숨기 대상(회피 보정이 반짝가루와 다른 경로)도 `null`.
3-b. **물붓기**를 맞아 독 타입이 사라진(타입 물) 사용자의 맹독 → `0.9`(현재 타입 규칙 시험. 메가진화로 독 타입이 생기는 맹독 사용자는 champions에 없어 예시를 물붓기로 바꿈. 변환자재·리베로도 맹독 습득 종이 없어 해당 없음).
3-c. **구멍파기 1턴째 대상**(무적)에 독 타입이 쓴 맹독 → 명중(`evadedByCharge false`), 비독 타입은 현행대로 빗나감.
3-d. 엔진 경로 로그에 빗나감 문구가 없다.
4. 독 타입이 쓰는 **다른 독 기술**(독찌르기 등)은 필중이 되지 않는다.
5. 엔진 경로: 고정 난수 `0.99`(빗나감 값)로 독 타입 맹독 1턴 → 상대 `badly-poisoned`.
