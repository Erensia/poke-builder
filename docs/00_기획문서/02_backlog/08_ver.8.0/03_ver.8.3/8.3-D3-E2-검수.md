## 2. 상세

### E2-02 맹독 독 타입 필중 — 수정필요
- Showdown은 gen8 이후 독 타입이 쓰는 맹독을 필중으로 처리한다(본가도 6세대부터 같은 규칙). 엔진 `moves.json`의 맹독은 `accuracy 90`뿐이고 `hitChance.ts`(`accuracy: 90` 사용)에 독 타입 분기가 없어 **독 타입도 10% 빗나간다.** 독 타입 맹독 사용자(독 타입 + 맹독 습득)는 다수다.
- 조치안: `hitChance.ts`에 `move.id === "맹독" && attacker.types.includes("독")` → `null`(필중) 한 줄, 그리고 무적 상태(땅파기 등) 통과는 기술 규칙에 있으나 싱글에서 영향이 작아 2차.
- 영향: 독 타입 포켓몬의 맹독 사용 시 명중 판정 변동(필중) → 기준 출력 변동. 평가기·AI가 `computeBattleHitChance`를 공유하므로 자동 반영.

### E2-01 명중률 정수 절삭·4096 — 결정필요
- 엔진은 연속 확률(예: 명중 85, 랭크 −1 → 63.75%)을 그대로 쓰고, Showdown은 `trunc(85×3/4)=63`을 정수로 만든 뒤 `63%`로 굴린다. 보정 배율도 소수(1.3·1.1·0.9)와 4096 분율(5325·4505·3686)의 차이가 있다.
- **`[계산]`**(명중 50~100 × 랭크 −3~+3 × 보정 7종 = 425가지): 142가지(33%)에서 엔진이 Showdown보다 **평균 0.46%p, 최대 1.5%p 높다**(예: 명중 50·랭크 −3·광각렌즈 → 엔진 27.50% / Showdown 27%). 랭크·보정이 모두 없을 때는 같다.
- 영향: 명중에 보정이 걸린 경우만(랭크 변화 기술·렌즈류·반짝가루·복안 등). 효과는 최대 1%p 미만~1.5%p로 작다. 본가(사용자 확인 공식 `(3+s)/3`)가 정수 절삭인지는 **미확인**이다.
- 권고: **E1 fix-6의 4096 도구(`modify4096`·`chain4096`)를 재사용해 같은 방식으로 정리하되, fix-6과 별도 PR**(AI 시뮬 중 명중 판정이 달라 해시 원인 분리가 어려워진다). 묶는다면 fix-6 사전 확인에서 쓴 사용자 사례 방식(외부 계산기 값)으로 확인 1건이 필요하다.
- **결정(2026-11-17)**: 권고대로 따라간다. fix-6 머지 뒤 별도 PR(**fix-8**)로 진행.

## 6. E2-11 난동 끊김의 혼란 — 보정과 엔진 확인 결과 (결정필요, 2026-11-18)
- **Showdown 규칙**(`lockedmove`): 시작 시 `trueDuration = random(2,4)`(2 또는 3), 매 턴 `onResidual`에서 차감, `onEnd`는 **`trueDuration ≤ 1`일 때만 혼란**. 정리하면 **예정된 마지막 턴에 끊기면 혼란, 그 전에 끊기면 혼란 없음**이다.
  | 예정 지속 | 끊긴 시점 | 혼란 |
  |---|---|---|
  | 2턴 | 2턴째(예정 마지막 턴) | **있음** |
  | 3턴 | 2턴째(중간) | 없음 |
  | 3턴 | 3턴째(예정 마지막 턴) | **있음** |
  | 2·3턴 | 1턴째 빗나감 | 상태가 걸리지 않음 → 없음 |
  마비·풀죽음·얼음·혼란 자해 등 행동불능(`BeforeMove` 실패)도 턴 종료에 `duration`이 0이 되어 `end`가 먼저 불려 같은 결과다. **수면은 두 갈래로 정정(2026-11-18, `8.3-D3-fix10-난동혼란설계-검수.md` §2)**: 예정 마지막 턴에 움직이기 전 잠들면 혼란, **명중한 턴 안에서 잠들어 다음 턴 행동불능이면 `lockedmove.onResidual`의 "calming"으로 혼란 없이 조용히 해제**된다(하품은 `onResidualOrder: 23`이 `lockedmove`보다 먼저). 앞 문장의 "수면 줄은 실측"·검수 회신의 "수면도 같은 만료 경로"는 이 정정으로 대체된다.
- **엔진**(`rampage.ts` `updateRampage`, 읽고 확인함): `disrupted(action)`(행동불능·빗나감·방어·무효·특성 면역)이면 `endRampage` 후 **무조건 혼란 없이 종료**한다. 주석에도 "도중에 끊기면(… **마지막 턴 포함**) 혼란 없이 끝난다"로 적혀 있다. → **예정 마지막 턴에 끊긴 경우가 Showdown과 다르다**(엔진: 혼란 없음 / Showdown: 혼란).
- **이것이 사용자 확정 규칙과 부딪친다**: `1.9-backlog.md` 난동 5번 "도중에 끊기면 난동 종료·혼란 없음. **마지막 턴에 끊겨도 혼란 없음(D — B·C와 통일)**"(사용자 결정). 그래서 수정필요가 아니라 **결정필요**(설계서 Q4 "사용자 확정 규칙이 다르면 결정필요, 확정 유지가 기본")다.
- 권고: E2-01·E3-01과 같은 근거("정확성 > 기존 구현")로 **Showdown을 따라간다** — 예정 남은 턴이 1(마지막 턴)일 때 끊기면 혼란. 구현은 `updateRampage`의 분기 한 곳이고, AI의 난동 평가(1.9 backlog 8번 "끝나면 혼란" 비용)와 화면 문구(`rampageConfused`)가 이미 있어 영향이 작다. 해시는 난동 기술이 든 판에서 바뀔 수 있다. 빈도: 역린·꽃잎댄스·난동부리기 습득자가 많다(예: 한카리아스·망나뇽). **→ 사용자 결정(2026-11-18): Showdown을 따라간다 — 근거는 인게임 확인.** 사용자가 본가(인게임)에서 직접 확인했다: **2턴짜리 역린은 2턴째에 상대가 무효(페어리 타입)여도 혼란에 걸리고, 혼란이 안 걸리는 경우는 3턴짜리가 중간인 2턴째에 무효로 풀린 때뿐이다.** Showdown 규칙(위 표)과 정확히 같다. 이로써 1.9 사용자 결정 D("마지막 턴에 끊겨도 혼란 없음")는 **본가와 다른 규칙이었음이 확인되어 번복**한다("정확성 > 기존 구현"). 수정필요로 전환, 설계서 `8.3-D3-fix10-난동혼란설계.md`.
