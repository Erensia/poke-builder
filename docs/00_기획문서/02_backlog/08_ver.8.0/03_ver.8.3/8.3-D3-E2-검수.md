## 2. 상세

### E2-02 맹독 독 타입 필중 — 수정필요
- Showdown은 gen8 이후 독 타입이 쓰는 맹독을 필중으로 처리한다(본가도 6세대부터 같은 규칙). 엔진 `moves.json`의 맹독은 `accuracy 90`뿐이고 `hitChance.ts`(`accuracy: 90` 사용)에 독 타입 분기가 없어 **독 타입도 10% 빗나간다.** 독 타입 맹독 사용자(독 타입 + 맹독 습득)는 다수다.
- 조치안: `hitChance.ts`에 `move.id === "맹독" && attacker.types.includes("독")` → `null`(필중) 한 줄, 그리고 무적 상태(땅파기 등) 통과는 기술 규칙에 있으나 싱글에서 영향이 작아 2차.
- 영향: 독 타입 포켓몬의 맹독 사용 시 명중 판정 변동(필중) → 기준 출력 변동. 평가기·AI가 `computeBattleHitChance`를 공유하므로 자동 반영.

### E2-01 명중률 정수 절삭·4096 — 결정필요
- 엔진은 연속 확률(예: 명중 85, 랭크 −1 → 63.75%)을 그대로 쓰고, Showdown은 `trunc(85×3/4)=63`을 정수로 만든 뒤 `63%`로 굴린다. 보정 배율도 소수(1.3·1.1·0.9)와 4096 분율(5325·4505·3686)의 차이가 있다.
- **`[계산]`**(명중 50~100 × 랭크 −3~+3 × 보정 7종 = 425가지): 142가지(33%)에서 엔진이 Showdown보다 **평균 0.46%p, 최대 1.5%p 높다**(예: 명중 50·랭크 −3·광각렌즈 → 엔진 27.50% / Showdown 27%). 랭크·보정이 모두 없을 때는 같다.
- 영향: 명중에 보정이 걸린 경우만(랭크 변화 기술·렌즈류·반짝가루·복안 등). 효과는 최대 1%p 미만~1.5%p로 작다. 본가(사용자 확인 공식 `(3+s)/3`)가 정수 절삭인지는 **미확인**이다.
- 권고: **E1 fix-6의 4096 도구(`modify4096`·`chain4096`)를 재사용해 같은 방식으로 정리하되, fix-6과 별도 PR**(AI 시뮬 중 명중 판정이 달라 해시 원인 분리가 어려워진다). 묶는다면 fix-6 사전 확인에서 쓴 사용자 사례 방식(외부 계산기 값)으로 확인 1건이 필요하다.
- **질문 Q-E2-1**: 명중률의 정수 절삭·4096 체인을 따라갈지(권고: 따라간다, fix-7로 분리) 현행 소수를 유지할지.
