# ver.8.3 D3-fix-43 설계서 — 우격다짐이 위기회피·탈출버튼·레드카드를 막지 않는다 (E8-09)

**상태**: 초안 2026-11-27, **사용자 검수 대기**(검수 전에는 구현하지 않는다). 사용자 결정 2026-11-27: "Showdown champions 기준으로 고치고 한 PR로 묶어서 처리". 근거 `8.3-D3-E8-검수.md` §5, 검수 자료 `D3-덤프파일/e8a-run.cjs`.
**브랜치(예정)**: `feature/8.3-d3-fix43-sheerforce-aftermove`. PR 1개·커밋 1개.

## 1. 문제
엔진은 우격다짐이 추가효과를 위력으로 바꾼 행동(`action.sheerForceAbilityName`)에서 **방어측의 위기회피·탈출버튼·레드카드를 모두 발동시키지 않는다**. 이는 **기본 Showdown** 동작이다. 포챔스(Showdown `champions` 모드)는 우격다짐이 이 효과들을 억제하지 않도록 바꿨다.

| 증거 | 내용 |
|---|---|
| `[소스]` | `data/mods/champions/scripts.ts` 424행 주석 "Sheer Force doesn't suppress AfterMoveSecondary events: Berserk, Pickpocket, Emergency Exit, Eject Button, etc."; 같은 파일의 `hitStepMoveHitLoop`·`spreadMoveHit`가 `AfterMoveSecondary`·`EmergencyExit`를 `suppressingSecondaries()` 조건 없이 실행. `champions/abilities.ts` 발끈도 `!suppressingSecondaries()` 조건을 뺐다 |
| `[실행]` | Showdown(`gen9championsbssregmc`) 실측: 우격다짐 독침 → 위기회피 골리삼(발동·교체 요구) · 탈출버튼 잠만보(`-enditem Eject Button`) · 레드카드 잠만보(`-enditem Red Card` + 공격자 `drag`) · 발끈 드람파(특공 +1) **모두 발동**. 대조군(일반 특성)과 같은 결과 |
| `[엔진]` | 같은 장면에서 세 효과 모두 **미발동**. 시험 `21-ver83-a4b.mjs` N-6a·c·e가 이 미발동을 기대값으로 고정하고 있다(기본 Showdown 판정으로 쓴 시험) |

**이미 일치(변경 없음)**: 발끈(`hitResolution.ts` 420행은 우격다짐을 보지 않는다) · 나쁜손버릇(`hitResolution.ts` 1010행, 우격다짐 무관) · 유턴 사용자 vs 위기회피 동시 교체(`runTurn.ts` 492행, 시험 24번 A7-3).
**도달 가능성**: 샘플 파티에 위기회피 7슬롯·우격다짐 1슬롯. 우격다짐 사용자가 추가효과 있는 기술로 위기회피·탈출버튼·레드카드 보유자를 때리는 장면은 실제로 일어난다.

## 2. 변경 (코드 두 곳 + 주석)
`src/lib/battle/runTurn.ts`
1. `hitReachedBody`(398~417행): 마지막 조건 `!action.sheerForceAbilityName` 제거. 함수 주석의 "우격다짐이 추가효과를 위력으로 바꾼 행동은 이 효과들이 발동하지 않는다" 문장을 "포챔스는 우격다짐이 이 효과들을 막지 않는다(champions `scripts.ts` 424행, E8-09)"로 교체. 이 함수는 **레드카드와 탈출버튼이 공유**하므로 한 곳으로 둘 다 바뀐다.
2. `emergencyExitChoice`(492~506행): 조건 `!action.sheerForceAbilityName &&` 제거, 주석의 "우격다짐이 추가효과를 위력으로 바꾼 행동이면 발동하지 않는다" 문장을 같은 근거로 교체.
3. 이 두 함수 외 `sheerForceAbilityName` 사용처(`preHitEffects`·`hitResolution` 생명의구슬 반동·`mirroredEffects` 시럽·문어굳히기)는 **진짜 추가효과 억제·구슬 반동 억제**이므로 그대로 둔다(우격다짐의 본래 효과).
4. `finishTurn.ts` 미래예지 경로는 `sheerForceAbilityName: undefined`로 넘겨 이미 무관하다.

AI: 엔진 시뮬레이션(`runTurn`)을 쓰므로 자동으로 따라온다. `ai/moveDamage.ts` 229행의 우격다짐 처리는 생명의구슬 반동 계산용이라 영향 없음.
