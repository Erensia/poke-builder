## 2. 보완

### 2-1. [필수] §1 "혼란 자해·마비 턴에도 오른다(Showdown은 안 오름)" 정정
- Showdown에서 풀죽음은 혼란·헤롱헤롱·마비보다 먼저 막으므로, **풀죽음 + 혼란 / 풀죽음 + 마비인 불굴의마음 포켓몬은 항상 속도 +1**이고 혼란 지속도 줄지 않으며 자해·마비 굴림도 없다.
- 설계서 시험 7은 이미 이 결론(풀죽음 → 마비보다 먼저 → +1)이라 **§1 본문과 시험이 서로 어긋난다.** 구현자가 §1을 따라 "혼란·마비면 발동 안 함" 가드를 넣으면 틀리므로 본문을 고친다: "Showdown에서 오르지 않는 경우는 ① 이미 움직인 뒤 ② 수면·얼음(·재충전·게으름)으로 먼저 막힌 턴뿐."
- 시험 추가 9: 풀죽음 + 혼란 → 속도 +1, 혼란 지속 그대로, 난수 0회(엔진 순서 ② 풀죽음 → ⑤ 혼란이라 현행 구조에서 통과 예상 — 불변 확인용).

### 2-2. [권고] 재충전 + 풀죽음 → 오르지 않음
루카리오·엘레이드·괴력몬 모두 챔피언스에서 기가임팩트·파괴광선을 배운다. 재충전 턴에 상대가 속여때리기류를 쓰면 Showdown은 재충전(11)으로 먼저 막혀 불굴의마음이 발동하지 않는다. 엔진이 재충전을 `checkActionBlockers`의 풀죽음 판정 **뒤**에서 처리한다면 잘못 오른다. 시험 10으로 고정한다(게으름은 불굴의마음과 동시 보유가 특성 교체로만 가능해 생략 가능).

### 2-3. [참고] 랭크 +6
이미 +6이면 Showdown `boost()`는 실패 메시지만 낸다. 엔진 `applyStageDelta`가 상한을 지키면 별도 처리 불필요.
