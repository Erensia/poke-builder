# ver.8.3 D3-E8 — 특성 216종 대응표 (엔진 ↔ Showdown champions)

**작성 2026-11-26, 검수(`8.3-D3-E8-검수설계-검수.md`) 반영 2026-11-27.** 엔진 `src/data/abilities.json` 216종 ↔ Showdown `965a535` champions 덤프(`D3-덤프파일/showdown-champions-dump.json`). 대응은 E0와 같은 방식(PokeAPI 한국어 이름 → Showdown id, 수동 3건 파동의방호→`auraguard`·불꽃의갈기→`firemane`·천정부지→`eelevate`)이다.

- **집합 정정**: 엔진 216 중 **215종이 덤프와 겹친다.** 엔진에만 있는 것은 **단순**(`simple`, 덤프에 없음 — E0 기록: 출전 포켓몬 중 가진 종 없음 → **도달 불가**), 덤프에만 있는 것은 유대변화(`battlebond`, E0 Q-E0-2). 단순의 Showdown 훅은 덤프에서 못 읽어 소스(`abilities.ts` `onChangeBoost`, 심술꾸러기와 같은 성격)로 ②에 둔다.
- **champions 변경 ●** = 덤프의 `championsOverride` 표시가 있는 14종(출전 허용만 바꾼 것 포함 — 싱글 결과가 달라지는 것은 §1).
- **샘플 사용** = `samplePartyPresets.json`(70개 파티, 420슬롯)에서 그 특성이 쓰인 슬롯 수. 비어 있으면 샘플에서 쓰지 않는다. 쓰이는 특성은 84종.
- **묶음**은 Showdown 훅으로 **자동 배정**했다(앞 묶음 우선: ③ 무효·면역 → ① 피격 반응 → ④ 등장 → ⑤ 턴 종료·상태 → ② 배율 → ⑥ 나머지). **메가솔라는 ②**(날씨 데미지 배율, 검수 S2). 우선도 훅(짓궂은마음·질풍날개·퀵드로·시간벌기)은 ② 안의 "우선도" 소묶음으로 E3·fix-1과 함께 본다.
- **훅 열**은 `…Priority`·`…Order`·`…SubOrder`로 끝나는 키를 **같은 이름의 본 훅이 있을 때만** 생략한다(검수 R3 — 이전판은 `onModifyPriority`·`onFractionalPriority` 자체를 지워 5종이 "—"였다). 훅이 "—"인 부유·일찍기상·부식은 Showdown에서도 `abilities.ts` 밖(`sim/pokemon.ts`·`conditions.ts`)에서 구현된다 → 구현 위치를 같이 읽는다.
- **엔진 플래그 "—"**(17종)은 데이터에 동작 플래그가 없다 → 코드에서 이름 문자열로 직접 검색: 텔레파시·굳건한신념·일찍기상·배틀스위치·프렌드가드·리프가드·플러스·기묘한약·방진·마이너스·치유의마음·단순·픽업·리시버·마이티체인지·대접·강철정신. 이 중 8종은 싱글 무동작이라 E8-b에서 한 줄 판정(설계서 §4).
