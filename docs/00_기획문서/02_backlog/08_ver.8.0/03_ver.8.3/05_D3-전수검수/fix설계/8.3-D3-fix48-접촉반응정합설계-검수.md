## 2. 지적 사항

### A. 반영 필수 (사용자 결정으로 이번 PR에 포함)

**A-1. 부자유친 × 드레인 — 타마다 드레인 (③에 포함, 확정)**
- 원인: Reg M-C에 메가캥카(부자유친)가 합법이고, 캥카는 드레인펀치를 배운다(검증기 통과). 부자유친은 단발기를 2타로 만들기 때문에 데이터상 `maxHits`가 없어도 실전에서 다단 드레인이 생긴다.
- Showdown: 드레인이 `spreadDamage` 안에 있으므로 **타마다** 피해 → 드레인(그 타 피해 기준) → 접촉 반응이 반복된다.
  - 메가캥카 HP60 드레인펀치 vs 까칠한피부: 1타 피해 → 78 → 56 → 2타 피해 → 61 → 39
  - 메가캥카 HP1 드레인펀치 vs 울퉁불퉁멧: 1타 → 19 → 헬멧으로 기절, **2타 없음**
- 설계서 §2-3의 "다단은 루프 뒤" 호출은 Showdown과 다르다. 루프 뒤에서 합계 피해로 한 번 회복하면 (a) 2타째 반응 전 회복이 빠지고 (b) 공격측이 1타 반응으로 쓰러지는 판정이 달라지며 (c) 회복량이 타별 계산의 합과 다르다.
- 구현 지침:
  - 먼저 엔진의 부자유친 처리 분기(단발/다단)를 확인한다. 다단 분기라면 `applyDrainHeal`을 **루프 안, 각 타의 `applyDamageToDefender`·`applyEndurance` 직후, 반응 직전**에 **그 타의 실제 피해**로 호출한다(누적 `actualDamageDealt`가 아님).
  - 엔진에 부자유친이 없다면 §1·§4에 "부자유친 미구현이라 해당 없음"을 명시하고 다단 분기 호출은 넣지 않는다(쓰이지 않는 자리를 만들지 않음).
  - 회복식(내림)은 바꾸지 않는다(B-1, E10). 순서·타 단위만 바뀌므로 ③ 해시 원인은 "드레인 위치" 하나로 유지된다.

**A-2. 호출 기술(잠꼬대·따라하기)에서 봉인 대상 (②에 포함, 확정)**
- Showdown은 `disable.onStart`에서 `pokemon.lastMove`를 봉인한다. 호출된 기술은 `moveUsed`를 거치지 않으므로 `lastMove`는 **호출한 기술**이다.
  - 실행: 잠꼬대 → 깨물어부수기가 저주받은바디에 맞음 → **잠꼬대** 봉인 / 따라하기 → 야습 → **따라하기** 봉인
- 잠꼬대·따라하기는 둘 다 Champions 합법(손가락흔들기·선취는 Past).
- 설계서처럼 `c.move.id`와 `remainingPp[c.move.id]`를 쓰고 `c.move`가 호출된 기술이면:
  - 잠꼬대가 기술칸에 있는 기술을 부른 경우: 그 기술이 봉인됨(Showdown은 잠꼬대)
  - 따라하기가 기술칸에 없는 기술을 부른 경우: `remainingPp`가 `undefined`라 무발동(Showdown은 따라하기 봉인)
- 구현 지침: 봉인 id와 PP 검사 모두 **호출한 기술의 id**(엔진에서 호출 기술 실행 시 원래 선택한 기술을 들고 있는 필드)를 쓴다. 엔진이 이미 호출자 id를 넘기고 있으면 시험만 추가한다. PP는 호출한 기술에서만 깎이므로 "마지막 PP 직후 무발동"도 호출 기술 PP로 판정한다.

**A-3. 시험 7 — 해제 시점을 턴 단위로 고정**
- T1 부여 → T2·T3·T4 해당 기술 선택 불가(`moveRestrictionKind: "disable"`) → T4 턴 종료 시 해제 → **T5에 사용 가능**.
- 교체하면 해제됨(복귀 시 봉인 없음)도 같은 시험에 넣는다. 현행 PP 0 구현은 교체로도 풀리지 않으므로 현행 실패가 확인된다.

### B. 정정·보완

**B-1. 드레인 반올림 문구** — §2-3·§4의 "Showdown `Math.round`(최소 1)"을 "Showdown 세대 5+는 `Math.round`(최소 보정 없음, 0 가능)"로 고친다. E10 후보 기록도 같은 문구로 맞춘다.

**B-2. 반응의 범위** — Showdown에서 드레인은 **모든 `DamagingHit`보다 먼저**이므로 아이템 반응(울퉁불퉁멧·자보열매·령열매)과 유폭·내용물분출도 드레인 뒤다. 이 반응들이 `triggerAbilityHitEffect` 밖에서 먼저 처리되는 경로가 없는지 구현 때 확인한다. 시험 추가:
- HP1 드레인펀치 vs 울퉁불퉁멧 → 회복 후 헬멧 피해, 생존
- 드레인펀치로 유폭 보유 방어측 KO → 회복 후 유폭 피해(낮은 HP면 기절)

**B-3. 시험 15 — 구체 수치로** — **해감액 + 울퉁불퉁멧**은 동시 보유 가능. 흡혈 HP30 vs 독파리(해감액·울퉁불퉁멧): 해감액 → 7 → 헬멧 → 기절(Showdown). 이 장면으로 순서를 수치로 고정한다.

**B-4. 저주받은바디 난수 소비 위치(참고, 필수 아님)** — Showdown은 "이미 봉인 중"만 난수 **전**에 거르고, 아로마베일·PP 0·멘탈허브는 난수 **후**(`addVolatile` 단계)에 걸린다. 엔진 난수열은 Showdown과 별개라 정합성 영향은 없고 해시에만 영향이 있다.
