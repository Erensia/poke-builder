## 2. ⚠️ 무적 통과 — 분기 위치가 결과를 정한다

### 2-1. 근거 (소스)

Showdown의 기술 처리 단계는 **무적 판정 → … → 명중 판정** 순서다(`trySpreadMoveHit`). 독 타입 맹독은 **두 단계 모두**에 예외가 있다.

```ts
// hitStepInvulnerabilityEvent (:689)
} else if (this.battle.gen >= 8 && move.id === 'toxic' && pokemon.hasType('Poison')) {
    hitResults[i] = true;            // 땅파기·공중날기 중이어도 통과
// hitStepAccuracy (:793)
move.alwaysHit || (move.id === 'toxic' && this.battle.gen >= 8 && pokemon.hasType('Poison')) || ...
    accuracy = true;
```

- 6·7세대 mod(`data/mods/gen7/moves.ts` `toxic`)는 같은 규칙을 `onSourceInvulnerability`(무적 통과)와 `onSourceAccuracy`(필중)로 **함께** 구현한다. 본가 규칙은 6세대부터 "필중 + 무적 통과"가 한 묶음이다.
- 비교: 노가드(`noguard.onAnyInvulnerability`)·록온(`lockon.onSourceInvulnerability`)도 무적 통과와 필중을 함께 가진다.

### 2-2. 문제

- 설계서는 새 줄을 "`alwaysHits`·`lockOn` 필중 분기 묶음 옆"에 둔다. 엔진에서 이 묶음이 **반무적 판정보다 앞**에 있으면(노가드·록온의 무적 통과를 위해 그럴 가능성이 있다), 새 줄도 무적 통과까지 해 버린다 → 설계서 §2 "이번에 하지 않는 것"과 어긋난다.
- 반대로 묶음이 반무적 판정 **뒤**에 있으면 설계서 의도대로 필중만 들어간다.
- 설계서에는 `computeBattleHitChance` 안에서 반무적 처리가 어디에 있는지 적혀 있지 않다(이 검수에서는 엔진 코드를 보지 못했다).

### 2-3. "싱글에서 드물다"의 근거

champions(M-C 출전 가능 349종) 기준 반무적 기술을 배우는 포켓몬 수:

| 기술 | 배우는 수 |
|---|---|
| 구멍파기 | 158 |
| 다이빙 | 44 |
| 공중날기 | 37 |
| 뛰어오르다 | 34 |
| 고스트다이브 | 32 |
| 섀도다이브·프리폴 | 0(출전 불가·습득 없음) |

- 상황은 "느린 독 타입이 맹독 → 빠른 상대가 같은 턴 1턴째에 구멍파기·공중날기" 하나뿐이다. 실제 빈도는 샘플 파티에 달렸지만, 배우는 수로 보면 "드물다"는 근거가 약하다.

### 2-4. 조치 (택1, 설계서에 명시)

- **A(권장)**: 엔진 반무적 판정이 `computeBattleHitChance` 안에 있으면 **새 줄을 반무적 판정 앞에 두고 무적 통과까지 이번에 넣는다.** 같은 한 줄이고, 본가·Showdown 모두 한 묶음 규칙이라 둘로 나눌 이유가 없다. 2차(E2 반무적 규칙 표)에서 이 항목을 다시 볼 필요도 없어진다.
- **B(설계서 현행)**: 미룬다면 새 줄은 **반무적 판정 뒤**에 둔다고 적고, 현재 동작을 시험으로 고정한다(§4 시험 8). E2 2차 표에 "독 타입 맹독 무적 통과(Showdown `:689`)"를 미해결 항목으로 넣는다.

## 3. 현재 타입 — champions에서 실제로 바뀌는 경우

- 설계서 §2 "현재 타입(`attacker.types`)"은 Showdown `hasType`(→ `getTypes()`, 변경·추가 반영)과 같은 방향이다. 다만 시험이 메가진화만 언급한다.
- champions에서 맹독 사용자의 타입이 바뀔 수 있는 기술:

| 원인 | 배우는 수 | 결과 |
|---|---|---|
| 물붓기(상대가 사용) | 10 | 독 타입 → 물 단일 → **필중 아님(0.9)** |
| 매직파우더(상대가 사용) | 1 | 독 타입 → 에스퍼 단일 → 필중 아님 |
| 미러타입(사용자) | 4 | 독 타입 상대를 복사하면 → 필중 |

- **메가진화로 독이 생기거나 사라지는 맹독 사용자는 없다**(독 타입 맹독 사용자 30종의 메가는 모두 독 유지, 비독 9종의 메가 헬가는 악/불꽃). 설계서 §3의 메가진화 문장은 틀리지 않지만 시험 대상으로는 물붓기가 맞다.
- 변환자재·리베로: Showdown은 `PrepareHit`(타입 변경)을 명중 단계보다 **먼저** 실행해 "변환자재 + 맹독 → 독 타입이 되어 필중"이 된다. 그러나 champions에서 **맹독을 배우는 변환자재·리베로 보유 포켓몬은 0**이라 이번에는 해당 없다. 설계서 §7에 한 줄 기록만 한다.

## 5. 영향 범위 보충

- champions에서 맹독을 배우는 포켓몬은 39종이고, 그중 **독 타입이 30종**(메가 포함)이다. 독 타입 맹독 사용자가 대부분이므로 샘플 파티에 맹독이 있으면 거의 확실히 해시가 바뀐다. 설계서 §4의 "구현 전에 샘플 수를 센다"에 동의한다.
- 비독 맹독 사용자 9종(찌리배리·글라이온·미끄래곤·헬가·메가헬가·화강돌·대로트·블래키·조로아크)은 현행 그대로다.
