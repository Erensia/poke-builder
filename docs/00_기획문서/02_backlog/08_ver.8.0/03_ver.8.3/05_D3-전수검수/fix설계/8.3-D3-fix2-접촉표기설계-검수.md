## 2. ❌ 구현 전 반영 필수

### 2-0. 핵심 원리 — 고정 데미지는 데미지 보정 단계를 거치지 않는다

```ts
// sim/battle-actions.ts getDamage
if (move.ohko) return ...maxhp;
if (move.damageCallback) return move.damageCallback.call(...);
if (move.damage === 'level') return source.level;   // ← 지구던지기는 여기서 끝
...
// 이후: BasePower 이벤트(단단한발톱), ModifyDamage/SourceModifyDamage(복슬복슬·파동의방호), ×0.25(방어 관통)
```
- 원인 → 결과: 지구던지기는 레벨만큼의 값을 곧바로 반환한다. 그래서 **위력·데미지 보정형 접촉 효과(단단한발톱·복슬복슬·파동의방호·방어 관통 ×0.25)는 지구던지기에 적용되지 않는다.**
- 반면 **명중 후 반응형**(`onDamagingHit`: 까칠한피부·철가시·울퉁불퉁멧·정전기·불꽃몸·독가시 등)은 데미지 계산과 관계없이 실행된다. 그래서 지구던지기에도 적용된다.
- 이 구분이 §2 표 전체를 다시 읽는 기준이다.

### 2-1. 복슬복슬·파동의방호 — 바뀌는 쪽은 지구던지기가 아니다

```ts
fluffy:    onSourceModifyDamage: Fire ×2, contact ×0.5
auraguard: onSourceModifyDamage: contact ×0.5   // 파동의방호, champions에서 사용 가능
```

| 기술 | 변경 전(접촉) | 변경 후(Showdown) | 비고 |
|---|---|---|---|
| 불새·트림·바늘미사일 | ×0.5 | **×1** (데미지 2배로 증가) | — |
| **대격분(불꽃)** vs 복슬복슬 | 불꽃 ×2 · 접촉 ×0.5 = ×1 | **×2** | 가장 크게 바뀐다 |
| 지구던지기 | ×1 (비접촉) | **×1 (그대로)** | 고정 데미지라 보정 단계에 들어가지 않음(§2-0) |

- 해당 특성 보유(Showdown 도감 기준, champions 출전 여부는 엔진 목록으로 좁힐 것): 복슬복슬 — 포곰곰·이븐곰·우르·배우르·묘두기·묘지기. 파동의방호 — 메가루카리오 Z폼(`lucariomegaz`, champions 신규).
- 설계서 수정: §2 표의 이 두 행을 위 내용으로 바꾼다.
- **엔진 확인 필요**: 엔진의 복슬복슬·파동의방호가 최종 데미지에 일괄 곱하는 구조라면, 이번 정정 후 지구던지기가 절반이 되는 **새 오차**가 생긴다. 고정 데미지 기술이 이 보정을 건너뛰는지 확인한다.

### 2-2. 단단한발톱 누락 — 메가 2종의 화력이 바뀐다

```ts
toughclaws: onBasePower: contact → chainModify([5325, 4096])   // ×1.3
```

| 보유자 | 해당 기술 | 변경 |
|---|---|---|
| **메가프테라** | 불새 | ×1.3 **없어짐** |
| **메가갑주무사** (champions 신규 메가) | 바늘미사일 | ×1.3 **없어짐**(타수마다) |
| 지구던지기 습득 종 | — | 단단한발톱 보유자 없음. 있더라도 고정 데미지라 영향 없음 |

- 원인 → 영향: 설계서 §2의 "설명문에 '접촉'이 든 특성 18종"은 반응형으로 묶여 있다. 그러나 단단한발톱은 반응이 아니라 **위력 보정**이다. 실전 메가 2종의 데미지가 직접 줄어들므로 `regress`·`greedy` 해시가 바뀔 가능성이 높다(§6 "0일 수도"는 가능성이 낮다).
- AI `moveDamage.ts`가 단단한발톱을 `makesContact`로 판정한다면 자동으로 따라간다. 하드코딩된 기술 목록이 있으면 같이 고친다.

### 2-3. 방어류 접촉 반응 누락

[소스] 킹실드·니들가드·토치카(champions에서 사용 가능. 블로킹·실크트랩·불꽃의수호는 `Past`)는 기술을 **막았을 때** `checkMoveMakesContact`이면 반응을 준다.

| 기술 | 막혔을 때 반응(킹실드 공격 −1 · 니들가드 1/8 · 토치카 독) |
|---|---|
| 불새(공격 턴)·트림·대격분·바늘미사일 | 있음 → **없어짐** |
| 지구던지기 | 없음 → **생김** |

- 바늘미사일이 막히면 반응은 1회다(방어 판정이 기술당 1회).
- B9 확정(관통드릴·보이지않는주먹으로 뚫어도 반응 발동)과는 별개다. 이 항목은 **일반 공격이 막히는 경우**다.

### 2-4. Q2·§7 — 관통 시 지구던지기 데미지는 정해져 있다

- [소스] 방어 관통 ×0.25는 `modifyDamage` 안에 있다. 고정 데미지는 그 전에 값을 반환한다(§2-0). 따라서 **관통드릴 + 지구던지기 vs 방어 = 레벨 데미지 그대로(Lv50이면 50)**, ×0.25가 없다.
- 이것은 **B9 검수 §3 4번 결정("일격기 및 고정 데미지는 ×0.25에서 제외, 방어 관통 자체는 적용")과 같다.** 설계서 §7의 "데미지 규칙을 모른다 → E2 후보"는 "B9 규칙대로 50"으로 바꾼다. B9가 그 가드를 이미 구현했다면 이번 PR에서는 시험만 추가하면 된다.
- 뚫었을 때 방어류(킹실드·니들가드·토치카) 반응은 B9 확정에 따라 **발동**한다(Showdown은 미발동, 의도적 차이).
- **실전 영향 없음**: champions에서 관통드릴은 메가몰드류, 보이지않는주먹은 메가골루그뿐이다. 둘 다 이번 5개 기술을 배우지 않는다. 지구던지기 습득 8종(괴력몬·쁘사이저·헤라크로스·입치트·부란다·내던지기·케오퍼스·저승갓숭)에도 두 특성 보유자가 없다. 원격(모크나이퍼 계열)도 마찬가지다. **§5의 관통·원격 시험은 특성을 강제로 붙인 시험 전용 경로**이며, 해시에는 영향이 없다.
