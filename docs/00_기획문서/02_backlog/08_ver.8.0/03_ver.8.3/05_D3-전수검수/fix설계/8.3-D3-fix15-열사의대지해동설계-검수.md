## 1. 소스 대조

```ts
// data/conditions.ts frz (champions는 inherit: true로 onStart·onBeforeMove만 재정의 → 아래 두 핸들러는 그대로 상속)
onModifyMove(move, pokemon) { if (move.flags['defrost']) { ...; pokemon.clearStatus(); } }      // ① 사용자 해동
onAfterMoveSecondary(target, source, move) { if (move.thawsTarget) target.cureStatus(); }       // ② 맞은 상대 해동
onDamagingHit(damage, target, source, move) {                                                   // ③ 불꽃 해동
  if (move.type === 'Fire' && move.category !== 'Status' && move.id !== 'polarflare') target.cureStatus();
}
```

## 2. 보완

### 2-1. [필수] 우격다짐 + 열사의대지 — 시험 10 추가
- 사전 메모(fix-14 검수 §5)의 "선택 항목"은 **실전 조합이 있어 필수로 올린다.** 챔피언스에서 열사의대지를 배우는 우격다짐 포켓몬이 있다: **강철톤(숨겨진 특성 우격다짐, `learnsets.ts`에 `scorchingsands`, `formats-data` 합법)**. 열탕을 배우는 우격다짐 포켓몬은 없다.
- Showdown 동작:
  - `sheerforce.onModifyMove`는 `secondaries`(화상 30%)만 지우고 `thawsTarget`은 남긴다. 위력 ×1.3.
  - `sim/` 기본은 `if (!suppressingSecondaries())`로 ②를 막지만, **champions `hitStepMoveHitLoop`(575)는 이 검사 없이 ②를 부른다**(422행 주석: "Sheer Force doesn't suppress AfterMoveSecondary events"). → **챔피언스에서 우격다짐 강철톤의 열사의대지는 얼음 상대를 녹인다(화상은 없음).**
- 엔진 확인: `healAndThaw`의 `curesStatus` 갈래가 우격다짐(부가효과 억제) 판정과 묶여 있으면 해동이 빠진다. 이번에 가드를 넣을 때도 **우격다짐 조건을 섞지 않는다.**
- 시험 10: 우격다짐 강철톤 → 얼음 상대에 열사의대지 → 해동됨, 화상 없음. 현행에서 실패하면 같은 PR에서 고친다(Q2 범위 안 — 해동 규칙 한 덩어리).

### 2-2. [권고] 시험 8에 불꽃 기술 포함
가드는 ②·③ 두 갈래에 들어가는데 시험 8은 열탕·열사의대지만 적혀 있다. 시험 7처럼 **불꽃 데미지 기술의 빗나감·방어**도 넣어 두 갈래를 모두 고정한다.

### 2-3. [권고] 시험 9 보강 — 사용자 해동은 빗나감·방어와 무관
Showdown ①은 `useMoveInner`의 `ModifyMove`(503)에서 일어나고 이것은 명중·방어 판정(`trySpreadMoveHit`, 582)보다 앞이다. **얼어 있는 사용자의 열사의대지가 빗나가거나 방어돼도 사용자는 녹는다.** 새 가드(`c.hit` 등)가 자기 해동 경로에 번지지 않았는지 확인하는 사례로 시험 9에 "빗나감·방어돼도 사용자 해동" 1건을 추가한다.

### 2-4. [권고·선택] 대타 관통
틈새포착(Infiltrator)처럼 대타를 무시하고 맞히면 Showdown은 대상을 `null`로 바꾸지 않으므로 해동된다. 엔진의 `hitSubstitute`가 관통 시 `false`면 자동으로 맞는다. 시험 7 옆에 "틈새포착 + 불꽃 기술 → 대타 있는 얼음 상대 해동" 1건이 있으면 가드가 과하게 막는지 확인된다(챔피언스 합법 예: 드래펄트).

### 참고(범위 밖)
③ 불꽃 해동은 **기술의 최종 타입**(`move.type`)으로 판정한다(쾌청 웨더볼, 오거폰 화덕의 가면 등). 엔진이 원래 타입으로 판정한다면 별도 항목이다. 이번 PR에서 가드를 넣다가 눈에 띄면 기록만 남긴다.
