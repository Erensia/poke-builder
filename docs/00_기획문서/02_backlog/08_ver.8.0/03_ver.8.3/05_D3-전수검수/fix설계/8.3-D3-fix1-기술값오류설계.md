**상태**: 검수 반영 완료(2026-11-16, `8.3-D3-fix1-기술값오류정정-검수.md`: 조건부 승인 → 누락 3건 반영) — **구현 전.** 근거: `8.3-D3-E0-검수.md` §2-1·§2-3, 원자료 `05_D3-전수검수/자료/D3-검수자료/E0-원자료.txt`.
**PR 묶음**: ① 기술 값 오류(이 문서) → ② 접촉 표기(D3-E0-09~13) → ③ PP 25건. 각각 PR 1개·커밋 1개.
**엔진 코드 변경(데이터 외) — 세 곳뿐이다**
1. **반동 반올림**(Q5): `hitResolution.ts:921` `floor` → `Math.round`·최소 1. **33% 기술만이 아니라 양날박치기·파멸의빛(1/2)·와일드볼트(1/4)도 바뀐다.** AI 평가 `moveDamage.ts:225`는 소수 그대로 계산하므로 정합 확인만.
2. **막말내뱉기 조건부 교체**: 새 필드 `selfSwitchIfStatLowered`(`types/move.ts`) + `runTurn.ts:364` 부근에 분기 하나. 썰렁개그의 `selfSwitchAfterUse`는 **무조건 교체**(`runTurn.ts:361~367` 주석: 효과 실패해도 교체)라 못 쓴다. 행동 기록에 `loweredDefenderStats`(상대 랭크가 실제로 떨어짐)와 `loweredAttackerStats`(미러아머 반사로 사용자가 떨어짐)가 이미 있어 "둘 중 하나라도 비어 있지 않으면 교체"로 표현된다.
3. **썬더다이브 자해 조건**: `hitResolution.ts:800~812`는 방어에 막힘·타입 면역만 자해한다. 흡수 특성 무효(축전·피뢰침·전기엔진 등)가 빠져 있으면 조건 추가(구현 때 시험 3번 사례로 확인 — 빠졌다면 코드 변경, 이미 들어 있으면 시험만).

## 5. 위험·한계

- 반동 반올림은 **기존 반동 기술 전체의 기준 출력을 바꾼다**(1/2·1/4 포함) — 단계 ③에서 변동이 이 범위 안인지 확인한다.
- 막말내뱉기는 엔진에 "상대 랭크 하락 + 조건부 자기 교체 + 소리 + 반사" 조합이 처음이다. 교체 분기는 새 필드로 따로 두어 기존 유턴류·썰렁개그 경로를 건드리지 않는다.
- 트라이어택 확률이 18.7% → 20%로 오른다(마비 쏠림 해소). AI 평가가 `inflictsStatus`를 읽는 곳이 있으면 `inflictsRandomStatus`도 같이 읽는지 확인한다(페이탈클로 선례).
- 짓궂은마음 악 타입 무효(위) · 페인트 방어 해제 · 작아지기 최종 데미지 2배는 이 PR 밖이다.
