## 1. 무엇이 다른가
| 항목 | Showdown | 엔진 |
|---|---|---|

| 난수 | 85~100% 16단계 정수 | `MIN_DAMAGE_ROLL + random × (1 − MIN)` 연속값(본 피해 경로는 16단계) |

## 2. 고칠 것
1. `volatileConditions.ts` `CONFUSION_SELF_HIT_CHANCE = 0.33`(주석에 Showdown `randomChance(33, 100)`). 같은 상수를 쓰는 AI(`turnRates.ts:318·382`)도 함께 바뀌어 엔진·AI가 일치한다.
2. `preHitEffects.ts` 혼란 자해(약 435~440행)의 `computeDamage` 옵션에 `attackerStages: c.attacker.stages, defenderStages: c.attacker.stages`(자기 랭크 — 같은 포켓몬이므로 둘 다 자기 것), `randomRoll: (DAMAGE_ROLL_MIN_PERCENT + Math.floor(c.random() * DAMAGE_ROLL_STEP_COUNT)) / 100`. **난수 호출 횟수는 그대로 1회**(자해 굴림 1 + 피해 굴림 1)라 난수열 위치는 바뀌지 않는다.
   - **굴림 식은 본 피해 경로와 같은 함수·상수식을 그대로 재사용한다**(검수 §2-2). Showdown은 `100 − random(16)`(작은 난수 → 100%), 엔진은 `85 + floor(r × 16)`(작은 난수 → 85%)로 방향이 반대이나 분포는 같다. 자해만 다른 식을 쓰면 시험 1의 "단계 지정"이 두 경로에서 엇갈리므로, 시험 1은 본 피해 경로의 매핑 기준으로 단계를 지정한다.
   - **랭크를 처음 넘기는 PR이므로 특성·도구 옵션은 자해 호출에 넘기지 않는다**(검수 §2-1 필수). `computeDamage`가 `attackerAbility`/`defenderAbility`로 천진을 처리하는 구조면 공격·방어가 같은 포켓몬인 자해에서 자기 천진이 자기 랭크를 지우는 경로가 새로 열린다. Showdown은 `calculateStat`이 `ModifyAtk/Def`·`ModifyBoost`를 부르지 않아 천진(자기·상대)·천하장사·구애머리띠·화상 반감이 모두 무영향이다. 구현 첫 단계에서 `computeDamage`의 옵션 처리를 읽고, 현행 호출이 이 옵션들을 안 넘기면 코드 변경 없이 시험 5만 통과하면 된다.
3. 최소 1: Showdown은 `max(1, 피해)`. 엔진 `computeDamage` 결과가 0일 수 있는지(`selfHit?.damage ?? 0`) 구현 첫 단계에서 확인하고 필요하면 `Math.max(1, …)`(HP 실수 1 방지 — 위력 40·Lv50이라 사실상 항상 ≥ 1이면 시험으로만 고정).
4. **AI 기대값**: `turnRates.ts` `confusionSelfHitFraction(target)`이 자해 피해 비율을 어떻게 계산하는지(랭크 반영 여부)를 구현 첫 단계에서 grep으로 확인한다. 랭크를 안 쓰면 엔진과 같은 방식으로 한 줄 맞추고(AI 일치), 이미 쓰면 변경 없음.

## 3. 영향·측정
혼란을 건 시뮬(이상한빛류)에서 자해 확률·피해가 바뀌어 `regress` 해시가 바뀔 것이다. 단계 하나(33% 상수와 피해식을 한 번에): `regress 200`·`regress 20000`·`STATUS=1 greedy 60`(약 3분, `SERIAL=1`) 뒤 `SERIAL=1 verify.sh`(약 8분) → 기준값 갱신 → 재검증. **원인 분리**: 해시가 바뀌면 33% 상수만 되돌린 변형으로 `regress 200`(약 5초)을 재서 확률 vs 피해식 기여를 나눠 보고한다. 불변이어야 하는 것: `test:inference` 결합 `ec4a4164caf2846c`·차분 해시(역산·계산 함수는 혼란 자해와 무관).

## 4. 시험 `47-ver83-d3fix16.mjs` (먼저 쓰고 현행 코드에서 실패 확인)
1. **참조 구현 일치**: Showdown 식을 그대로 옮긴 참조 구현과 엔진 자해 피해를 비교 — 실능 공격·방어 조합 × 랭크 −2~+2 × 난수 0~15단계 전수(엔진 쪽은 `c.random` 고정값으로 단계 지정).
2. **자기 랭크 반영**: 공격 +2인 혼란 포켓몬의 자해 피해 > 랭크 0인 같은 포켓몬(현행은 같음 → 실패). 방어 +2는 반대로 작아짐.
3. **확률 경계**: `random` 0.329 → 자해, 0.331 → 자해 안 함(현행 0.331은 자해 → 실패).
4. **난수 호출 수**: 자해한 행동에서 `c.random` 호출이 2회(굴림 + 피해 단계)이고 안 하면 1회 — 난수열 이동 방지 확인. **혼란 지속이 0이 되어 풀리는 행동은 난수 0회**(Showdown은 굴림 없이 해제, 검수 §1).
5. **무영향 목록(필수, 검수 §2-1)**: 급소·화상·자속·타입은 영향 없음 — 화상인 혼란 포켓몬·자속 있는 포켓몬의 자해 피해가 같은 조건의 중립 포켓몬과 같다. 추가로 ① **천진 픽시**(챔피언스 합법, 숨겨진 특성) 공격 +2 자해 = 천진이 아닌 같은 조건(+2 반영), ② **상대가 천진**이어도 같음, ③ **천하장사 마릴리**(·순수한힘 메가요가램)·**구애머리띠** 보유 자해 = 중립 포켓몬과 같음.
6. 혼란 지속·소모는 불변(E4b-01): 자해 굴림 횟수가 1~4회인 분포 유지.
7. 최소 1: 극단적으로 낮은 공격·높은 방어(랭크 +6 방어)에서도 피해 ≥ 1.
8. AI: `turnRates`의 자해 확률 상수가 엔진과 같은 값(0.33)을 쓰는지.

- **Q1**: 33% 변경을 이 PR에 묶는 것(권고 — 같은 규칙 한 덩어리, 해시 원인은 §3 변형으로 분리)과 분리하는 것 중 선택.
