## 3. R1·R2(필수): 잠자기 실패 조건 보강

Showdown 판정 순서(`Rest.onTry` → `onHit`의 `setStatus`):
1. **이미 수면**(잠꼬대 경유) → 실패
2. 풀피 → `-fail heal`
3. 불면·의기양양 → `-fail [from] ability`
4. `setStatus` 실패: 스위트베일·정화의소금·리프가드(쾌청) / 일렉트릭필드(접지) / **미스트필드(접지)** / 소란 → 실패. **플라워베일·신비의부적은 자기 자신이라 막지 않는다.**

권고:
- §3-5 조건 3을 **"일렉트릭필드 또는 미스트필드 + 접지, 소란피기 중"**으로 넓힌다. 문구는 Q1 방침대로 `statusInflictFailed`.
- §3-5에 **0번 "이미 수면이면 실패"**를 추가한다(한 줄). 구현 전 엔진의 잠꼬대가 잠자기를 고를 수 있는지 확인 — 고를 수 있다면 현행은 수면 중 HP 완전 회복 + 수면 카운터 재설정으로 Showdown과 크게 다르다. 고를 수 없게 막혀 있다면 그 자체가 다른 어긋남이므로 기록만 한다.
- 조건 2의 특성 판정은 `abilityBlocksStatus`를 그대로 쓰지 말고 **자기 자신 대상**으로 판정한다(플라워베일 제외, 리프가드 쾌청 포함). `abilityBlocksStatus(fighter, ability, status, {self: true})` 같은 인자 하나로 충분하다.
- `restFails(state, key)`(AI 공용)에 위 조건이 전부 들어가므로 AI도 함께 맞는다(Q3).
- 도달: 미스트필드 습득 35종(픽시·가디안·플라제스 등, 미스트시드 합법), 잠자기+잠꼬대 319종, 리프가드+잠자기 3종(메가니움·리피아·달코퀸).

## 7. N1·N2 (확인)

- **N1 틀깨기·틈새포착**: `statusBlockReason`의 `ability` 인자가 틀깨기로 무시된 뒤의 값인지, 신비의부적 판정이 사용자 틈새포착을 보는지 확인한다. 아니면 "콜로솔트의 정화의소금!" 줄이 나오면서 마비가 안 걸린다. 합법 도달: 틀깨기+전기자석파 1종(두드리짱), 틈새포착+도깨비불 3종·하품 2종·전기자석파 3종·최면술 2종.
  - 참고: 틀깨기 도깨비불 vs 열교환은 Showdown에서 "화상 → 즉시 치료"다. 엔진이 턴 끝에 치료하면 화상 데미지가 한 번 들어갈 수 있으나 champions 합법 조합(틀깨기+도깨비불)이 없어 기록만 한다.
- **N2**: §3-2 `abilityBlocksStatus`에 플라워베일이 들어 있으므로 잠자기에 쓰면 R1의 자기 자신 판정 인자가 필요하다(위 §3).
