## 2. ❌ 구현 전 반영 필수

### 2-1. 막말내뱉기 — 교체가 조건부다 (Q1)
Showdown `partingshot`: 변화·악·명중 100·PP 20·우선도 0, 플래그 `protect·reflectable·mirror·sound·bypasssub`, `selfSwitch: true`. 설계서 값(변화기·소리·−1/−1·교체)은 맞다. 그런데 교체는 **무조건이 아니다**.

```
onHit(target, source, move) {
  const success = this.boost({ atk: -1, spa: -1 }, target, source);
  if (!success && !target.hasAbility('mirrorarmor')) delete move.selfSwitch;
}
```

| 상황 | Showdown 결과 | 썰렁개그(무조건 교체)와 다른 점 |
|---|---|---|
| 상대 공격·특공이 모두 −6, 클리어바디·하얀연기 등으로 둘 다 실패 | **교체하지 않는다** | 있음 |
| 둘 중 하나라도 떨어짐 | 교체 | — |
| 상대가 미러아머 | 랭크 하락이 사용자에게 반사되고 **교체는 한다** | 있음 |
| 상대가 방어 | 막힘(실패) → 교체 없음 | 있음(썰렁개그는 자기 대상) |
| 상대가 방음 | 무효 → 교체 없음 | 있음 |
| 상대가 대타 | 소리 + `bypasssub` → 대타 무시하고 적중 | — |
| 상대가 매직미러 | `reflectable` → 반사. 반사한 쪽이 기술을 **사용**하므로(`useMove(newMove, target)`) 반사한 포켓몬이 교체 대상이 된다 | Showdown 소스 동작. 엔진 B6(매직미러 반사) 경로와 일치하는지 확인 |
| 교체할 포켓몬이 없음 | 랭크 하락만, 기술은 성공 | — |

- **변화기가 되므로 특성 `짓궂은마음`의 우선도 +1이 붙는다.** 엔진 습득기 7종 중 오롱털이 짓궂은마음을 가진다 → 악 타입 상대에게는 무효(교체 없음). 물리기일 때는 없던 경로다.
- 설계서 §5 "새 코드는 없을 것"은 **교체 취소 조건이 기존 `selfSwitchAfterUse`로 표현되는지**에 달렸다. 썰렁개그용 필드가 무조건 교체라면 "랭크 하락이 하나라도 성공했을 때만 교체(미러아머는 예외)"를 넣는 코드가 필요하다. Claude Code에서 필드 의미를 확인해 설계서 헤더와 §5를 고친다.
- 태그: `sound`뿐 아니라 **반사 대상(`reflectable`)** 과 방어에 막힘(`protect`)도 데이터에 넣는다. 반사 대상 60개(D3 검수 F8)에 막말내뱉기가 들어 있으므로, 엔진 반사 목록이 기술 id 기준이면 이미 들어 있는지도 확인한다.

### 2-2. 썬더다이브 — 사용자 확인으로 보류 해제, 단 2가지 추가 (Q2)
사용자가 게임에서 확인한 값: **위력 100·명중 95·PP 16·우선도 0, 빗나가거나 실패하면 최대 HP 1/2 자해, 작아지기 상태인 상대에게 위력 2배·반드시 명중.** Showdown `supercellslam`(`pp 15` → 최대 PP 16, `hasCrashDamage`, `onMoveFail`, `flags.minimize`)과 **완전히 같은 기술**이다. 따라서 엔진 습득기(잠만보·전룡 등)는 맞고, 엔진의 130·85·마비 20%만 틀렸다.

설계서 표 E0-02에 다음을 더한다.

| 추가 항목 | Showdown 근거 | 엔진 확인 |
|---|---|---|
| **작아지기 상대 ×2·필중** | `minimize` 상태의 `onSourceModifyDamage`(×2)·`onAccuracy`(true)가 `flags.minimize` 기술에 적용. 누르기·헤비봄버·히트스탬프 등과 같은 플래그 | 엔진에 작아지기 대상 기술 플래그·목록이 있는지. 목록이 코드에 하드코딩돼 있으면 코드 변경 |
| 자해 조건 = 기술 실패 전체 | `trySpreadMoveHit`이 대상 0개로 끝나면 `MoveFail` → 자해. 빗나감·방어·땅 타입 무효·축전/피뢰침/전기엔진 흡수·공중날기 등 무적 상태 **모두** 자해 | 엔진 `crashFraction`(무릎차기)이 빗나감 외 실패에도 발동하는지. 대타 적중은 성공이라 자해 없음 |
| 이판사판 ×1.2 | `reckless`: `move.recoil || move.hasCrashDamage` | 습득기 거대코뿌리가 이판사판을 가진다. 엔진 이판사판이 `crashFraction` 기술도 보정하는지 |
| 자해량 | `floor(최대 HP / 2)`, 매직가드면 없음, 돌머리는 막지 못함(반동이 아님) | — |
| 설명문 "위력 2배" | Showdown은 위력이 아니라 **최종 데미지 ×2**로 구현 | 엔진도 같은 단계(최종 보정)인지 |

### 2-3. 반동 반올림 — 바뀌는 범위가 33% 기술만이 아니다 (Q5)
- Showdown `sim/battle-actions.ts`: `clampIntRange(Math.round(damageDealt * recoil[0] / recoil[1]), 1)` — **반올림·최소 1** 확인. champions `scripts.ts`에 재정의 없음.
- 엔진 `hitResolution.ts:921`의 `floor`를 고치면 **모든 반동 기술**이 바뀐다. 출전 가능(champions 습득기 기준) 비 33% 반동 기술: **양날박치기·파멸의빛(1/2), 와일드볼트(1/4)**. 1/2 반동은 피해가 홀수면 1 차이가 난다(99 → floor 49 / round 50).
- `0.33` 표기는 안전하다: 피해 1~2000에서 `Math.round(d × 0.33)`과 `Math.round(d × 33/100)`의 결과가 모두 같다(이 채팅에서 계산).
- 설계서 수정: 헤더 "엔진 코드는 바꾸지 않는다"에 Q5 예외(코드 1줄 + AI 평가 1곳)를 적고, §3 시험 5번에 1/2·1/4 반동 사례를 더한다.

## 3. ⚠️ 보완

### 3-1. 트라이어택 — "6.67%×3 = 20%"는 판정 방식에 따라 동등하지 않다 (Q4)
- Showdown: **20% 한 번** 판정 → 화상·마비·얼음 중 하나를 고르게 선택(`sample`) → `trySetStatus`(선택된 상태가 무효면 다시 고르지 않음).
- 엔진이 6.67% 판정을 **세 번 따로** 한다면 하나 이상 걸릴 확률은 1 − (1 − 1/15)³ ≈ 18.7%다. 하늘의은총(2배)이면 Showdown 40% vs 약 35%로 차이가 커진다. 앞쪽 판정이 먼저 걸리는 순서 편향도 생긴다.
- 권고: 엔진 구현을 확인한다. 세 번 따로라면 E0 문서에 나온 무작위 상태 필드(`inflictsRandomStatus`, 페이탈클로와 같은 방식)로 "20% 한 번 + 3개 중 하나"로 바꾼다. 같은 PR에 넣으면 해시 변동 원인이 겹치므로 §4 단계 측정에 별도 단계로 둔다.
- 분류 특수 정정은 ✅. 물리 공격 기반 평가가 바뀌는 것은 본가와 맞추는 변화라 문제없다.

### 3-2. 암석액스 급소율 — 보류할 이유가 없다 (Q6)
`stoneaxe`에는 `critRatio`가 없고 champions 재정의도 없다 → **급소 단계 보통**. 본가(9세대)도 급소 보정이 없다. 엔진 "높음"은 E0-07(메가톤킥)과 같은 유형의 데이터 오류이므로 **이 PR에 포함**하는 것을 권한다(D3-E0-17 → 수정필요).

### 3-3. 페인트 방어 해제 — Showdown 기준값 ([실행] 대기 2)
- `feint`: 우선도 +2, 플래그에 `protect`가 **없음** → 방어류에 막히지 않음. `breaksProtect: true` → `hitStepBreakProtect`가 상대의 방어·킹실드·니들가드·토치카·블로킹·실크트랩·불꽃의가드 상태를 지우고, 9세대에서는 상대 쪽의 트릭가드·마룻바닥세워막기·패스트가드·와이드가드도 지운다. 지운 게 있으면 `-activate`(방어 해제) 로그.
- 엔진 `bypassesProtect false`면 페인트가 방어에 막힐 가능성이 크다. 이것은 동작 수정이라 D3 검수 §5 Q5 원칙(데이터 수정과 동작 수정은 다른 PR)에 따라 **E2에서 수정필요로 다룬다.**

### 3-4. 막말내뱉기·썬더다이브 이름 ([실행] 대기 3)
- PokeAPI 한국어 공식 이름: 575 `parting-shot` = **막말내뱉기**, 916 `supercell-slam` = **썬더다이브**. 엔진 이름은 맞다.
- champions 습득기(`mods/champions/learnsets.ts`): 막말내뱉기 7종(알로라 페르시온·부란다·어흥염·폭슬라이·오롱털·모르페코·시비꼬), 썬더다이브 10종(잠만보·전룡·썬더볼트·렌트라·램펄드·거대코뿌리·저리더프·찌르성게·찌리배리·빠르모트)으로 **설계서 표의 종 목록과 완전히 같다.** 이름·습득기는 맞고 기술 데이터 내용만 다른 기술 값이 들어간 것이다.
