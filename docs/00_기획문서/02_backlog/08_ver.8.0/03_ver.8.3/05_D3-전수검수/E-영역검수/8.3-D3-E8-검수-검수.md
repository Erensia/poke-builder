## 0. 먼저 알아둘 것

1. **champions 모드는 이 16종을 재정의하지 않는다.** `mods/champions/abilities.ts`의 14종에 없고, `scripts.ts`·`conditions.ts`도 날씨·필드 설정(`field.ts` `setWeather`·`setTerrain`)을 건드리지 않는다. 기준은 기본 `data/abilities.ts`·`sim/field.ts`다. champions `formeChange`(메가진화)는 기절 후 되돌림만 바꿨고 `setAbility(…, isFromFormeChange=true)` 호출은 기본과 같다.
2. **메가진화가 실제 진입점이다(설계서 R4② 확인).** 합법 메가 중 이 묶음 특성을 **얻는** 것: 메가리자몽Y(가뭄)·메가라이츄X(일렉트릭메이커)·메가후딘·메가냐오닉스(트레이스)·메가썬더볼트(위협)·메가갸라도스·메가전룡·메가염무왕(틀깨기)·메가눈여아(눈퍼뜨리기). **같은 특성을 다시 얻는** 것: 메가마기라스(모래날림)·메가눈설왕(눈퍼뜨리기)·메가곤율거니(위협)·메가개굴닌자(변환자재). **잃는** 것: 갸라도스·보만다·찌르호크(위협)·프테라·앱솔(프레셔)·가디안(트레이스) 등. 샘플의 가뭄 1·일렉트릭메이커 1·트레이스 1슬롯이 메가 보유자인지 먼저 확인할 것을 권한다.
3. **`setAbility`는 같은 특성이어도 `End` → 상태 초기화 → `Start`를 다시 부른다**(`sim/pokemon.ts`). 그래서 메가곤율거니는 **위협이 두 번**, 메가마기라스는 **비를 모래바람으로 다시 덮고**, 메가개굴닌자는 **변환자재를 한 번 더** 쓸 수 있다(§1 W5·I4·R7). 엔진에서 가장 어긋나기 쉬운 지점이다.

### P. 프레셔 — 규칙 정밀화(2026-11-26 재확인)
**소스**: `battle-actions.ts` 531~547행 + `pokemon.ts` `getMoveTargets` 867~876행. 추가 PP = **`pressureTargets` 중 상대편 프레셔 보유자 수**. `pressureTargets`는 기술의 **실제 대상 목록**이고, 예외 두 가지가 있다: `foeSide`는 빈 목록(단 `mustpressure` 플래그면 상대 전원), `mustpressure` 플래그는 대상과 무관하게 상대 전원.

| 대상 종류(`target`) | 예 | PP 소모 |
|---|---|---|
| `normal`·`any`·`scripted`·`allAdjacentFoes`·`randomNormal` | 몸통박치기·독가루·카운터 | **2** |
| `all`(필드 전체) | 흑안개·트릭룸·비바라기 | **2** |
| `foeSide` + `mustpressure` | 압정뿌리기·스텔스록·독압정 | **2** |
| `foeSide`(플래그 없음) | **끈적끈적네트** | **1** |
| `self` | 칼춤·대타출동·방어·HP회복 | **1** |
| `self` + `mustpressure` | **봉인** | **2** |
| `allySide` | 리플렉터·빛의장막·순풍 | **1** |
| 빗나감 / 프레셔 쪽 방어에 막힘 | 최면술 / 몸통박치기 | 2(PP는 판정 전에 깎임) |
- 호출 기술(잠꼬대 등)이 부른 기술의 추가 PP는 **호출한 기술**(잠꼬대)에서 깎인다(`callerMoveForPressure`) — 참고.
