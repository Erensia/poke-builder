## 2. 재확정 (2026-11-12, 사용자 승인: Showdown 동작 채택)

### R7 — 교체할 확정 문구
> **길동무**는 방어류 카운터(`protectStreak`)에서 완전히 분리한다. 같은 포켓몬의 **직전 행동이 성공한 길동무**이면 이번 길동무는 100% 실패한다(다른 기술 사용·행동 불능·교체 시 해제, 실패 후 다음 사용은 성공 → 성공/실패가 번갈아 나옴).
> **버티기**는 방어·판별·킹실드와 같다: **이번 턴 마지막에 행동하면 실패**하고, 연속 사용 확률 판정도 공유한다. 실패하면 `protectStreak`은 **0으로 초기화**된다(올라가지 않음).
> **패스트가드·와이드가드**는 연속 사용 확률 판정을 받지 않지만 **마지막에 행동하면 실패**한다. 성공하면 `protectStreak`을 올려 다음 턴 방어류의 확률을 깎는다.
> AI `protectSuccessChance`도 같은 규칙으로 맞춘다.

근거
- [소스] `data/moves.ts` endure: `onPrepareHit(pokemon) { return !!this.queue.willAct() && this.runEvent('StallMove', pokemon); }` — protect와 동일. 성공 시에만 `onHit`에서 `addVolatile('stall')`.
- [소스] `data/conditions.ts` stall: 판정 실패 시 `delete pokemon.volatiles['stall']`, 성공한 기술이 없으면 duration 2 만료 → 카운터 초기화.
- [소스] quickguard·wideguard: `onTry() { return !!this.queue.willAct(); }`, `onHitSide`에서 `addVolatile('stall')`(StallMove 판정 없음).
- [소스] destinybond: `onPrepareHit(pokemon) { return !pokemon.removeVolatile('destinybond'); }`, 다른 기술의 `onBeforeMove`·`onMoveAborted`에서 볼라타일 제거. `stallingMove`·`stall` 미사용.
- [실행] 빠른 한카리아스 방어 → 잠만보 버티기(마지막 행동): `|move|p1a: Snorlax|Endure||[still]` / `|-fail|p1a: Snorlax`
- [실행] 팬텀 길동무 3연속: 성공(`-singlemove`) → 실패(`-fail`) → 성공

### R8 — 교체할 확정 문구
> 배틀스위치의 폼 변경은 **기술 자체의 실패 판정보다 먼저** 일어난다. 폴터가이스트(상대 도구 없음)·기습(상대가 공격하지 않음) 등이 **실패해도 폼은 바뀐다**. 킹실드가 실패해도 실드폼으로 돌아간다.
> 상태이상(마비·수면·빙결)·풀죽음·혼란(자해 포함)으로 **행동하지 못하면 폼 불변**(현재 유지).
> 폼이 바뀌면 엔진이 `turnResults`에 폼 변경 이벤트를 넘기고 UI가 받는다 — 로그 "킬가르도는 블레이드폼으로 폼체인지했다!" / "킬가르도는 실드폼으로 폼체인지했다!"(기술 사용 줄보다 **앞**), 스프라이트 교체·[실드폼]/[블레이드폼] 배지(필수), 팝 모션(권장).

근거
- [소스] `data/abilities.ts` stancechange: `onModifyMove`에서 `formeChange`.
- [소스] `sim/battle-actions.ts`: `runEvent('ModifyMove')`(:503)가 `singleEvent('Try')`(:652·:885)보다 앞 → `onTry`의 도구 확인 실패 전에 폼이 바뀜. 행동 불능은 그보다 앞인 `BeforeMove`에서 끊김.
- [실행] 도구 없는 잠만보에게 폴터가이스트:

## 3. 일치 항목 보충 (확정 문구에 추가 권장)

### R1 돌림노래
- [실행] 같은 턴 상대의 선행 돌림노래 → 뒤 돌림노래 `BP doubled`. 다음 턴 연속 사용은 2배 아님.
- 엣지: 2배 판정은 **선행 돌림노래가 `onTry` 단계에 도달했는지**로 정해진다. 선행 쪽이 빗나가거나 방어에 막혀도 2배, 선행 쪽이 수면·마비·풀죽음으로 행동하지 못하면 2배 아님.
- Q1-3 배경: Showdown은 `queue.prioritizeAction`으로 뒤 돌림노래를 앞당긴다(더블용). 싱글은 원래 다음 차례이므로 "위력만 2배"와 결과가 같다.

### R2 회복봉인
- [소스] healblock `onDisableMove`/`onBeforeMove`/`onModifyMove`가 `heal` 플래그 기술을 막는다 → 회복 기술과 **흡수 기술(전부 `heal` 플래그)** 은 선택 불가, 강제로 쓰면 `cant`. `onTryHeal`이 `false` → 먹다남은음식·조개껍질방울·희망사항 회복 차단. ~~흡수 기술은 회복만 차단~~(11/12 정정). 사이코노이즈 재적중 시 `onRestart`에서 그냥 넘어감 → 지속 시간 갱신 없음(데미지는 들어감). 지속 2턴(`durationCallback`), `onResidualOrder: 20`.
- 보충: 자뭉열매 등은 `onTryEatItem`에서 막혀 **소비되지 않고 보존**된다(봉인 해제 후 발동 가능).
- 보충: 저수·축전 등 흡수 특성은 회복만 막히고 **기술 무효화는 유지**.

### R3 미래예지
- [소스] futuremove 슬롯 조건 `onEnd` → `trySpreadMoveHit`로 맞는 시점에 계산. 맞는 칸이 기절 상태이거나 사용자 자신이면 무효. 방어 플래그 없음 → 방어 무시.
- [실행] 대타가 대신 맞아 깨짐(`|-end|p2a: Snorlax|Substitute`).
- 생명의구슬은 사용자가 필드에 있을 때만 적용(`data.source.isActive` 확인).
- **미확인**: 사용자가 교체되어 없을 때 그 밖의 도구·특성(구애안경 등) 반영 여부 → 8.3 착수 시 실행으로 확인.

### R4 명중
- 번개·폭풍은 **대상의** `effectiveWeather()` 기준 → 대상이 만능우산이면 비 필중·쾌청 50% 모두 무효. 눈보라는 필드 날씨(`hail`·`snowscape`) 기준.

### R5 PP
- `runMove`에서 `deductPP` 후 대상 없음 `-fail` → PP 소모. 현재 유지와 일치.

### R6 턴 종료 순서
- `onResidualOrder`: 미래공격 3 → 희망사항 4 → 먹다남은음식 5(sub 4) → 회복봉인 종료 20 → 지옥찌르기 22. 11/11 개정안(`8.3-A1-턴종료순서설계.md`)과 일치.
- 문서 정리: R6 "확정" 본문의 "③ 희망사항 → 미래예지"는 개정 전 순서이므로 본문을 고치거나 취소선 처리.
- "회복 0이어도 로그 한 줄"은 Showdown에 없는 줄(UI 결정). Showdown 로그와 대조할 때는 비교 대상에서 제외.
