## ② 이관 (6.6에서 넘어옴)
### B1 → 7.3: 눈보라(눈)·번개(비) 날씨 필중 미구현
- **현상(6.6 읽기 전용 검토)**: `moves.json` 눈보라(`accuracy: 70`, effect "눈이 내리면 반드시 명중한다")·번개(70, "비가 내리면 반드시 명중한다")에는 날씨 필중을 나타내는 필드가 없고, `src/lib/battle/hitChance.ts` `computeBattleHitChance`에도 날씨 분기가 없다(필중은 노가드·록온·작아지기 vs 플라잉프레스뿐, 일격기는 고정 확률). 그래서 눈에서 눈보라, 비에서 번개가 70%로 굴려진다. 폭풍은 effect에 날씨 조항이 없어 데이터와 일치한다.
- **영향**: 명중 확률은 배틀 AI(`ai/evaluator.ts`·`ai/moveDamage.ts`)와 공유하므로 고치면 AI 평가도 바뀐다. `scripts/battle-ai-scenarios/03-engine-weather.mjs`에는 이 사례가 없다.
- **수정안(작음)**: `Move`에 "이 날씨면 필중" 필드(예: `alwaysHitsInWeather: WeatherKind`)를 추가하고 눈보라(눈)·번개(비) 데이터를 채운 뒤 `computeBattleHitChance`가 `activeWeather(state)`와 일치하면 `null`(필중)을 돌려준다. 날씨 무효화(에어로크 등)는 `activeWeather`가 이미 반영하는지 확인한다.
- **7.3 규칙**: 수정 뒤 `npm run sim:ai -- regress 200` 해시 비교 → `verify-kit` 기준값 갱신 → **집 PC에서 `verify.sh` 전체 통과**(`CLAUDE.md`). 7.3에서 폭풍(effect에 날씨 조항 없음)도 원본 규칙과 대조한다.
