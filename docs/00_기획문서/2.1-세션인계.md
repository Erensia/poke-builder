# ver.2.1 세션 인계 (2026-09-30 기준 — 착수 직전)

컨테이너가 사라져도 새 세션에서 이어갈 수 있도록 남기는 문서. 새 세션은 **아래 "시작 프롬프트"를 그대로 붙여 넣으면** 된다.
작업이 진행되면 이 문서의 "현재 상태"를 갱신한다.

```

```

**주의(새 세션)**: 로컬 클론이 오래됐을 수 있다 — 시작하자마자 `git fetch origin` 후 `origin/dev`와 맞출 것(2.1 착수 세션에서
클론이 ver.1.7에 멈춰 있어 2.1 문서가 안 보인 적 있음).

## 작업 규칙 (사용자 확정)

ver.2.0과 같다 — `2.0-세션인계.md` → `1.9-세션인계.md` "작업 규칙"을 그대로 따른다(코드 우선, 설계안 먼저 합의, 항목마다 dev에서
브랜치 → PR squash 머지, dev 삭제 금지, 커밋 전 lint·tsc·`npm run test:ai`, 엔진 변경 시 regress 해시, AI 판정은 `npm run bench`,
화면 검증은 사용자, 한국어, 기획 문서만 바꾸면 dev에 직접 커밋, 머지 때 README 최신화, 커밋 끝에 Co-Authored-By/Claude-Session 줄).
dev → main은 **ver.2.1 끝에 merge commit**(사용자 확인 후, 로컬 `git merge --no-ff dev` 후 main 푸시, 원격 dev 남아 있는지 확인).
