# 배틀타워 어려움 AI — 플레이테스트 체크리스트 (ver.1.8 종합 테스트 ⑤)

시뮬레이터(그리디·AI끼리 대전)로는 잡기 어려운 "사람이 보기에 이상한 선택"을 직접 두어 보며 확인하는 목록이다.
각 항목은 **어떤 상황을 만들고 → AI가 어떻게 해야 맞는지**를 적었다. 이상하면 턴 번호·양쪽 포켓몬·HP·AI가 고른 행동을
적어서(가능하면 로그 캡처) 알려주면 된다. 테스트 중 localStorage의 `champions-party-sim.party.v1`(파티 자동저장)은 지우지 않는다.

## 1. 기본 판단

| # | 만들 상황 | 기대 동작 |
|---|---|---|
| 1-1 | AI가 한 방에 쓰러뜨릴 수 있는 상대를 앞에 둔다 | 교체·랭크업 대신 바로 공격(동점이면 드물게 다른 선택 — 관찰 대상) |
| 1-2 | AI 포켓몬이 크게 불리한 상성(4배 약점 등)으로 대면 | 유리한 대기 포켓몬으로 교체하거나, 버틸 수 있으면 유턴류로 빠짐 |
| 1-3 | 서로 피해를 거의 못 주는 대면(교착) | 칠 수 있는 포켓몬으로 교체 — 같은 행동을 수십 턴 반복하지 않음 |
| 1-4 | AI 쪽이 마지막 한 마리이고 이길 수 없는 대면 | 가장 오래 버티거나 가장 많이 깎는 행동(무의미한 변화기 반복 X) |

## 2. 상대 교체 모델링(로드맵 3)

| # | 만들 상황 | 기대 동작 |
|---|---|---|
| 2-1 | 내 포켓몬이 AI에게 불리하지만 내 대기에 그 AI 포켓몬을 잡는 포켓몬이 있다 | AI가 "내가 교체할 수도 있다"를 반쯤 고려 — 랭크다운·도발 같은 걸 무리하게 걸지 않음 |
| 2-2 | AI 파티에 검은눈빛·블록이 있고, 내 포켓몬이 불리한 대면에서 교체로 빠질 수 있다 | AI가 가두는 기술을 쓰고 이어서 공격 |
| 2-3 | 내가 멸망의노래를 쓴다(AI는 교체 가능) | AI가 카운트가 끝나기 전에 교체로 피함 |
| 2-4 | AI가 멸망의노래를 가졌고 내 포켓몬이 갇혀 있다(검은눈빛 등) | AI가 멸망의노래로 마무리를 노림 |

## 3. 변화기·필드

| # | 만들 상황 | 기대 동작 |
|---|---|---|
| 3-1 | AI가 모래바람·쾌청 등 날씨 기술을 가졌고 자기 파티에 유리 | 유리할 때 날씨를 깔고, 이미 깔렸으면 다시 쓰지 않음 |
| 3-2 | 그래스필드·먹다남은음식으로 AI가 오래 버틸 수 있는 대면 | 회복을 감안해 버티며 싸움(바로 교체하지 않음) |
| 3-3 | 내 포켓몬이 독·씨뿌리기에 걸려 있다 | AI가 방어·대타로 시간을 끄는 선택을 할 수 있음 |
| 3-4 | 상대(나)가 랭크업을 쌓는다 | AI가 흑안개·울부짖기·도발 등으로 대응(가진 경우) |
| 3-5 | 하품·도발·앙코르·트집 등 방해 변화기를 AI가 가짐 | 쓸 만한 상황에서만 씀(이미 걸린 상대에게 다시 쓰지 않음) |

## 4. 도구·특성

| # | 만들 상황 | 기대 동작 |
|---|---|---|
| 4-1 | AI 포켓몬이 자뭉열매를 들고 HP가 절반 근처 | 열매 회복을 감안해 공격을 이어감 |
| 4-2 | 기합의띠·옹골참으로 한 번 버티는 상대 | 연속기·선공기 등으로 끊는 선택(가진 경우) |
| 4-3 | 눈/모래바람 상태의 얼음/바위 타입 | 방어 1.5배를 감안한 판단(특수/물리 선택) |

## 5. 체감

| # | 확인 | 기대 |
|---|---|---|
| 5-1 | AI 한 턴 판단 대기 시간 | 체감상 즉시(시뮬레이터 평균 수십 ms, 최대 수백 ms) |
| 5-2 | 전투 로그 | AI 행동 문구가 어색하거나 빠진 곳 없음 |
