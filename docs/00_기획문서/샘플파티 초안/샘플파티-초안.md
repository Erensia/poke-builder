# 샘플 파티 초안 (ver.2.1 B) — 실전형 10 + 교과서형 10

사용자가 두 방향을 비교해 고르기 위한 초안이다. **확정 아님** — 고른 쪽(또는 섞어서)을 다듬어 `src/data/samplePartyPresets.json`으로 넣는다.
데이터 원본: [샘플파티-초안.json](샘플파티-초안.json) (앱 파티 저장 형식과 같은 슬롯 구조).

## 먼저 알아둘 것

- **실전형은 실제 사용률 자료를 근거로 한 것이 아니다.** 제가 Pokémon Champions의 실제 사용률·메타 순위를 확인할 수단이 없어서, 이 로스터(252종)에서
  스탯·특성·도구가 좋은 포켓몬과 흔히 알려진 조합(날씨 세팅, 위협 사이클, 메가 에이스 + 서포트 등)으로 **추정**해 짰다. 사용자가 실전에서 보는 파티와 다르면 알려 달라.
- 모든 슬롯은 `validate-data` 규칙(포켓몬·기술·특성·도구·성격 존재, 그 종이 배울 수 있는 기술, 그 종의 특성, 포인트 합 66 이하·스탯당 32 이하)을 통과했고,
  파티당 메가 1마리 이하·같은 포켓몬/같은 도구 중복 없음이다. 20개 전부 배틀 엔진에서 실제로 돌려(3마리 선출, 40턴) 오류가 없는지 확인했다.
- 이 게임의 도구는 본가와 다르다(오랭열매 = 체력 절반 이하에서 10 회복, 리샘열매 = 모든 상태이상 회복, 자뭉열매 = 체력 절반 이하에서 1/4 회복 등). 도구 목록에 없는 것
  (돌격조끼·구애머리띠·구애안경 등)은 쓰지 않았다.
- 포인트 표기: H=HP, A=공격, B=방어, C=특공, D=특방, S=스피드.
