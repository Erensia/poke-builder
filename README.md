# Poke-Builder

Pokémon Champions 파티 빌더 — 6슬롯 파티를 구성하고 타입 상성을 확인하며, 결정력·내구력 매치업과 여러 턴짜리 배틀타워 시뮬레이션까지 판정하는 웹 앱.

- **배포**: [poke-builder-two.vercel.app](https://poke-builder-two.vercel.app/) — Vercel에 `main` 브랜치 자동 배포
- **저장소**: [github.com/Erensia/poke-builder](https://github.com/Erensia/poke-builder)
- **현재 버전**: ver.3.1 — 상세는 [문서](#문서) 참고

## 주요 기능

- **6슬롯 파티 편성**: 기술 4개·특성·도구 배치, 실제 스프라이트 이미지(메가·폼·성별 자동 반영), 이름 붙인 파티/빌드 프리셋 저장·불러오기, 드래그앤드랍 순서 변경
- **타입 상성 매트릭스**: 파티 6마리 × 공격 타입 18종 방어 배율을 한눈에, 파티 전체 취약/강점 자동 판정
- **성격·능력포인트 편집**: 챔피언스 전용 실수치 공식, 슬라이더 UI로 스탯 배분
- **결정력 & 내구력 매치업**: 랭크·날씨·필드·스크린·특성·다단히트까지 반영해 확정 1타~3타 이상 판정, 난수(85~100)별 데미지를 "실제 데미지 (HP%)"로 표기(범위 + 16개 펼치기). ver.1.9부터 카드별 가정 토글 — 상태이상·급소·HP 조건(맹화류·멀티스케일·HP 슬라이더)·조건부 위력(보복·눈사태·분함의발구르기·열불내기·분풀이·승부굳히기·작아지기)
- **배틀타워(다중 턴 시뮬레이션)**: 우선도·명중/회피·급소·상태이상·반동·2턴 차지기·난동(역린 등 2~3턴 고정 + 혼란)·날씨/필드 등 전투 로직 전반을 반영한 턴제 대전(난동·모으기 2턴째·반동 턴은 선택 없이 자동 진행 — 교체 불가), 6빌드→3선출 & 교체(중복 배치 방지, 드래그앤드롭 순서 변경, 압축 카드 뷰), 배틀비디오(최근 3전 다시보기)
- **배틀타워 AI**(ver.1.9부터 난이도 선택 없이 한 가지): 상대 편을 컴퓨터가 조작 — 기술·교체·메가진화를 "HP 교환" 점수식 하나로 비교해 선택. 유턴류·회복·랭크업·배턴터치·상태이상·벽·설치기·날씨/필드/트릭룸·도발/앙코르·방어류(엔진 한 턴 시뮬레이션)까지 판단. ver.1.8부터 파티 단위 평가 — 남은 포켓몬끼리의 대면표로 교환 뒤 수 싸움까지 계산(미니맥스). ver.1.9에서 판단 정확도 보강 — 급소 확률, 기습 성공 확률, 반동·생명의구슬·흡수 등 자기 HP 변화, 모으기·반동 기술의 턴 비용, 탈피·수확·맹독 누적, 교체 봉쇄 기술 가치. ver.2.0에서 판단 구조 강화 — 후보 행동마다 실제 엔진으로 한 턴을 돌려 보는 탐색(Web Worker, "AI 생각 중" 표시, 평균 약 0.25초), 상대도 같은 평가식으로 판단한다고 보는 한 단계 추론 + 교체 읽기, 사용자 패턴 학습(대전 간 누적 — 최근 약 100판, 설정 화면 `🧠 AI 학습 N판` → "AI가 본 내 습관"에서 성향 확인·학습 끄기·초기화). 판단 기준 한눈에 보기: [ai-판단기준-요약.md](docs/00_기획문서/03_battleAI_DEV/ai-판단기준-요약.md)
- **상대 진영 설치 기술 6종**·**강제 교체 기술 4종**: 스텔스록·압정뿌리기 등 / 드래곤테일·울부짖기 등
- **상대 실능치 역산**(ver.2.1, 결정력 & 내구력 화면의 두 번째 탭): 내가 입힌 데미지(상대 HP 정수 %)를 관측으로 입력하면 상대의 HP·방어(특방) 능력 포인트와 성격이 될 수 있는 범위를 좁힘 — 엔진과 같은 정수 데미지 공식으로 후보 전수를 난수 16단계까지 시험. ver.3.1에서 내가 받은 데미지(내 HP 수치)로 상대 공격(특공), 선후공 관측으로 상대 스피드까지 역산하고 세 쪽을 결합(성격 공유·포인트 합계 66), 메가 전·후 비교 표 추가
- **샘플 파티 34개**(ver.2.1, 2.2에서 심화샘플 6개, 3.1에서 4개, 3.2에서 3개 추가, 배틀타워 설정 화면의 "샘플 파티"·"무작위 샘플"·"랜덤 구축"(ver.2.2 — 저장해 둔 슬롯 프리셋에서 마리 단위로 6마리 조합)·"배틀 프런티어"(ver.2.2 연속 대전 → 2.5 개편 — 선출을 고정하고 샘플 파티를 무작위로 상대하며 연승·최대 연승·샘플별 승패를 저장, 도중 이탈은 패배)): 심화샘플 24 + 기초샘플 10(날씨·트릭룸·스톨·하이퍼 오펜스·사이클 등)을 양쪽 진영에 사본으로 불러온다. 읽기 전용 데이터라 불러와서 고쳐도 원본·저장 파티는 그대로
- **사이드 메뉴**: 포켓몬 도감(전국도감 순 정렬, 루가루암 등 폼 변종은 폼 탭으로 종족값·특성·기술 전환)·카드형 기술표·도구 도감
- **레귤레이션 M-C 대응**: 신규 포켓몬 26종 + 전용 기술·특성·지닌 도구를 엔진에 배선
- **글래스모피즘 UI + 모바일 대응(≤760px)**: 반투명·블러 기반 디자인 토큰, 사이드바 드로어, 모달 하단 시트화, 검색창 하단 고정, 입력 확대 방지
- **로컬 자동 저장**: 편성 내용이 `localStorage`에 자동 저장, 새로고침해도 복원
- **한국어 조사 자동 처리**: 로그·모달 문구의 조사를 받침 기반으로 자동 판별

## 데이터 규모

- 포켓몬 252종 — 메가진화 가능 76종 / 메가폼 81개(일부 종은 메가폼 2개)
- 기술 511개 (우선도·랭크 변화·다단히트 정보 포함)
- 특성 216개
- 샘플 파티 34개 (`src/data/samplePartyPresets.json` — `npm run validate:data`가 기술·특성·포인트·중복을 검사)
- 도구 166종 (메가스톤 포함)
- 성격 21종
- 스프라이트: `public/sprites/` — `npm run sprites`로 `src/data/spriteManifest.json` 재생성

## 기술 스택

React 19 + TypeScript + Vite 8. 별도 백엔드 없이 로컬 JSON 데이터 + `localStorage`로 동작하는 순수 정적 SPA. `@/`는 `src/`를 가리키는 경로 별칭(ver.1.5). 린트는 oxlint, 테스트 러너는 없음 — 엔진·AI 검증은 Vite `ssrLoadModule`로 `src/`를 직접 불러오는 스크립트(`npm run test:ai`·`npm run sim:ai`, ver.1.7)로 한다.

## 시작하기

```bash
npm install
npm run dev      # http://localhost:5174
npm run build    # 데이터 검증 + tsc -b + vite build → dist/
npm run lint     # oxlint
npm run sprites  # public/sprites/ 스캔 → src/data/spriteManifest.json 재생성
npm run test:ai  # 배틀 AI·엔진 규칙 시나리오(실패 시 exit 1)
npm run test:inference  # 상대 실능치 역산: 엔진 데미지 공식 대조 + 왕복 검증(ver.2.1)
npm run sim:ai -- regress   # 엔진 동작 불변 확인용 로그 해시(모드: regress|ai|greedy|h2h|diag)
npm run bench -- compare <이전 체크아웃>   # AI 벤치(그리디·STATUS·h2h, 코어 수만큼 병렬 — toggle 모드는 켬/끔 비교)
```

## 배포 & 개발 워크플로

`main` 브랜치가 Vercel 프로덕션에 자동 배포된다(제로 설정, 프레임워크 프리셋 자동 감지). `dev`에서 항목별 브랜치를 파서 PR로 `dev`에 머지하고, 버전이 끝나면 `dev`를 `main`에 merge commit으로 병합한다(`dev`는 삭제하지 않는다). 기획·백로그 문서만 고치는 변경은 브랜치/PR 없이 직접 커밋한다. 상시 브랜치는 `main`·`dev` 둘뿐 — 머지된 작업 브랜치는 로컬·원격 모두 삭제한다.
