# Poke-Builder

Pokémon Champions 파티 빌더 — 6슬롯 파티를 구성하고 타입 상성을 확인하며, 결정력·내구력 매치업과 여러 턴짜리 배틀타워 시뮬레이션까지 판정하는 웹 앱.

- **배포**: [poke-builder-two.vercel.app](https://poke-builder-two.vercel.app/) — Vercel에 `main` 브랜치 자동 배포(`dev` 브랜치는 배포하지 않는다 — `vercel.json`, ver.7.7)
- **저장소**: [github.com/Erensia/poke-builder](https://github.com/Erensia/poke-builder)
- **현재 버전**: ver.8.2 — 노력치 역산 확장(고정 데미지·쓰러진 다단히트·속임수·자이로볼·일렉트릭볼·셸암즈 지원, 상대 스피드·공격을 몰라도 가능한 값 전체를 평균내 역산), 프런티어 기록 두 기기 합치기를 판 시각 기준으로 개선, 샘플 파티 68개, 상세는 [문서](#문서) 참고

## 주요 기능

- **6슬롯 파티 편성**: 기술 4개·특성·도구 배치, 실제 스프라이트 이미지(메가·폼·성별 자동 반영), 이름 붙인 파티/빌드 프리셋 저장·불러오기, 드래그앤드랍 순서 변경
- **타입 상성표(방어/공격)**: 파티 편성 화면 아래의 두 표(기본은 접힘 — 제목을 눌러 펼친다, ver.7.6). **방어**는 파티 6마리 × 공격 타입 18종 방어 배율을 한눈에, 파티 전체 취약/강점 자동 판정. **공격**은 파티 기술을 타입별로 물리·특수·변화 몇 개씩인지 세고(스킨류 특성·메가폼 특성·레이징불로 바뀐 타입 반영, 웨더볼 같은 날씨 의존 기술은 기본 타입), 물리·특수 기술이 약점을 찌를 수 있는 방어 타입 수(약점 커버)와 못 찌르는 타입을 보여 준다 — 기준은 단일 타입 18개 또는 실제 포켓몬 데이터의 타입 조합(이중 타입 포함, ver.7.7) 중 고른다. 두 표의 펼침/접힘은 브라우저가 기억한다(ver.7.7)
- **성격·능력포인트 편집**: 챔피언스 전용 실수치 공식, 슬라이더 UI로 스탯 배분
- **결정력 & 내구력 매치업**: 랭크·날씨·필드·스크린·특성·다단히트까지 반영해 확정 1타~3타 이상 판정, 난수(85~100)별 데미지를 "실제 데미지 (HP%)"로 표기(범위 + 16개 펼치기). ver.1.9부터 카드별 가정 토글 — 상태이상·급소·HP 조건(맹화류·멀티스케일·HP 슬라이더)·조건부 위력(보복·눈사태·분함의발구르기·열불내기·분풀이·승부굳히기·작아지기)
- **배틀타워(다중 턴 시뮬레이션)**: 우선도·명중/회피·급소·상태이상·반동·2턴 차지기·난동(역린 등 2~3턴 고정 + 혼란)·날씨/필드 등 전투 로직 전반을 반영한 턴제 대전(난동·모으기 2턴째·반동 턴은 선택 없이 자동 진행 — 교체 불가), 6빌드→3선출 & 교체(중복 배치 방지, 드래그앤드롭 순서 변경, 압축 카드 뷰), 배틀비디오(배틀타워 최근 3전 다시보기). 대전 중 효과(ver.7.4 — 타격 번쩍임·피해 숫자·상태이상·회복·교체·기절·메가진화·날씨·설치물 연출, 동작 줄이기 설정이면 생략)는 앞 연출이 끝난 뒤 다음 포켓몬이 등장하도록 재생 대기열로 순서를 맞추고(ver.7.5), 기절 뒤 강제 교체는 그 턴 카드 안에 이어서 표시(먼저 쓰러진 쪽 먼저)
- **배틀타워 AI**(ver.1.9부터 난이도 선택 없이 한 가지): 상대 편을 컴퓨터가 조작 — 기술·교체·메가진화를 "HP 교환" 점수식 하나로 비교해 선택. 유턴류·회복·랭크업·배턴터치·상태이상·벽·설치기·날씨/필드/트릭룸·도발/앙코르·방어류(엔진 한 턴 시뮬레이션)까지 판단. ver.1.8부터 파티 단위 평가 — 남은 포켓몬끼리의 대면표로 교환 뒤 수 싸움까지 계산(미니맥스). ver.1.9에서 판단 정확도 보강 — 급소 확률, 기습 성공 확률, 반동·생명의구슬·흡수 등 자기 HP 변화, 모으기·반동 기술의 턴 비용, 탈피·수확·맹독 누적, 교체 봉쇄 기술 가치. ver.2.0에서 판단 구조 강화 — 후보 행동마다 실제 엔진으로 한 턴을 돌려 보는 탐색(Web Worker, "AI 생각 중" 표시, 평균 약 0.25초), 상대도 같은 평가식으로 판단한다고 보는 한 단계 추론 + 교체 읽기, 사용자 패턴 학습(대전 간 누적 — 배틀타워는 최근 약 100판, 랭크배틀은 별도 기록 최근 약 200판, 설정 화면 `🧠 AI 학습 N판` → "AI가 본 내 습관"에서 성향 확인·학습 끄기·초기화). 판단 기준 한눈에 보기: [ai-판단기준-요약.md](docs/00_기획문서/03_battleAI_DEV/ai-판단기준-요약.md)
- **랭크배틀**(ver.5.0, 사이드 메뉴): 배틀타워 화면(파티 편성·선출·대전)을 그대로 쓰되 상대는 AI와 샘플 파티로 자동 고정. 몬스터볼 → 슈퍼볼 → 하이퍼볼(각 4~1단계, 원형 게이지 경험치제) → 마스터볼(레이팅제 — 진입 레이팅 (1300 + 2×누적 승수) × 조건부 1.1, 한 판 기본 ±20 + 턴 보정, 연승·연패 배율) → 챔피언(마스터볼 레이팅 2500 이상). 승패 직후 계산 내역 카드·최근 50판 이력·30일 시즌 기록·이탈은 패배. 상대는 같은 등급의 샘플 파티 또는 같은 등급 샘플 슬롯으로 무작위 구축한 파티(볼별 비율: 몬스터 100% · 슈퍼 70% · 하이퍼 50% · 마스터 30% · 챔피언 40%)이고, 최근 상대는 다시 안 나오며 챔피언은 전용 최상 파티 풀을 쓴다. 경험치제 구간에서 연패하면 상대 파티 등급·AI 단계를 낮추는 난이도 보정. 랭크 AI는 몬스터볼~하이퍼볼에서 실수 모델로 약화한 3단계, 마스터볼은 레이팅 구간(4~1) 따라 상대 모델만 → 앱 AI로 올라가고, 몬스터볼~하이퍼볼에서 쌓은 사용자 습관을 마스터볼부터 단계적으로(0.25~1.0) 활용(학습은 배틀타워와 따로 — 랭크는 최근 약 200판). 편성·선출 화면의 상대는 메가폼·도구를 숨긴 기본형으로 표시. 배틀비디오는 랭크 최근 5전을 따로 보관
- **상대 진영 설치 기술 6종**·**강제 교체 기술 4종**: 스텔스록·압정뿌리기 등 / 드래곤테일·울부짖기 등
- **계산 기능**(사이드 메뉴, 탭 4개 — 탭끼리 내 포켓몬·상대 종·날씨·필드를 공유하고 날씨·필드 배경이 깔린다. 입력은 새로고침·탭 이동 뒤에도 자동 복원)
  - **결정력 계산**: 위 "결정력 & 내구력 매치업". 내/상대 포켓몬은 드래그앤드롭으로 자리를 바꾼다(ver.3.3)
  - **노력치 역산**(ver.2.1 "상대 실능치 역산"): 내가 입힌 데미지(상대 HP 정수 %)를 관측으로 입력하면 상대의 HP·방어(특방) 능력 포인트와 성격이 될 수 있는 범위를 좁힘 — 엔진과 같은 정수 데미지 공식으로 후보 전수를 난수 16단계까지 시험. ver.3.1에서 내가 받은 데미지로 상대 공격(특공), 선후공 관측으로 상대 스피드까지 역산하고 세 쪽을 결합(성격 공유·포인트 합계 66), 메가 전·후 비교 표. ver.3.3~3.6에서 다단히트·포인트 합계 하한·쓰러진 공격 지원, 결합 계산 약 4배 빠르게, 구체적인 후보 카드 목록(정렬 3종). ver.3.7에서 관측 사이 턴 종료 효과(먹다남은음식·독·화상·맹독 등) 반영. ver.8.2에서 역산 지원 기술 확대: 고정 데미지(나이트헤드·지구던지기)·쓰러진 다단히트(방어·공격 양쪽), 속임수, 자이로볼·일렉트릭볼, 셸암즈(물리/특수 분류를 배틀 엔진 규칙으로 후보마다 판정). 자이로볼·일렉트릭볼·속임수는 상대 스피드·공격 실수치를 몰라도 비워 두면 가능한 값 전체를 평균내 계산하고(같은 상대의 선후공·받은 데미지 관측이 있으면 그 범위 안에서만), 알면 직접 입력해 고정
  - **스피드 조정**(ver.3.4 스피드 표 → 3.6 재설계): 내 스피드로 상대 최속·준속·무투자·최저속 단계별로 어떤 포켓몬을 추월하는지, 목표 포켓몬을 넘는 최소 스피드 포인트
  - **내구 조정**(ver.3.7): 상대 포켓몬·기술을 최대 난수(또는 난수 n%)로 맞아도 버티는 최소 HP·방어(특방) 포인트 조합 표, HP 최적 수치(16n+15 등) 표시. 포인트 편집 모달의 HP 눈금도 도구·타입·기술에 따라 자동 강조(ver.3.7)
- **샘플 파티 68개**(ver.2.1, 2.2에서 심화샘플 6개, 3.1에서 4개, 3.2에서 3개, 3.5에서 1개, 5.0에서 2개, 5.1에서 2개, 5.2에서 심화샘플 10개·기초샘플 8개, 5.3에서 심화샘플 1개, 6.5 이후 심화샘플 10개 추가, 배틀타워 설정 화면의 "샘플 파티"·"무작위 샘플"·"랜덤 구축"(ver.2.2 — 저장해 둔 슬롯 프리셋에서 마리 단위로 6마리 조합)·"배틀 프런티어"(ver.2.2 연속 대전 → 2.5 개편 — 선출을 고정하고 샘플 파티를 무작위로 상대하며 연승·최대 연승·샘플별 승패를 저장, 도중 이탈은 패배)): 심화샘플 50 + 기초샘플 18(날씨·트릭룸·스톨·하이퍼 오펜스·사이클·해악·막이·그래스·사이코·일렉트릭 등)을 양쪽 진영에 사본으로 불러온다. 읽기 전용 데이터라 불러와서 고쳐도 원본·저장 파티는 그대로. "내 샘플"(ver.3.1)은 ver.3.2부터 JSON 파일로 내보내고 가져올 수 있다(가져올 때 형식·id·포인트를 검사하고 중복은 제외)
- **사이드 메뉴**: 계산 기능(위)·포켓몬 도감(전국도감 순 정렬, 루가루암 등 폼 변종은 폼 탭으로 종족값·특성·기술 전환)·카드형 기술표·도구 도감
- **레귤레이션 M-C 대응**: 신규 포켓몬 26종 + 전용 기술·특성·지닌 도구를 엔진에 배선
- **글래스모피즘 UI + 모바일 대응(≤760px)**: 반투명·블러 기반 디자인 토큰, 하단 탭 네비(5.1 — 파티·계산·배틀타워·랭크배틀·도감 시트, 랭크 대전 중 이동 확인, 홈 화면 추가용 PWA 설정과 홈 인디케이터·노치 안전 영역), 모달 하단 시트화, 검색창 하단 고정, 입력 확대 방지. **모바일 배틀(8.1)**: 셋업은 내 파티 → VS → 상대 파티 순, AI 상대 대전은 선택한 기술을 한 번 더 누르면 턴 진행(고를 게 없는 턴은 1초 쉬고 자동 진행), 360~760px에서 두 카드를 한 줄(내 카드 약 60%·상대 카드 약 40%)에 놓고 상대 카드는 포켓몬/능력치(랭크 변화)/파티 면을 버튼으로 전환, 배틀 로그는 접힌 채 시작. 눌리는 영역은 가로·세로 44px를 보장하고(터치 환경), 터치에서 안 보이던 `title` 설명 일부는 탭으로 볼 수 있다
- **로컬 자동 저장**: 편성 내용이 `localStorage`에 자동 저장, 새로고침해도 복원
- **오프라인 사용(PWA)**: 서비스 워커로 앱 파일을 저장해 네트워크 없이도 열 수 있고(ver.6.5), 새 버전이 배포되면 안내 바로 알려 준다(ver.6.6)
- **백업·클라우드 동기화**(파티 빌더 헤더 "백업" 버튼): 저장한 파티·저장한 포켓몬 빌드를 JSON 파일로 내보내기·가져오기(ver.5.5). **선택 기능**으로 Google 로그인하면 저장한 파티·저장한 포켓몬·내 샘플(ver.6.2)이 Firebase(Firestore)에 자동 백업되고 같은 계정의 다른 기기와 맞춰진다(ver.6.0) — 한쪽만 바뀌면 자동 반영, 두 기기에서 따로 바꿨으면 항목 단위로 합친다(추가·삭제·이름 변경 모두, ver.6.2). 랭크배틀 기록(랭크·레이팅·승패·시즌 기록)과 프런티어 기록(연승·전적)도 같이 맞춘다(ver.6.2) — 두 기기에서 따로 플레이한 랭크 판은 기준 상태에서 시각 순으로 다시 계산해 합치고(시즌이 끼었거나 한쪽이 50판을 넘기는 등 합칠 수 없을 때만 화면에서 고른다), 프런티어 기록은 최근 50판의 판 시각을 같이 저장해 기준 이후의 판을 시각 순으로 다시 계산해 합치고(ver.8.2), 합칠 수 없을 때만 화면에서 고른다. 대전 영상·AI 학습 기억은 동기화하지 않는다. 로그인하지 않으면 지금처럼 `localStorage`만 쓴다
- **한국어 조사 자동 처리**: 로그·모달 문구의 조사를 받침 기반으로 자동 판별

## 기술 스택

React 19 + TypeScript + Vite 8. 서버 코드 없는 정적 SPA — 기본은 로컬 JSON 데이터 + `localStorage`로 동작하고, 선택 기능인 클라우드 백업만 Firebase(Authentication·Firestore, 로그인 화면을 열 때 지연 로딩)를 쓴다(ver.6.0). 접속 성능은 Vercel Speed Insights로 수집한다(ver.7.4). `@/`는 `src/`를 가리키는 경로 별칭(ver.1.5). 린트는 oxlint, 테스트 러너는 없음 — 엔진·AI 검증은 Vite `ssrLoadModule`로 `src/`를 직접 불러오는 스크립트(`npm run test:ai`·`npm run sim:ai`, ver.1.7)로 한다.

## 배포 & 개발 워크플로

`main` 브랜치가 Vercel 프로덕션에 자동 배포된다(제로 설정, 프레임워크 프리셋 자동 감지). `dev`에서 항목별 브랜치를 파서 PR로 `dev`에 머지하고, 버전이 끝나면 `dev`를 `main`에 merge commit으로 병합한다(`dev`는 삭제하지 않는다). 기획·백로그 문서만 고치는 변경은 브랜치/PR 없이 직접 커밋한다. 상시 브랜치는 `main`·`dev` 둘뿐 — 머지된 작업 브랜치는 로컬·원격 모두 삭제한다.
