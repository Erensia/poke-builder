# Poke-Builder

Pokémon Champions 파티 빌더 — 6슬롯 파티를 구성하고 타입 상성을 확인하며, 결정력·내구력 매치업과 여러 턴짜리 배틀타워 시뮬레이션까지 판정하는 웹 앱.

- **배포**: [poke-builder-two.vercel.app](https://poke-builder-two.vercel.app/) — Vercel에 `main` 브랜치 자동 배포
- **저장소**: [github.com/Erensia/poke-builder](https://github.com/Erensia/poke-builder)
- **현재 버전**: ver.1.1 (실제 포켓몬 스프라이트 배선 + 전체 모바일 대응 완료)

## 주요 기능

- **6슬롯 파티 편성**: 포켓몬 선택 → 기술 4개 / 특성 1개 / 도구 1개 배치. 이름 붙인 파티·슬롯 프리셋 저장/불러오기
- **실제 스프라이트 이미지**: 파티 슬롯·배틀 셋업·매치업 슬롯 + 도감 리스트·상세 5곳의 이니셜 뱃지를 공유 `<PokemonAvatar>`로 교체. 메가·겉모습·리전폼·성별별 스프라이트를 `resolvePokemonSpriteUrl`이 해석하고, 이미지가 없거나 로드 실패 시 이름 첫 글자 + 타입 색 그라디언트로 폴백
- **메가진화 자동 전환**: 메가스톤을 도구로 장착하면 아바타·타입·스탯이 즉시 해당 메가폼 기준으로 바뀜 (메가X/Y처럼 폼이 2개인 경우도 지원)
- **타입 상성 매트릭스**: 빌드한 6마리 × 공격 타입 18종 표로, 각 포켓몬이 그 타입 기술을 받을 때의 방어 배율(`½`/`¼`/`×2`/`×4`/`면역`)을 항상 펼쳐 보여줌. 7번째 "종합" 열이 타입별로 파티 전체의 취약/보통/강점을 확정 규칙(`r≥w ∧ r≥2` → 강점 / `w−r≥2` → 취약)으로 판정. 좁은 폭에서는 가로 스크롤
- **성격·능력포인트 편집**: 챔피언스 전용 실수치 공식(레벨/개체값 없음)으로 계산, 스탯당 최대 32 / 합산 66 포인트 배분. 로딩바형 슬라이더 에디터 — 클릭·드래그·방향키, 성격 ×1.1로 실수치 +2 되는 "매직 넘버"에 흰 눈금, 성격 상승/하락 스탯 색상 표기
- **결정력 & 내구력 매치업**: 내 포켓몬과 상대 포켓몬·기술을 고르면 확정 1타 ~ 3타 이상까지 5단계로 판정. 랭크 상태·날씨·필드·스크린·특성 배율·다단히트 기술(×1/×2/×3), "이전 턴 가정" 토글(도구 강탈·곡예 스피드 2배 등), 스피드 비교(트릭룸·마비 가정)까지 반영
- **배틀타워 (다중 턴 시뮬레이션)**: 양쪽 포켓몬을 편성하고 매 턴 기술/교체를 직접 골라가며 여러 턴짜리 가상 대전을 진행. 우선도·실효 스피드(동속 랜덤, 트릭룸이면 역전) 기반 턴 순서, 레벨 50 기준 실제 데미지·%HP, 명중/회피율(반짝가루·광각렌즈·포커스렌즈 배율 포함)·급소율, 화상·독·맹독·마비·잠듦·얼음 상태이상(정확한 해제 확률·타입 면역까지 전수 검증)과 풀죽음·반동·혼란·졸음 같은 행동방해 효과, 반동(recoil) 데미지·다단히트·2턴 차지 기술(공중날기 등)·상태이상 치료·불꽃타입 해동, 잠자기·광합성·뿌리박기·씨뿌리기·희망사항 등 HP/PP 회복 엔진, 날씨(5턴 카운트다운·배율·배경색·특성 자동 발동·연장 바위)와 필드(그래스/미스트/사이코/일렉트릭)·리플렉터/빛의장막/오로라베일 스크린·방어류(방어/판별/버티기/킹실드) 차단, 지닌 도구 위력 보정(타입 강화·생명의구슬·달인의띠·메트로놈·나무열매 등)까지 반영해 턴별 로그로 보여줌
- **6빌드 → 3선출 & 교체**: 편측 6마리를 빌드(슬롯 0 = 리드)하고, 4마리 이상 빌드하면 선출 화면에서 3마리와 순서를 고름(3마리 이하면 선출 화면을 건너뜀). 매 턴 "기술 / 교체" 선택, 교체 우선도(항상 기술보다 먼저)·기절 후 강제 교체·양측 파티 HP·상태이상·기절 트래커. 교체하면 구애 잠금·앙코르·도발·곡예·씨뿌리기·헤롱헤롱·뿌리박기·아쿠아링이 해제되고, 나가는 쪽에 재생력·자연회복이 발동. 등장 시 처리 파이프라인(설치물 → 등장 특성(위협·날씨·트레이스 등) → 재생력/자연회복)
- **상대 진영 설치 기술 6종**: 스텔스록·압정뿌리기·독압정·끈적끈적네트·비검천중파·암석액스 — 스택(압정 3층·독압정 2층)·등장 데미지·비접지 판정·고속스핀/안개제거 제거·독타입 등장 시 독압정 흡수
- **턴 중 메가진화 선언 & 일루전**: 배틀타워에서 본가식 메가진화 선언 버튼(선언 후 스프라이트·타입·스탯 전환), 조로아크/히스이조로아크 일루전(위장 대상 스프라이트로 상대를 속임)
- **강제 교체 기술**: 드래곤테일·배대뒤치기·울부짖기·날려버리기 — 무작위 예비 포켓몬으로 즉시 교체(흡반·뿌리박기 저항, 타입면역/예비없음이면 생략)
- **겉모습 폼·성별 이미지**: 마휘핑·플라제스·트리미앙·비비용 등 겉모습(전투 무관, 이미지 전용) 순환/리스트 선택, 화염레오·대쓰여너·냐오닉스 등 성별 스프라이트
- **사이드 메뉴 (포켓몬 도감 / 기술표 / 도구 도감)**: 전체 로스터·기술·도구 데이터를 검색·열람
- **특성 기반 전투 로직 대거 확장(Phase 4.5~7)**: 방어적 특성(부유·정전기·타오르는불꽃·저주받은바디 등) 다수, 상대 방어적 특성 무시(틀깨기), 부가효과·위력 트레이드(우격다짐), 도구 강탈/상실(매지션·곡예), 상대 기술 선택 제약(도발·사슬묶기·앙코르), 폼체인지(킬가르도 배틀스위치), 타입 변환(변환자재), 무작위 기술 대체(잠꼬대), 명중률 보정(복안), 장 전체 타입 위력(페어리오라), 부가 데미지 전면 무효(매직가드), 상대 기술 반사(매직미러), 추가효과 무산(인분), 독타입 면역 관통(부식) 등
- **모바일 대응 (≤760px)**: 사이드바 햄버거 오버레이 드로어(포커스 트랩·Esc·백드롭), 모달 하단 시트화, 입력 포커스 시 확대 방지(font-size 16px), 파티 그리드 1열·배틀타워/매치업 세로 스택
- **로컬 자동 저장**: 편성 내용이 브라우저에 자동 저장되고 새로고침해도 복원됨 (`localStorage`, `champions-party-sim.*` 키)
- **한국어 조사 자동 처리**: 로그·모달 문구의 `은(는)`/`이(가)`/`을(를)`/`와(과)`/`(으)로`를 받침 기반으로 자동 판별(`src/lib/josa.ts`)
- **저작권 푸터**: 앱 셸 공용 닌텐도 상표 고지

## 데이터 규모

- 포켓몬 228종 (포챔스 입국몬 2~9세대 전체 병합) — 메가진화 가능 73종 / 메가폼 77개(리자몽·한카리아스·루카리오·라이츄는 메가폼 2개)
- 기술 497개 (우선도·랭크 변화·다단히트 정보 포함)
- 특성 202개 (전부 효과 설명 포함, 그중 다수는 결정력/내구력/배틀 로직에 실제 반영되도록 구조화)
- 도구 150종 (메가스톤 포함, 전부 효과 설명 포함. 다수는 데미지 위력 보정 배율로 구조화)
- 성격 21종
- 스프라이트: `public/sprites/{세대}/`, `메가진화/`, `도구/`(+`메가스톤/`), `타입/` — `npm run sprites`로 `src/data/spriteManifest.json` 재생성

## 기술 스택

React 19 + TypeScript + Vite 8. 별도 백엔드 없이 로컬 JSON 데이터 + `localStorage`로 동작하는 순수 정적 SPA. 린트는 oxlint(`.oxlintrc.json`), 테스트 러너는 없음(엔진 검증은 dev 서버 페이지 컨텍스트에서 `src/lib/*` 직접 import).

## 시작하기

```bash
npm install
npm run dev      # http://localhost:5174 (vite.config.ts에서 5174 고정 — 5173은 다른 프로젝트가 사용)
npm run build    # tsc -b + vite build → dist/
npm run lint     # oxlint
npm run sprites  # public/sprites/ 스캔 → src/data/spriteManifest.json 재생성
```

정적 검증 세트: `npx tsc -b` + `npx oxlint` + `npm run build`.

## 배포

- **Vercel 제로 설정 배포.** `vercel.json` 없이 프레임워크 프리셋(Vite)이 자동 감지된다 — 빌드 커맨드 `npm run build`, 출력 디렉터리 `dist/`.
- `main` 브랜치에 머지되면 프로덕션 배포가 자동 갱신된다.
- `dev` 등 다른 브랜치 푸시는 Vercel 프리뷰 배포로 붙어, 프로덕션에 올리기 전 모바일 등에서 확인한다.

## 개발 워크플로

`dev`에서 항목별 브랜치를 파서 → PR로 `dev`에 머지 → 프리뷰에서 확인 → 주기적으로 `dev`를 `main`에 머지(프로덕션 배포). 기획·백로그 문서만 고치는 변경은 브랜치/PR 없이 직접 커밋한다.
