# Poke-Builder

Pokémon Champions 파티 빌더 — 6슬롯 파티를 구성하고 타입 상성을 확인하며, 결정력·내구력 매치업까지 판정하는 웹 앱.

## 주요 기능

- **6슬롯 파티 편성**: 포켓몬 선택 → 기술 4개 / 특성 1개 / 도구 1개 배치
- **메가진화 자동 전환**: 메가스톤을 도구로 장착하면 아바타·타입·스탯이 즉시 해당 메가폼 기준으로 바뀜 (메가X/Y처럼 폼이 2개인 경우도 지원)
- **타입 상성 요약**: 파티 전체가 18타입 공격에 얼마나 약한지/버티는지 한눈에 보여주고, 타입 칸을 클릭하면 어떤 포켓몬이 해당되는지 드릴다운
- **성격·능력포인트 편집**: 챔피언스 전용 실수치 공식(레벨/개체값 없음)으로 계산, 스탯당 최대 32/합산 66 포인트 배분
- **결정력 & 내구력 매치업**: 내 포켓몬과 상대 포켓몬·기술을 고르면 확정 1타 ~ 3타 이상까지 5단계로 판정. 랭크 상태·날씨·특성 배율·다단히트 기술(×1/×2/×3)까지 반영
- **배틀타워(다중 턴 시뮬레이션)**: 양쪽 포켓몬을 편성하고 매 턴 기술을 직접 골라가며 여러 턴짜리 가상 대전을 진행. 우선도·실효 스피드(동속 랜덤, 트릭룸이면 역전) 기반 턴 순서, 레벨 50 기준 실제 데미지·%HP, 명중/회피율(반짝가루·광각렌즈·포커스렌즈 배율 포함)·급소율, 화상·독·맹독·마비·잠듦·얼음 상태이상(정확한 해제 확률·타입 면역까지 전수 검증)과 풀죽음·반동·혼란·졸음 같은 행동방해 효과, 반동(recoil) 데미지·다단히트·2턴 차지 기술(공중날기 등)·상태이상 치료·불꽃타입 해동, 잠자기·광합성·뿌리박기·씨뿌리기·희망사항 등 HP/PP 회복 엔진, 날씨(5턴 카운트다운·배율·배경색·특성 자동 발동·연장 바위)와 필드(그래스/미스트/사이코/일렉트릭)·리플렉터/빛의장막/오로라베일 스크린·방어류(방어/판별/버티기/킹실드) 차단, 지닌 도구 위력 보정(타입 강화·생명의구슬·달인의띠·메트로놈·나무열매 등)까지 반영해 턴별 로그로 보여줌
- **3마리 파티 & 교체(Phase 8 — 배틀타워 리뉴얼)**: 편측 3마리 파티를 편성(슬롯 0 = 리드)하고, 매 턴 "기술 / 교체"를 선택. 교체 우선도(항상 기술보다 먼저)·기절 후 강제 교체·양측 파티 HP·상태이상·기절 트래커. 교체하면 구애 잠금·앙코르·도발·곡예·씨뿌리기·헤롱헤롱·뿌리박기·아쿠아링이 해제되고, 나가는 쪽에 재생력·자연회복이 발동. 등장 시 처리 파이프라인(설치물 → 등장 특성(위협·날씨·트레이스 등) → 재생력/자연회복). **상대 진영 설치 기술 6종**(스텔스록·압정뿌리기·독압정·끈적끈적네트·비검천중파·암석액스): 스택(압정 3층·독압정 2층)·등장 데미지·비접지 판정·고속스핀/안개제거 제거·독타입 등장 시 독압정 흡수. 딸린 특성 플라워베일·공생 배선, 가속의 "교체로 나온 턴 미발동" 예외 복원
- **사이드 메뉴(포켓몬 도감 / 기술표)**: 전체 로스터·기술 데이터를 검색·열람
- **특성 기반 전투 로직 대거 확장(Phase 4.5~7)**: 방어적 특성(부유·정전기·타오르는불꽃·저주받은바디 등) 다수, 상대 방어적 특성 무시(틀깨기), 부가효과·위력 트레이드(우격다짐), 도구 강탈/상실(매지션·곡예), 상대 기술 선택 제약(도발·사슬묶기·앙코르), 폼체인지(킬가르도 배틀스위치), 타입 변환(변환자재), 무작위 기술 대체(잠꼬대), 명중률 보정(복안), 장 전체 타입 위력(페어리오라), 부가 데미지 전면 무효(매직가드), 상대 기술 반사(매직미러), 추가효과 무산(인분), 독타입 면역 관통(부식) 등
- **로컬 자동 저장**: 편성 내용이 브라우저에 자동 저장되고 새로고침해도 복원됨

## 데이터 규모

- 포켓몬 228종 (포챔스 입국몬 2~9세대 전체 병합, 메가진화 가능 73종 — 그중 리자몽·한카리아스·루카리오·라이츄는 메가폼 2개)
- 기술 497개 (우선도·랭크 변화·다단히트 정보 포함)
- 특성 202개 (전부 효과 설명 포함, 그중 다수는 결정력/내구력/배틀 로직에 실제 반영되도록 구조화)
- 도구 150종 (메가스톤 포함, 전부 효과 설명 포함. 다수는 데미지 위력 보정 배율로 구조화)
- 성격 21종

## 기술 스택

React + TypeScript + Vite, 별도 백엔드 없이 로컬 JSON 데이터 + `localStorage`로 동작.

## 시작하기

```bash
npm install
npm run dev
```

5173 포트가 다른 프로젝트와 겹칠 수 있어 `vite.config.ts`에서 5174로 고정했다 — `http://localhost:5174`로 접속한다.

## 폴더 구조

```
src/
├─ types/        Pokemon, Move, Ability, Item, Party, Nature, Matchup, BattleStats, Status 등 도메인 타입
├─ data/         pokemon.json, moves.json, abilities.json, items.json, natures.json, typeChart.json
├─ lib/          데이터 조회, 타입 상성 계산, 메가폼 계산, 파티 상성 집계, 실수치/결정력/내구력/상세 데미지 계산,
│                특성 배율(moveContext로 통합), 랭크 상태, 명중/회피/급소 계산, 턴 순서, 상태이상/행동방해,
│                다중 턴 배틀 시뮬레이터(battleSimulator — sideA/sideB 파티 배열·activeIndex·진영별 설치물 HazardState·
│                move｜switch 액션·performSwitch 등장/퇴장 파이프라인), 로컬 저장
├─ hooks/        useParty.ts(파티 상태), useMatchup.ts(매치업 화면 상태), useBattleSetup.ts(배틀타워 편측 3슬롯 셋업),
│                usePartyPresets.ts / useSlotPresets.ts(샘플 저장)
└─ components/   Sidebar, PartyBoard, PartySlotCard, TypeCoverageSummary, MatchupPage,
                 MatchupSlotCard, VerdictBadge, WeatherPicker, BattleLogPage(파티 트래커·기술/교체 토글·강제 교체 패널 포함),
                 BattleSetupCard, PokedexPage, MoveDexPage, ItemDexPage,
                 *PickerModal, PointsEditorModal, StageEditorModal 등
```

## 로드맵

- ✅ Phase 1: 파티 빌더 MVP

- ✅ Phase 2: 전투 시뮬레이터 — 턴 순서, 상세 데미지 공식, 명중/회피/급소, 상태이상·행동방해, 다중 턴 대전 로그 화면
